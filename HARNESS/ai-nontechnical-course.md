# HARNESS.md — AI Nontechnical Course

## Назначение

Интерактивный курс "ИИ для не-IT специалистов" (закупки, логистика, строительство).  
10 уровней, 4 языка (RU, EN, FR, ZH), практические промпты + квизы.

Live: https://logistoria.com/ai-course/

## Правила добавления урока

### Шаг 1: Создать структуру

```bash
# Создать директорию
mkdir lessons/NN-slug

# Создать index.html по шаблону
# Скопировать от соседнего урока → адаптировать
```

**NN** = 2 цифры (00-99).  
**slug** = короткое название на английском (choose-model, prompt-engineering).

### Шаг 2: Наполнить контент

Обязательные секции в `index.html`:
- [ ] Заголовок урока + номер уровня
- [ ] Вводная (зачем это нужно)
- [ ] Основной контент (теория + практика)
- [ ] Практические промпты (копируемые)
- [ ] Квиз (минимум 3 вопроса)
- [ ] Навигация ← Предыдущий | Следующий →

### Шаг 3: Обновить навигацию

**В предыдущем уроке:**
- Добавить ссылку "Следующий →" на новый урок

**В новом уроке:**
- Добавить "← Предыдущий" на прошлый
- Добавить "Следующий →" на следующий (если есть)

### Шаг 4: Обновить catalog.html

Добавить карточку урока:
```html
<div class="lesson-card" data-level="N" data-lesson="NN">
  <div class="lesson-number">Урок NN</div>
  <h3>Название урока</h3>
  <p>Краткое описание (2-3 строки)</p>
  <a href="lessons/NN-slug/index.html" class="lesson-link">Начать →</a>
</div>
```

### Шаг 5: Обновить updates.html (⚠️ КРИТИЧЕСКИ ВАЖНО!)

**Правило:** При добавлении любого урока/уровня/вкладки — обновить на **всех 4 языках**!

**Формат записи:**
```html
<div class="update-item">
  <span class="update-date">2026-07-29</span>
  <span class="update-badge new">NEW</span>
  <p>Урок 4.7 "Harness: как ИИ получает руки"</p>
</div>
```

**Языки:**
- RU: `updates.html` (корень)
- EN: `en/updates.html`
- FR: `fr/updates.html` (можно ссылаться на EN)
- ZH: `zh/updates.html` (можно ссылаться на EN)

### Шаг 6: Скопировать на другие языки

```bash
# EN
mkdir en/lessons/NN-slug
cp lessons/NN-slug/index.html en/lessons/NN-slug/index.html
# → Перевести контент

# FR, ZH — аналогично (или оставить ссылку на EN)
```

### Шаг 7: Пересобрать поиск

```bash
npx pagefind --site . --serve
```

## Стиль оформления

### CSS-переменные (использовать!):
```css
--bg-primary: #0a0a0a      /* Фон */
--bg-secondary: #1a1a1a    /* Карточки */
--accent: #e94560           /* Акцентный цвет */
--text-primary: #ffffff     /* Основной текст */
--text-secondary: #a0a0a0   /* Вторичный текст */
```

### Компоненты:
- **Карточки уроков:** `lesson-card`
- **Промпты:** `prompt-box` (копируемые)
- **Квиз:** `quiz-container`
- **Навигация:** `lesson-navigation`
- **Формулы:** `formula-box`

### Запрещено:
- ❌ Inline CSS (всё через style.css или классы)
- ❌ JS внутри HTML (всё через app.js)
- ❌ Прямые ссылки на личные проекты (logistoria.com только где уместно)

## Ограничения

- **Не использовать** сторонние CDN (всё локально)
