# HARNESS.md — Ozon Tax Calculator

## Назначение

Калькулятор налогов для ООО «Интернет Решения» (Ozon) на АУСН.

Автоматизирует расчёт:
- Возвратов
- Услуг (комиссия, акты, отчёты)
- Взаиморасчётов для ЛКН АУСН

## Архитектура

```
skills/ozon-tax-calculator/
├── calculator.py       # Основной скрипт
├── requirements.txt    # Зависимости
├── SKILL.md            # Документация
└── tests/
    └── test_calculator.py
```

## Входные файлы

| Файл | Столбцы | Обязательность |
|------|---------|----------------|
| Отчёт о реализации | «Возвращено на сумму», «Выплаты по механикам лояльности» | ✅ Да |
| Отчёт о взаиморасчётах | «Суммы дебиторской задолженности», тип документа | ✅ Да |

## Алгоритм

```
Возвраты = Σ(«Возвращено на сумму») + Σ(«Выплаты по механикам»)

Услуги = Σ строк из взаиморасчётов:
  - «Отчёт о реализации»
  - «Акт выполненных работ"
  - «Отчёт о перевыставлении услуг"
  - «Акт об оказанных услугах"
```

## Команды

```bash
cd skills/ozon-tax-calculator

# Запуск
python3 calculator.py \
  --realization отчёт_реализации.xlsx \
  --mutual_settlement отчёт_взаиморасчётов.xlsx

# Тесты
python3 tests/test_calculator.py
```

## Параметры

| Параметр | Описание |
|----------|----------|
| `--realization` | Отчёт о реализации |
| `--mutual_settlement` | Отчёт о взаиморасчётах |

## Вывод для ЛКН АУСН

| Статья | Сумма |
|--------|-------|
| Приход | Услуги + Возвраты |
| Возврат прихода | Возвраты |
| Расход | Услуги |

## Ограничения

- Формат: Excel (.xlsx) или CSV
- Кодировка: UTF-8
- Даты: YYYY-MM-DD
