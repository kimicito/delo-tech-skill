# HARNESS.md — SupplyChains Bot

## Назначение

Telegram-бот для автопостинга в канал @supplychains:
- Регулярные посты 3-4 раза/день
- Источники: supplychains.ru, научные статьи, кейсы
- Аудитория: 10k+ специалистов по цепочкам поставок

## Архитектура

```
supplychains-bot/
├── bot.py              # Основной бот
├── config.py           # Настройки
├── content/
│   ├── sources.py      # Источники контента
│   ├── generator.py    # Генерация постов
│   └── scheduler.py    # Планировщик
├── utils/
│   ├── telegram_api.py # Работа с Telegram API
│   ├── parser.py       # Парсинг статей
│   └── image_gen.py    # Генерация изображений
└── data/
    ├── posted.json     # История постов
    └── queue.json      # Очередь на публикацию
```

## Правила публикации

### Частота
- **Утро (9:00):** Новость/статья
- **День (13:00):** Кейс/практика
- **Вечер (17:00):** Мем/развлечение или важная новость

### Формат поста
```
[Эмодзи] Заголовок

Текст (3-7 предложений)

Источник: ссылка
#хэштеги
```

### Источники (приоритет)
1. **supplychains.ru** — наши статьи
2. **Harvard Business Review** — исследования
3. **MIT Sloan** — кейсы
4. **Gartner** — тренды
5. **LinkedIn** — мнения экспертов

## Параметры

| Параметр | Значение |
|----------|----------|
| Макс. длина | 4096 символов |
| Изображения | ≤ 10MB, 1280×720 |
| Хэштеги | 3-5 штук |
| Часовой пояс | Europe/Moscow |

## Ограничения

- ❌ Без политики и религии
- ❌ Без прямой рекламы (только нативная)
- ❌ Без фейковых новостей
- ✅ Только проверенные источники

## Чеклист перед постом

- [ ] Фактчек информации
- [ ] Ссылка на источник
- [ ] Хэштеги релевантные
- [ ] Длина < 4096 символов
- [ ] Изображение оптимизировано (если есть)
