# HARNESS.md — WB Tax Calculator

## Назначение

Калькулятор налогов для РВБ (Wildberries / ООО «РВБ») на АУСН.

Автоматизирует расчёт:
- Комиссии WB (основной + выкупы)
- Возвратов
- Взаимозачёта для ЛКН АУСН

## Архитектура

```
skills/wb-tax-calculator/
├── calculator.py       # Основной скрипт
├── requirements.txt    # Зависимости
├── SKILL.md            # Документация
└── tests/
    └── test_calculator.py
```

## Входные файлы

| Файл | Столбцы | Обязательность |
|------|---------|----------------|
| Реестр еженедельных операций | Тип отчёта, Продажа, Итого к оплате | ✅ Да |
| Детализация отчётов | Тип документа, «Вайлдберриз реализовал Товар (Пр)» | ✅ Да |
| Уведомления о выкупе | Сумма | Опционально |
| Доп. расходы (Аналитика) | Потери/подмены/дефекты | Опционально |

## Алгоритм

```
Комиссия (Основной) = Σ(Продажа) − Σ(Итого к оплате)
Комиссия (Выкупы) = Σ(Уведомления) − Σ(реестр)
Итого комиссия = Основной + Выкупы + Доп. расходы
Возвраты = Σ из детализации (фильтр: «возврат»)
```

## Команды

```bash
cd skills/wb-tax-calculator

# Запуск
python3 calculator.py \
  --registry реестр.xlsx \
  --details детализация.xlsx \
  [--purchases уведомления.xlsx] \
  [--losses 9104.28]

# Тесты
python3 tests/test_calculator.py
```

## Параметры

| Параметр | Описание |
|----------|----------|
| `--registry` | Реестр еженедельных операций |
| `--details` | Детализация отчётов |
| `--purchases` | Уведомления о выкупе (опц.) |
| `--losses` | Сумма доп. расходов (опц.) |

## Вывод для ЛКН АУСН

| Статья | Сумма | Примечание |
|--------|-------|------------|
| Взаимозачёт | Итого комиссия | Основной + Выкупы + Доп. расходы |
| Возврат прихода | Возвраты | Отдельно |

## Ограничения

- Формат: Excel (.xlsx) или CSV
- Кодировка: UTF-8
- Даты: YYYY-MM-DD
