# delo-tech-impreport

## Описание

Skill для автоматической выгрузки отчёта **13 "Движение по импорту"** из системы ДЕЛО ТЕХ (rlisystems.ru/conterra/).

## Установка

```bash
cd ~/.openclaw/workspace/skills/delo-tech
pip install playwright
playwright install chromium
```

## Настройка

Создать файл `.env`:

```
DELO_TECH_USERNAME=pl_11640
DELO_TECH_PASSWORD=Qwerty123
```

## Использование

### Запуск

```bash
python3 delo_tech_impreport.py --date-from 01.08.2026 --date-to 21.08.2026 --output report.xlsx
```

### Параметры

| Параметр | Описание | Пример |
|----------|----------|--------|
| `--date-from` | Начало периода (DD.MM.YYYY) | `01.08.2026` |
| `--date-to` | Конец периода (DD.MM.YYYY) | `21.08.2026` |
| `--output` | Путь для сохранения | `/tmp/report.xlsx` |
| `--headed` | Показать окно браузера | (флаг) |

## Процесс выгрузки (ручной)

1. **Вход** в систему: https://rlisystems.ru/conterra/
2. **Панель управления** → **Дополнительные услуги** → **Отчётность по обработке груза**
3. **Двойной клик** на "13. Движение по импорту"
4. Заполнить форму:
   - Стивидор: ТЕРМИНАЛ ВРАНГЕЛЬ ООО
   - Договор: РУСАЛТРАНС ООО, договор КЭ/ТБ-19-2024
   - Начало периода: `01.08.2026 00:00`
   - Окончание периода: `21.08.2026 23:59`
   - Представление: Импорт
5. Нажать **"ПОКАЗАТЬ ОТЧЁТ"**
6. В таблице нажать иконку дискеты 💾 для выгрузки Excel

## Известные проблемы

- Сайт использует Vaadin-фреймворк с iframe — автоматизация через CDP ограничена
- Для headed-режима требуется X11 (xvfb-run)
- Сессия истекает ~через 30 минут бездействия
