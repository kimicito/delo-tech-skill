# Kimicito Workspace

Структура рабочей директории OpenClaw.

## Директории

| Путь | Назначение |
|------|------------|
| `personal/` | Личные задачи (стажировки, образовательные программы, контакты) |
| `work/` | Рабочие задачи (задачи_шефа.md) |
| `projects/` | Проекты (botgame, dungeonbot, educai8, smeta, super_dashboard, walkytalky) |
| `skills/` | Активные skills (price-comparison, smeta, soulsaying...) |
| `memory/` | Daily notes (2026-06-28.md...) |

## Бэкап

- Git remote: `https://github.com/kimicito/openclaw-workspace.git`
- Cron: ежедневно в 3:00 AM Asia/Shanghai
- Скрипт: `backup.sh`

## Bootstrap файлы

- `AGENTS.md` — правила поведения
- `SOUL.md` — личность
- `USER.md` — профиль пользователя
- `TOOLS.md` — локальные заметки и приоритеты skills
- `MEMORY.md` — долгосрочная память (только в main session)
