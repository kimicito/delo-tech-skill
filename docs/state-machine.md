# State Machine для скиллов

## Фазы выполнения скилла

```
[ANALYZE] → [VALIDATE] → [EXECUTE] → [VERIFY] → [REPORT]
```

### ANALYZE — Анализ
- Изучить входные данные
- Проверить формат и полноту
- Определить граничные случаи

### VALIDATE — Валидация
- Проверить предусловия
- Валидировать параметры
- Убедиться в наличии необходимых данных

### EXECUTE — Выполнение
- Запустить основной алгоритм
- Логировать промежуточные результаты
- Обрабатывать ошибки

### VERIFY — Проверка
- Сверить результат с ожиданиями
- Проверить на адекватность (sanity check)
- Запустить тесты если есть

### REPORT — Отчёт
- Сформировать читаемый вывод
- Зафиксировать результат в memory
- Обновить документацию при необходимости

## Правила переходов

- `ANALYZE → VALIDATE`: данные получены
- `VALIDATE → EXECUTE`: все проверки пройдены
- `VALIDATE → ANALYZE`: данных недостаточно, запросить уточнение
- `EXECUTE → VERIFY`: расчёт завершён
- `EXECUTE → ANALYZE`: ошибка, требуется переосмысление
- `VERIFY → REPORT`: проверка пройдена
- `VERIFY → EXECUTE`: найдена ошибка, пересчитать

## Пример: WB Tax Calculator

```
ANALYZE: Изучить реестр Excel, определить период
VALIDATE: Проверить наличие колонок Продажа, Итого к оплате
EXECUTE: Рассчитать комиссию = Σ(Продажа) − Σ(Итого к оплате)
VERIFY: Сверить с предыдущими периодами, проверить на отрицательные значения
REPORT: Вывести таблицу с результатами, записать в memory
```
