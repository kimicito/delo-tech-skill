## 2026-06-27

### Price-Comparison Skill v3.0 — Технические матрицы аналогов

Обновлен skill `price-comparison` до версии 3.0 с поддержкой технических сравнительных матриц.

**Новая архитектура:**
- Основная таблица с ценами (вкладка «Результат сравнения»)
- Для каждого аналога — отдельная вкладка Excel с детальной технической матрицей (30+ параметров)
- Субагенты (1 на аналог) выполняют глубокое исследование спецификаций через `kimi_search`

**Созданные файлы:**
- `skills/price-comparison/SKILL.md` — полная документация v3.0
- `skills/price-comparison/scripts/runner_v2.py` — создание основной таблицы + analogs.json
- `skills/price-comparison/scripts/matrix_builder.py` — сборка финального Excel с матрицами
- `skills/price-comparison/scripts/analog_researcher.py` — шаблон для субагентов
- `skills/price-comparison/subagent-task.md` — инструкция для субагентов (8 категорий сравнения)
- `skills/price-comparison/subagent-config.json` — конфиг субагента
- `skills/price-comparison/analogs/analog_matrix_Cisco_C9200_Huawei_S5735.json` — демо-матрица

**Структура матрицы (8 категорий):**
1. Порты и интерфейсы
2. Питание
3. Производительность
4. ПО и управление
5. Физические характеристики
6. Безопасность
7. Интеграция
8. Надёжность

**Цветовая кодировка:**
- 🟢 Зелёный — характеристики совпадают или аналог лучше
- 🟡 Жёлтый — частичное совпадение, отличия не критичны
- 🔴 Красный — критичное отличие, функциональность потеряна
- ⚪ Серый — информация не найдена

**Демо-пример:** Cisco C9200-24P-E vs Huawei S5735-S24P4X
- 17 параметров ✅, 9 ⚠️, 2 🔴 (MACsec отсутствует, forwarding rate в 2x ниже)
- Экономия: 7% (~7 520 ₽)
- Рекомендация: замена возможна для корпоративных сетей без требования MACsec

**Eval v3.0** дополнительно проверяет:
- Наличие отдельных вкладок для каждого аналога
- Полноту матриц (≥5 параметров)
- Все статусы заполнены (✅/⚠️/🔴/⚪)

**Workflow:**
1. Агент ищет цены (2+1) → записывает в JSON
2. runner_v2.py создаёт основную таблицу + analogs.json
3. Субагенты исследуют аналоги параллельно → сохраняют JSON
4. matrix_builder.py собирает финальный Excel с вкладками
5. eval.py проверяет перед выдачей

**Демо-файл:** `price_comparison_v3_demo.xlsx` (3 вкладки: сводка, основная таблица, матрица Huawei)

### Технические заметки
- Субагенты запускаются через `sessions_spawn` с `runtime="subagent"`
- Поиск спецификаций через `kimi_search` по запросам: `[product] datasheet технические характеристики`
- Приоритетные источники: datasheet производителя, официальные сайты, технические порталы
- Важно: sub-agent не должен дублировать поиск цен (это делает основной агент)
- Субагент ищет только технические спецификации и строит матрицу сравнения
