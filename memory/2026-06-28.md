**Создано для предотвращения повторения:**
- `eval_smeta.py` — скрипт проверки сметы против ВОР (FAIL/WARN система):
  - Всё из ВОР есть в смете?
  - В смете нет лишнего (не из ВОР)?
  - Количества совпадают?
  - Единицы измерения корректны?
  - НР и СП присутствуют?
  - Позиции с "УТОЧНИТЬ" помечены?
- `ПРАВИЛО_ВОР.md` — red line: ВОР/ведомость дефектов = ЕДИНСТВЕННЫЙ источник объёмов работ
- `ОШИБКИ_АНАЛИЗ.md` — разбор корневых причин (самоуверенность, отсутствие правила, нет доступа к ГРАНД-Смете)

**Процесс работы с новой ВОР (7 шагов):**
1. Сохранить ВОР (оригинал не трогать)
2. Извлечь позиции, условия, регион
3. Для каждой позиции: знаю код ФЕР → вписываю, не знаю → "УТОЧНИТЬ"
4. Создать Excel с формулами (базовая цена × поправка × индекс)
5. Запустить eval_smeta.py
6. Добавить комментарии "что уточнить в ГРАНД-Смете"
7. Сохранить, запушить, отправить сметчику

**Чего не хватает (требует сметчика):**
- ГРАНД-Смета (подбор кодов ФЕР, проверка расценок)
- Актуальные письма Минстроя (индексы по статьям)
- Точные характеристики оборудования (масса, диаметр)
- Шифр строительства (для % НР и СП)

- **Источник:** https://www.weforum.org/publications/the-ai-playbook-for-financial-services/
- **Дата публикации:** 24 июня 2026
- **Авторы:** WEF Centre for Financial and Monetary Systems + Accenture
- **Методология:** 18 месяцев, 150+ senior executives, 100+ организаций, раундтейблы в HK, London, NYC, Singapore

**Ключевые находки (4 штуки):**
1. AI — стратегический вопрос для Совета директоров (не просто IT-пилот)
2. Дифференциация через клиентские отношения, усиленные AI (аналитика — commodity, доверие — преимущество)
3. Максимальная выгода от голистического редизайна (не точечное внедрение)
4. Agentic AI меняет правила (спектр автономности: assistive → autonomous → multi-agent)

**Framework:** 4 этапа — Define Vision → Build Digital Core → Two-Speed AI → Transform Workforce

**Кейс KBTG (Таиланд):** 200 идей → 60 MVPs → 8 платформ, ~30,000 рабочих дней сохранено, 20-59% productivity improvement
