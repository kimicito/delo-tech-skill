**Создано для предотвращения повторения:**
- `eval_smeta.py` — скрипт проверки сметы против ВОР (FAIL/WARN система):
  - Всё из ВОР есть в смете?
  - В смете нет лишнего (не из ВОР)?
  - Количества совпадают?
  - Единицы измерения корректны?
  - НР и СП присутствуют?
  - Позиции с "УТОЧНИТЬ" помечены?

**Процесс работы с новой ВОР (7 шагов):**
1. Сохранить ВОР (оригинал не трогать)
2. Извлечь позиции, условия, регион
3. Для каждой позиции: знаю код ФЕР → вписываю, не знаю → "УТОЧНИТЬ"
4. Создать Excel с формулами (базовая цена × поправка × индекс)
5. Запустить eval_smeta.py
6. Добавить комментарии "что уточнить в ГРАНД-Смете"
7. Сохранить, запушить, отправить сметчику

**Чего не хватает (требует сметчика):**
- ГРАНД-Смета (подбор кодов ФЕР, проверка расценок)
- Актуальные письма Минстроя (индексы по статьям)
- Точные характеристики оборудования (масса, диаметр)
- Шифр строительства (для % НР и СП)
