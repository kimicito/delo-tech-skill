### Key Design Decisions
1. **Config as source of truth** — eval reads from `config/indexes.json`, never hardcoded
2. **Object folders** — each project: `data/<name>/` with VOR + versioned estimates + README
3. **VOR is immutable** — never edited; estimates version as v1, v2, v3... final
4. **Eval gates** — FAIL blocks estimate submission; must pass before sending
5. **Cron monthly** — 1st at 9:00 checks FGIS CS for updates; logs to `/var/log/smeta_updates.log`

### БИМ Methodology Rules (Hardcoded in Eval)
- Indices by article: INDEX_ZP, INDEX_MACH, INDEX_MAT (not single INDEX_SMR)
- НР/СП from ФОТ (not from direct costs)
- Multiple corrections with different coeffs by article
- ФССЦ for materials separately
- VOR/Ведомость дефектов = ONLY source of work volumes
