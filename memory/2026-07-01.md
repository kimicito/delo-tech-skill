## Ключевые инсайты от профессионала (сохранены в SKILL.md)

1. **Выбор кода ГЭСН**: через классификатор строительных ресурсов (cnsi.ru) → отбор по классу работ → поиск по списку норм. Без этого — нет точного ГЭСН. Каждому ВОРу нужно найти подходящую норму по описанию работ.
2. **ПСЦ (проект сметной цены)**: цена из прайса поставщика (внутренний отдел снабжения). Но ГРАНД-Смета не принимает отрицательные поправки, поэтому иногда цена из федерального справочника ФССЦ.
3. **"Дополнительные затраты на сложные фундаменты"**: ГЭСН06-02-001-08 — применяется когда размер плиты фундамента не менее 100 м², толщина не менее 1.5 м. Проверяется по чертежу.
4. **Расчёт объёмов материалов**: по 3D-модели (Tekla, Revit) или вручную по чертежам. Например, для опалубки считается площадь боковой поверхности (периметр × высота). Бетон: суммарный объём по модели. Арматура: масса по спецификации из модели или расчётная по удельному расходу (кг/м³).
5. **Почему 70 позиций для ПФм1 vs 9 для Фом**: крупная плита ПФм1 имеет много элементов (опалубка, каркас, закладные, швеллер, пеноплекс, герметик). Мелкие фундаменты Фом — простые, без закладных и каркасов. Объём тоже отличается (469 м³ vs 7.5 м³).
6. **Перевозка 1918.95 т**: масса грунта + ПГС. Грунт: 1163 м³ × 1.6-1.8 т/м³ (плотность в зависимости от влажности) = ~1860-2090 т. ПГС: 637 м³ × ~1.6 т/м³ = ~1020 т. Сумма ~2900 т, но в смете 1918.95 т — возможно, часть грунта не вывозится (остаётся на площадке), либо только грунт без ПГС (1918.95 ≈ 1163 × 1.65). Нужно уточнить.
7. **НР/СП по подразделам**: требование методологии ГРАНД-Сметы — НР и СП считаются отдельно для каждого раздела/подраздела. Общих на весь объект не бывает.
8. **Каркас пространственный КП1**: металлоконструкция для армирования (сварной каркас из уголков и полос). Цена 154166.67 руб./т — это изготовление + сварка, в 2 раза выше арматуры (просто прокат). Для каждого фундамента свой каркас по чертежам.
9. **Процентные расценки**: "Гидроизоляция обмазочная 0.7733 (100 м²)" — 0.7733 = количество единиц измерения (100 м² каждая). Итого площадь = 0.7733 × 100 = 77.33 м².
10. **ПРЧ vs ПТРКр**: ПРЧ = прейскурант на автомобильные перевозки (старая система). ПТРКр = перевозка автотранспортом по Красноярскому краю (новый формат). Нужно использовать актуальный формат.
11. **Состав сметы по элементам**: Земляные → Бетонная подготовка → Фундамент ПФм1 → Фундамент Фом1 → Фом2 → Фом3 → Крыльцо → Деформационные швы → Отмостка. Каждый элемент — отдельный подраздел со своими позициями.
12. **Eval VOR vs Smeta**: отдельный скрипт `eval_vor_smeta.py` проверяет соответствие ВОР и сметы (5 пунктов: всё из ВОР есть в смете, нет лишнего, количества совпадают, единицы корректны, НР/СП присутствуют).
