### Detailed RAM Analysis
| Parameter | Value |
|-----------|-------|
| Total RAM | 7.1 GB |
| Really free (free) | 1.9 GB |
| Available (free+cache) | 5.3 GB |
| openclaw-gateway | 1.2 GB RSS |
| buff/cache | 3.6 GB |
| Overcommit | strict (0), ratio 50 |

Key insight: `available` (5.3 GB) is misleading. PyTorch allocates contiguous blocks, needs `free` (1.9 GB). EasyOCR needs 1.3 GB peak → crashes with SIGKILL at 1500px+.

### Tesseract Results
- 500px: garbage (too small)
- 1000px: garbage
- 1500px: partial structure visible, lots of garbage
- 2000px: SIGKILL even for Tesseract
- Preprocessing (CLAHE, sharpening, adaptive threshold): no improvement on blurry scans
- PSM modes 3, 4, 6 tested: no meaningful difference

Conclusion: Tesseract cannot read blurry construction drawing scans at any practical resolution.

### ⚡ BREAKTHROUGH: PDF Conversion Works!
- User converted TIFF → PDF using external converter
