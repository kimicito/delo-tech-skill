- **ClawHub skills**: установлены P0 (mermaid, gh-issues, html-mailer-builder, node-connect, weather, tmux, taskflow, video-frames) и P1 (excel-xlsx, word-docx, browser-scraping, youtube-watcher, mcporter, auto-updater, multi-search-engine).

## Drawings-to-VOR (сметы)
- Обработаны чертежи **КЖ5** через полный pipeline.
- Расширен `extract_vor.py`: добавлены **ростверки (Рсм)**, **балки фундаментные (БФм)**, **фундаменты (ФОм)**, **закладные детали (Зд)**, **каркасы (КП)**.
- Добавлено извлечение **количеств, размеров и формул расчёта**.
- Добавлен **`vor_reviewer.py`** — автоматическая проверка ВОР без API (проверяет дубли, полноту, разумность значений).
- Интегрирован `vor_reviewer` в **price-comparison skill** (сравнение смет + проверка ВОР).
- Сравнение ВОР AI vs сметчик-профессионал: разница ~3-5% на типовых элементах, ~10-15% на сложных/закладных.

## Курс обучения: OpenWebUI / Генеративный ИИ
- Создан проект `projects/ai-training-course/` (5 модулей, 15 уроков, 12,000+ строк).
- Интегрирована **презентация на 23 слайда** (OpenWebUI для директоров дивизиона РУСАЛ / алюминиевого завода).
- Ключевые концепции встроены: **РКЗФО**, **Eval (4 типа)**, **RAG-настройки** (chunk 500-800, overlap 10-20%, top-k 5-8, temp 0.1-0.2), **anchor-запросы**, **системные промпты по 6 департаментам**, **правило 15 минут**.
- Модули: 0 (общий), 1 (PR/Дирекция СО), 2 (строители), 3 (СБ), 4 (закупки/логистика).
- Каждый урок содержит: теорию (15 мин), Live Demo, Hands-on (20 мин), чек-лист, системный промпт, практические кейсы.
- Курс запушен в `github.com/kimicito/openclaw-workspace.git` (commit `4a51461`).

## Решения
- **Storewars**: порт 80 (через Nginx reverse proxy), SQLite вместо PostgreSQL для упрощения.
- **Таймвеб Cloud**: только порты 22/80/443 доступны извне, нестандартные порты (8080, 8001 и др.) заблокированы на уровне файрвола.
- **AI Vision**: Qwen-VL лучше для OCR/детальных сцен, LLaVA для описания сцен, обе on-premise.
- **Eval обязателен** для важных результатов (проверка на галлюцинации, выдуманные факты, цитаты).
- **Системные промпты** зафиксированы для 6 департаментов (закупки, производство, финансы, HR, юристы, качество/продажи).

## Следующие шаги (ожидают решения)
- Подготовить презентации (PPTX) для уроков курса.
- Подготовить материалы для следующего занятия (ИИ-агенты, уровень 4).
- Добавить реальные кейсы из работы компании в модули 1-4.
