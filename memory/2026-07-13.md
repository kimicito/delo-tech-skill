   - Dictionary-based phrase replacement for common UI elements (navigation, section headers, labels, quiz buttons)

**Challenges encountered:**
- Word-level dictionary replacement broke words inside other words (e.g., "не" inside "ИТ-специалистов" → "AndТ-withпецandandлandwiththatin")
- Batch translation via Google Translate API caused text segment reordering (joining by `\n`)
- Had to switch to one-by-one segment translation to preserve structure
- Apostrophes in JavaScript strings caused issues after translation (needed manual cleanup)
- Remaining 19 Russian text segments after 3 passes — acceptable (mostly edge cases)

**Technical notes:**
- Google Translate free endpoint: `https://translate.googleapis.com/translate_a/single?client=gtx&sl=ru&tl=en&dt=t&q={text}`
- Rate limit: ~0.3s between requests, 0.5s between files — 39 lessons took ~15-20 min
- Commit: `a85dc15` on main, `gh-pages` branch deployed
