## Multi-Agent vs Pipeline Clarification

**Multi-Agent Research:**
- Parallel execution (3-6 agents simultaneously)
- Use case: gathering diverse information (prices, regulations, suppliers)
- Resource: RAM-heavy (1.5-2G), CPU-medium
- Output: synthesized briefing from multiple sources

**AI Pipeline:**
- Sequential execution (step 1 → step 2 → step 3)
- Use case: content production (slides → voiceover → upload → notify)
- Resource: RAM-light (200-500M), CPU-light, but time-consuming
- Features: checkpoint after each step, retry with backoff, graceful error handling

**Key difference:** Multi-Agent = parallel research team. Pipeline = production conveyor.
