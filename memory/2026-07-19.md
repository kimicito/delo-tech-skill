## AgentField — Enterprise Agent Control Plane

**URL:** https://github.com/Agent-Field/agentfield
**Status:** ⛔ Не внедряем сейчас, запомнить для enterprise-масштаба

**Что это:** Open-source control plane для AI-агентов в production. Не framework для написания (как LangChain), а инфраструктура для запуска.

**Ключевые фичи:**
- REST API из коробки (каждый агент = POST endpoint)
- Distributed fan-out (1 запрос → 1000 суб-агентов)
- Human-in-the-loop (`app.pause()` для approve)
- Signed audit trails (verifiable, tamper-proof)
- Memory scopes: global / actor / session / workflow
- Observability: DAG execution, traces, metrics dashboard
- Multi-lang: Python, Go, TypeScript

**Сравнение с OpenClaw:**
- OpenClaw = personal assistant, скиллы, Telegram
- AgentField = production API, enterprise compliance, fleet management
- AgentField требует Docker + control plane + базу
- OpenClaw subagents не масштабируются на 1000+, AgentField — да

**Когда рассмотреть:**
1. Enterprise: нужен audit trail, human approval, access policies
2. API для агентов: внешние сервисы звонят агентам по HTTP
3. 1000+ суб-агентов: массовый fan-out
4. Compliance: доказать, что решение принято агентом

**Решение:** ⛔ Не внедрять сейчас. Сфокусироваться на OpenClaw + 4 новых проектах. Вернуться к AgentField при enterprise-масштабе.
