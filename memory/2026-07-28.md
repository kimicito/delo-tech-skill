## supplychains-bot — баг с парсингом статей
- **Симптом:** `Can't parse entities: can't find end of the entity starting at byte offset 831`
- **Причина:** `_fetch_article_content` парсит `<p>` теги, но попадает на JSON-LD микроразметку и JavaScript из HTML
- **Результат:** в текст поста попадает мусор `"telephone": "+7-499-288-7371", "email": "PROJECT@supplychains.ru"` — кавычки ломают Markdown парсинг Telegram
- **Готовый пост:** `content/scheduled/auto_20260728_160002.json` — содержит JSON-LD вместо текста статьи
- **Фикс нужен:** фильтровать `<script>`, `<style>`, JSON-LD перед извлечением текста + экранировать Markdown-символы
