## Введение

Claude Code — это инструмент для агентного программирования (agentic coding), который работает в терминале. Он совместим с любой IDE, терминалом, SSH, tmux.

## Настройка окружения (рекомендации)

1. **terminal setup** — настройка сочетаний клавиш
   - Shift+Enter для новых строк (не нужны бэкслэши)
   
2. **/theme** — выбор темы (светлая/тёмная/Daltonize)

3. **GitHub App** — установка для упоминаний в issue/PR
   - Команда: `/install-github-app`

4. **Настройка разрешённых инструментов** — чтобы не спрашивал каждый раз

5. **Диктация (macOS)** — настройка в Системных настройках → Универсальный доступ → Диктация
   - Нажимаешь клавишу диктации дважды и говоришь промпт
   - Можно разговаривать с Claude Code как с другим инженером

## Главный совет: Начни с Q&A по кодовой базе

Это первое, что рекомендуют новым сотрудникам Anthropic:
- Задавай вопросы о коде
- Claude исследует кодовую базу и отвечает

**Результат:** Онборинг сократился с 2-3 недель до 2-3 дней.

**Важно:** Нет индексации в облаке. Код остаётся локально. Не используется для обучения моделей.

## Ключевые промпты (incantations)

### 1. "Before you write code, make a plan"
- Claude сначала планирует, потом пишет код

### 2. "think, commit, push"
- Claude думает → делает commit → push → создаёт PR
- Сам определяет формат коммита из git history
- Не требует объяснений — понимает из контекста

## Инструменты (Tools)

### Bash инструменты
- Просто скажи: "use this CLI to do something"
- Claude сам разберётся через `--help`
- Если часто используешь — добавь в `CLAUDE.md`

### MCP инструменты
- Расскажи Claude о MCP-сервере
- Он сам разберётся как использовать

## Память (Memory)

### Структура CLAUDE.md
- Проектный `CLAUDE.md` — общие правила
- Вложенные `CLAUDE.md` — для конкретных директорий
- Команда `/memory` — редактировать файлы памяти
- `#` (хэштег) — запомнить что-то на лету, можно выбрать куда сохранить

### Пример из практики Anthropic
- В репозитории apps есть Puppeteer MCP-сервер
- MCP JSON в репозитории — все инженеры используют автоматически
- Puppeteer для end-to-end тестов и скриншотов
- Не нужно каждому устанавливать самому

## Горячие клавиши

- **Shift+Tab** — принять все правки (auto-accept edits)
  - Bash-команды всё ещё требуют подтверждения
  - Редактирование кода — автоматически
  - Полезно когда Claude на правильном пути или пишет тесты

- **#** (хэштег) — запомнить что-то
  - Например, если Claude неправильно использует инструмент — скажи как правильно, он запомнит

## Почему CLI, а не IDE?

1. В Anthropic используют разные IDE (VS Code, Zed, Xcode, Vim, Emacs)
   - Терминал — общий знаменатель

2. Модели развиваются очень быстро
   - Возможно, к концу года IDE не понадобятся
   - Не хотят перегружать UI — может стать бесполезным

## Вопрос из аудитории

**Q:** Как используете Claude Code для ML/моделирования?
**A:** ~80% технических сотрудников Anthropic используют Claude Code ежедневно. Исследователи используют notebook tool для редактирования и запуска ноутбуков.
