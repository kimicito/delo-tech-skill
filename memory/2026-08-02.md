### Уроки (Lessons Learned)
1. **При вставке нового уровня** нужно проверять НЕ ТОЛЬКО `catalog.html` и `index.html`, но и **фактические имена папок** `lessons/NN-*/` — они могут не совпадать с ссылками.
2. **Массовая замена строк** в HTML без уникального контекста приводит к «заражению» соседних секций (инцидент с `level18` в EN catalog).
3. **Python-скрипты для проверки** лучше, чем ручной grep: создал `/tmp/check_404.sh` для автоматической проверки всех ссылок в `catalog.html` против реальных папок.
4. **После структурных изменений** всегда нужно делать сквозную проверку: `index.html` → `catalog.html#levelX` → `id="levelX"` → `href="lessons/NN-*/"` → реальная папка `lessons/NN-*/`.
