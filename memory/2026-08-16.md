### Проблема

### Найденные факты

**1. Nginx конфиг:** `/etc/nginx/sites-enabled/safemind`
- Проксирует `/api` на `http://127.0.0.1:8001` ❌
- Должен быть порт `8000` (SafeMind backend)
- Фронтенд: `root /opt/safemind; index index.html;`

**2. Docker контейнеры StoreWars (занимают порты):**
| Контейнер | Порт | Описание |
|-----------|------|----------|
| storewars-backend | 8001 | Kadena backend |
| storewars-frontend | 8080 | Kadena frontend |
| storewars-db | 5432 | Postgres |

**3. SafeMind backend:**
- Работает на порту 8000 (uvicorn)
- `systemctl status safemind` показывал `active (running)`

**4. Фронтенд файлы SafeMind:**
- `/opt/safemind/` содержит backend-файлы (`api_server.py`, `backend/`, `campaign.db`)
- **НЕТ фронтенд HTML:** нет `index.html`, нет папок `ru/`, `en/`, `es/`
- Вероятно фронтенд лежит в другом месте или деплоился отдельно

**5. SSH проблема:**
- SSH сервер запущен (`systemctl status ssh` — active, listening on 0.0.0.0:22)
- Но внешние подключения таймаутят
- Проблема: группа безопасности Timeweb не привязана к серверу или правило ещё не применилось
- Пользователь добавил правило для IP 43.98.171.248, но подключение всё ещё не работает

### Root Cause
- Nginx проксирует API на 8001 (StoreWars Docker) вместо 8000 (SafeMind)
- Фронтенд HTML файлы SafeMind не найдены в `/opt/safemind/`

### Следующие шаги (в процессе)
1. Исправить nginx: `sed -i 's/127.0.0.1:8001/127.0.0.1:8000/' /etc/nginx/sites-enabled/safemind`
2. Проверить ответ SafeMind: `curl http://localhost:8000/`
3. Найти где лежат HTML-файлы фронтенда (возможно в `/var/www/` или отдельном репозитории)
4. `nginx -t && systemctl reload nginx`

**Важно:** Фронтенд SafeMind (многоязычный сайт ru/en/es) деплоился отдельно от бэкенда. Нужно найти исходники или собранные файлы.
