- **browser tool (CDP)** — не может взаимодействовать с элементами внутри iframe
- **Selenium** — не установлен на сервере, установка через apt убивается SIGKILL

### Решение
- Создан скрипт `delo_tech_impreport_v2.py` для **headed-режима** (с окном браузера)
- Пользователь запускает локально с `--headed` флагом
- Рабочий процесс задокументирован в `README-impreport.md`

### Итоговый процесс (ручной / полуавтоматический)

cd ~/.openclaw/workspace/skills/delo-tech
