## CLI-Anything (HKUDS)

- **Что:** Фреймворк для создания CLI-обёрток (harnesses) вокруг любого ПО, чтобы AI-агенты управляли им через текстовые команды
- **Репо:** `github.com/kimicito/CLI-Anything`
- **Реестр:** CLI-Hub (`pip install cli-anything-hub`)
- **Готовые harnesses:** FreeCAD, Blender, QGIS, ArcGIS, Kdenlive, Shotcut, Obsidian, Zotero, n8n, ChromaDB, LibreOffice и 200+ других
- **Когда использовать:** задачи, требующие управления desktop-software или CAD/медиа/документами
- **Добавлено:** 2026-07-16
