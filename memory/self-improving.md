# Self-Improving Rules

## Status Updates During Long Operations

**Rule:** If a task takes longer than 4 minutes without responding to the user, send a brief status update explaining:
- What I'm currently working on
- What step I'm at
- ETA or next milestone

**Trigger:** Any long-running operation (file processing, OCR, deployment, etc.)
**Frequency:** Every 4 minutes if no response sent
**Format:** Short, concrete (2-3 sentences max)
