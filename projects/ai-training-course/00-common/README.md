# Модуль 0: Общий вводный курс

## Цель
Дать всем сотрудникам базовое понимание Generative AI, on-premise инфраструктуры и навыки промпт-инжиниринга.

## Урок 0.1: Что такое Generative AI — за 30 минут

### Цели
- Понять разницу между традиционным AI и Generative AI
- Узнать, как работают LLM (без математики)
- Понять, почему on-premise важен для корпоративных данных

### План (15 слайдов)
1. **Традиционный AI vs Generative AI** — сравнительная таблица
2. **Как работает LLM** — аналогия с "autocomplete на стероидах"
3. **Типы моделей** — text, vision, code, multimodal
4. **Популярные модели** — GPT, Claude, Llama, Qwen, Mistral
5. **On-premise vs Cloud** — безопасность данных, стоимость, скорость
6. **Наш стек** — OpenWebUI + Ollama + локальные модели
7. **Где применяем** — 4 направления, примеры задач
8. **Что НЕ умеет AI** — галлюцинации, проверка фактов, критическое мышление
9. **Правила безопасности** — не вводить конфиденциальные данные в cloud
10. **Live Demo** — первое общение с моделью
11. **Практика** — каждый задаёт 3 вопроса модели
12. **Разбор** — хорошие и плохие ответы
13. **Чек-лист** — что запомнить
14. **Домашнее задание** — поиграть 15 минут с интерфейсом
15. **Q&A**

### Hands-on задание
Открыть OpenWebUI, задать 3 вопроса:
1. Общий знания ("Какие бывают фундаменты?")
2. Креативный ("Напиши стих про стройку")
3. Профессиональный (своя специальность)

### Ожидаемый результат
Все сотрудники могут открыть интерфейс, задать вопрос, оценить качество ответа.

## Урок 0.2: OpenWebUI — интерфейс и возможности

### Цели
- Освоить интерфейс OpenWebUI
- Понять настройки моделей (temperature, top_p, system prompt)
- Научиться создавать персонажей (custom models)

### План
1. **Интерфейс** — чат, история, настройки
2. **Выбор модели** — какая для чего
3. **Параметры** — temperature (креативность vs точность)
4. **System prompt** — задание роли модели
5. **Custom models** — создание персонажей для задач
6. **RAG (Documents)** — загрузка документов для ответов
7. **Functions/Tools** — как агенты подключаются
8. **Практика** — создать 3 персонажа для своей работы

### Hands-on задание
Создать персонажа "Сметчик-помощник" с system prompt:
```
Ты — опытный сметчик. Помогаешь проверять нормативы, 
находить ошибки в сметах, объяснять формулы. 
Отвечай кратко, по делу, с примерами.
```

## Урок 0.3: Промпт-инжиниринг для начинающих

### Цели
- Научиться писать промпты, которые дают точные ответы
- Понять структуру: роль + контекст + задача + формат
- Получить инструменты для повседневной работы

### План
1. **Плохой vs хороший промпт** — сравнение
2. **Структура RICE** — Role, Input, Context, Expectation
3. **Few-shot prompting** — примеры в промпте
4. **Chain of Thought** — "Давай разберём шаг за шагом"
5. **Формат вывода** — JSON, таблица, список, markdown
6. **Итеративное улучшение** — 3 версии промпта, сравнение
7. **Типовые шаблоны** — для каждого направления
8. **Практика** — написать 5 промптов для своих задач

### Hands-on задание
Улучшить промпт для своей специальности за 3 итерации.

### Шаблоны для каждого направления (вынесены в отдельные модули)
- PR: "Напиши пресс-релиз о [событие], аудитория [целевая], тон [нейтральный/позитивный]"
- Сметчики: "Проверь смету на ошибки: [вставить текст]. Укажи неточности, посчитай итог"
- СБ: "Проанализируй видеозапись [описание]. Опиши подозрительные действия"
- Закупки: "Сравни 3 предложения по критериям: цена, сроки, гарантия"
