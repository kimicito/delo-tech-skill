# Модуль 0: Первые шаги с OpenWebUI

> **Для кого:** Все сотрудники, кто впервые работает с генеративным ИИ.
> **Цель:** Научиться использовать ИИ в ежедневной работе. От "как открыть" до "как получить отличный ответ".
> **Формат:** 4 урока по 30 минут. Теория 10 мин + Live Demo 10 мин + Практика 10 мин.

## Урок 0.1: Знакомство с OpenWebUI — первый запрос

### Что такое OpenWebUI и почему он безопасен

**OpenWebUI** — это ваш личный чат с искусственным интеллектом. Выглядит как Telegram или WhatsApp, но вместо человека отвечает ИИ-модель.

**Главное преимущество — данные не уходят наружу:**
- Ваши запросы, документы, переписка остаются внутри компании
- Не отправляются в ChatGPT, Яндекс, Google
- Безопасно для конфиденциальной информации

**Где находится:**
```
Откройте браузер → введите адрес: [внутренний URL компании]
→ Войдите по логину и пароли (как в корп. системе)
```

### Интерфейс: что где находится

```
┌─────────────────────────────────────────────────────────────┐
│  OpenWebUI                                                  │
│  ┌──────────┬──────────────────────────────────────────┐   │
│  │ 📝 Чаты  │  Привет! Чем могу помочь?               │   │
│  │          │                                          │   │
│  │ Новый чат│  ┌──────────────────────────────────┐   │   │
│  │          │  │ Введите сообщение...             │   │   │
│  │ Чат 1    │  │ [📎] [🎙️] [➤]                   │   │   │
│  │ Чат 2    │  └──────────────────────────────────┘   │   │
│  │ ...      │                                          │   │
│  ├──────────┤  ⚙️ Настройки (вверху справа)            │   │
│  │ 🧠 Модели│    • Выбор модели                        │   │
│  │ 📚 Знания│    • System Prompt                       │   │
│  │ ⚙️ Настр.│    • Temperature                         │   │
│  └──────────┴──────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

**Главные элементы:**
| Элемент | Где | Зачем |
|---------|-----|-------|
| **Новый чат** | Слева, кнопка | Начать новый разговор |
| **История чатов** | Слева, список | Вернуться к старым диалогам |
| **Поле ввода** | Внизу | Писать запросы |
| **Скрепка 📎** | В поле ввода | Прикрепить файл |
| **Модель** | Вверху | Выбрать, какая ИИ-модель отвечает |
| **Настройки** | Вверху справа | Тонкие настройки ответов |

### Первый запрос — что попробовать прямо сейчас

**Шаг 1:** Нажмите «Новый чат»
**Шаг 2:** Напишите что-то простое:

```
Привет! Чем ты можешь мне помочь в работе?
```

ИИ ответит списком возможностей. Это ваша отправная точка.

**Шаг 3:** Попробуйте простые задачи:

```
Напиши черновик письма клиенту: "Мы получили ваш запрос, 
ответим в течение 2 рабочих дней"
```

```
Переведи на английский: "В приложении к письму направляем 
актуальный прайс-лист"
```

```
Перепиши это короче: "В связи с поступлением большого 
количества обращений от наших клиентов..." (макс 2 предложения)
```

```
Дай 5 идей для заголовка статьи про цифровизацию закупок
```

**Шаг 4:** Не бойтесь экспериментировать. Неправильных запросов нет — есть просто разные результаты.

**Проверка:** У всех получилось? Есть ответы? Отлично — вы уже используете ИИ.

## Урок 0.2: Ежедневные задачи — как ИИ экономит время

### Утро: планирование и приоритеты

**Сценарий:** У вас 10 задач, нужно понять, с чего начать.

```
Я — [должность]. Сегодня у меня:
- согласовать КП от поставщика
- проверить договор
- подготовить отчет за месяц
- ответить на 5 писем
- созвон с производством в 14:00
- срочно: клиент жалуется на брак

Помоги расставить приоритеты и составить план дня.
```

**Результат:** ИИ расставит приоритеты (срочное/важное) и предложит порядок действий.

### В течение дня: переписать, сократить, проверить

**Сделать текст короче:**
```
Сократи до 2 предложений: "[вставьте длинный текст]"
```

**Сделать текст длиннее/подробнее:**
```
Раскрой этот тезис подробнее: "[вставьте короткий тезис]"
```

**Проверить на ошибки:**
```
Проверь этот текст на грамматические и стилистические ошибки. 
Исправь и объясни, что поменял.

[вставьте текст]
```

**Изменить тон:**
```
Перепиши этот текст более мягко / более формально / 
более убедительно:

[вставьте текст]
```

**Перевод:**
```
Переведи на английский / китайский:
[вставьте текст]
```

### Вечер: саммари и планы

**Саммари встречи (вы записали тезисно):**
```
Составь протокол встречи из моих заметок:
- обсудили поставку кабеля, срок сдвинули на неделю
- производство просит ускорить монтаж
- финансы одобрили бюджет
- следующая встреча — в пятницу

Формат: дата, участники, решения, ответственные, сроки.
```

**План на завтра:**
```
На основе моих задач на сегодня, что не успел, 
и календаря на завтра — составь план на завтра.
```

### Примеры по департаментам

**Закупки:**
```
Напиши запрос поставщику: "Уточните сроки поставки 
позиций 3 и 7 из нашего заказа №12345. 
Нам нужно до 15 июля."
```

**Производство:**
```
Составь описание инцидента по моим заметкам: 
станок №3 остановился в 10:30, ошибка E-45, 
оператор Петров, вызван механик Иванов.
```

**Финансы:**
```
Объясни простым языком: почему отклонение по ФОТ 
составило 15%? Как это объяснить директору?
```

**HR:**
```
Напиши текст объявления о вакансии менеджера по закупкам. 
Требования: опыт 3+ года, знание SAP, готовность к командировкам.
```

**Юристы:**
```
Перепиши этот пункт договора понятным языком 
(без юридического жаргона):
"В случае нарушения сроков поставки..."
```

**Качество / Продажи:**
```
Составь чек-лист для аудита склада готовой продукции. 
10 пунктов, проверяемо.
```

### Live Demo (10 мин)

Инструктор демонстрирует 3 сценария:
1. Утро: расстановка приоритетов
2. День: сократить длинное письмо до 3 предложений
3. Вечер: саммари встречи из тезисов

### Практика (10 мин)

**Задание:** Выберите 2 задачи из вашей реальной работы и попробуйте решить их через ИИ.

**Шаблон:**
```
Я — [должность]. Мне нужно: [опишите задачу].
Контекст: [2-3 предложения о ситуации].
```

**Примеры для старта:**
- «Составь ответ на это письмо...»
- «Перепиши этот текст понятнее...»
- «Дай 3 варианта заголовка для...»
- «Проверь, есть ли ошибки в...»

## Урок 0.3: Фишки OpenWebUI — все возможности

### 1. Загрузка файлов (кнопка скрепки 📎)

**Как:** В поле ввода нажмите 📎 → выберите файл → задайте вопрос.

**Что можно загружать:**
- PDF (текстовые — лучше всего)
- Word (.docx)
- Excel (.xlsx) — но лучше экспортировать в PDF
- Изображения (для описания, OCR)

**Пример:**
```
[Загрузить PDF договора]

Прочитай этот договор и выдели:
1. Сроки поставки
2. Условия оплаты
3. Штрафы за просрочку
4. Порядок расторжения

Формат: таблица.
```

> 💡 **Лайфхак:** Для файлов до 50 страниц загружайте прямо в чат — это надёжнее, чем Knowledge Base.

### 2. Knowledge Base (База знаний)

**Зачем:** Хранить часто используемые документы и справочники.

**Как:**
```
Workspace (вверху) → Knowledge → New Knowledge
→ Назовите (например, "Регламенты закупок")
→ Загрузите файлы (PDF, Word)
→ Сохраните
```

**Как использовать:**
```
В чате: @Регламенты_закупок 
Вопрос: "Какой порог суммы для тендера?"
```

> ⚠️ **Важно:** Knowledge Base работает через RAG (модель видит только части документа). Для важных цифр загружайте файл прямо в чат.

### 3. System Prompt (Системный промпт)

**Зачем:** Настроить ассистента под ваш стиль и задачи.

**Как:**
```
Workspace → Models → Выберите модель → Edit (карандаш)
→ System Prompt → вставьте описание → Save
```

**Пример для закупщика:**
```
Ты — ассистент директора по закупкам. 
Всегда отвечай: таблица → риски → рекомендация. 
Отвечай на русском.
```

**Пример для юриста:**
```
Ты — корпоративный юрист. 
При анализе договоров: 1) топ-риски 2) отсутствующие условия 3) готовые формулировки. 
Ссылайся на пункты.
```

**Результат:** Каждый раз, когда вы пишете в чат, ИИ работает в этой роли.

### 4. Шаблоны промптов (/ в чате)

**Зачем:** Не набирать длинные запросы каждый раз.

**Как сохранить:**
```
1. Напишите хороший промпт, получите ответ
2. В поле ввода наберите / → Create Prompt
3. Дайте название: «Анализ КП"
4. Вставьте текст промпта
5. Сохраните
```

**Как использовать:**
```
В любом чате наберите / → выберите «Анализ КП» → 
промпт подставится автоматически
```

**Примеры шаблонов для разных департаментов:**

| Департамент | Название шаблона | Что делает |
|-------------|------------------|------------|
| Закупки | /анализ_КП | Сравнивает 3 КП по цене, срокам, рискам |
| Юристы | /проверка_договора | Находит топ-5 рисков |
| Производство | /разбор_инцидента | 5Why или Ishikawa |
| HR | /описание_вакансии | Генерирует текст вакансии |
| Финансы | /объясни_цифру | Объясняет отклонение простым языком |
| Качество | /чек_лист_аудита | Создает чек-лист по стандарту |

### 5. Переключение моделей

**Если доступно несколько моделей:**
```
Вверху чата → выпадающий список моделей
```

| Модель | Когда использовать |
|--------|-------------------|
| **Llama 3 / Mistral** | Общие задачи, тексты, анализ |
| **Qwen-VL** | Работа с изображениями, OCR, чертежи |
| **DeepSeek / Qwen** | Математика, код, логика |

### 6. Настройки генерации (для продвинутых)

```
Настройки (вверху справа) → Controls
```

| Параметр | Что делает | Рекомендация |
|----------|-----------|--------------|
| **Temperature** | Творчество (0 = строго, 1 = креативно) | Для документов: 0.1-0.2. Для идей: 0.7-0.9 |
| **Max Tokens** | Максимальная длина ответа | 2000-4000 для большинства задач |
| **Top P** | Разнообразие ответов | Оставьте по умолчанию (0.9) |

> 💡 **Правило:** Если ИИ выдумывает факты — понизьте Temperature до 0.1.

### 7. История чатов

- **Слева** — список всех ваших чатов
- **Нажмите на чат** — продолжите разговор
- **Удалите чат** — если больше не нужен
- **Переименуйте** — чтобы не путать (клик по названию)

### Live Demo (10 мин)

Инструктор демонстрирует все 7 фишек:
1. Загрузка PDF и вопрос по нему
2. Создание Knowledge Base
3. Настройка System Prompt
4. Создание и использование шаблона (/)
5. Переключение моделей
6. Изменение Temperature
7. Работа с историей чатов

### Практика (10 мин)

**Задание — мини-квест:**
1. Загрузите любой рабочий документ (PDF или Word) через скрепку
2. Задайте вопрос по документу
3. Создайте System Prompt для своей роли (3-4 предложения)
4. Сохраните 1 шаблон (/ → Create) с частым запросом
5. Проверьте, что шаблон работает

## Урок 0.4: Как писать запросы, чтобы получать отличные ответы

### Почему "проверь договор" = плохой запрос

```
❌ «Проверь этот договор»
→ ИИ не знает: ты юрист или закупщик?
→ Не знает: что искать — риски, сроки, цены?
→ Не знает: для кого результат?
→ Ответ: общий, бесполезный шаблон

✅ «Ты — юрист. Найди топ-5 рисков 
для покупателя в этом договоре. Формат: таблица»
→ Роль задана → нужный стиль и глубина
→ Задача конкретна → фокус на рисках
→ Формат указан → готовый рабочий материал
```

### Формула РКЗФО (простая версия)

| Элемент | Что написать | Пример |
|---------|--------------|--------|
| **РОЛЬ** | Кто ты? | «Ты — аналитик закупок» |
| **КОНТЕКСТ** | О чём речь? | «Алюминиевый завод, тендер на ₽50М» |
| **ЗАДАЧА** | Что сделать? | «Сравни 3 КП по цене и срокам» |
| **ФОРМАТ** | Как оформить? | «Таблица + рекомендация» |
| **ОГРАНИЧЕНИЯ** | Чего не делать? | «Не более 200 слов. Только факты» |

> 💡 **Начни с РОЛИ — это одно слово повышает качество на 50%.**

### Примеры: плохо → хорошо

**Закупки:**
```
❌ «Сравни поставщиков»
✅ «Ты — аналитик закупок. Сравни 3 КП на поставку катодных блоков 
по цене, срокам, гарантии. Таблица + рекомендация. Только факты из КП."
```

**Юристы:**
```
❌ «Проверь риски»
✅ «Ты — корпоративный юрист. В договоре_поставки.pdf найди 
топ-3 риска для покупателя. Для каждого — номер пункта."
```

**Производство:**
```
❌ «Разберись с инцидентом»
✅ «Ты — эксперт по надёжности оборудования. Проведи разбор 
инцидента со станком №3 методом 5Why. Дерево причин + меры."
```

### Eval — как проверить качество ответа

**4 вопроса, которые улучшают любой ответ:**

1. **Самооценка:** «Оцени свой ответ 1–10. Что можно улучшить?»
2. **Пробел:** «Что важного ты не учёл?»
3. **Критик:** «Найди 3 слабых места в своём ответе»
4. **Альтернатива:** «Предложи другой подход»

**Когда использовать:** Для важных документов, смет, договоров, решений.

**Пример Eval:**
```
[После ответа ИИ]

Оцени свой ответ 1–10. 
Что ты не учёл из моего контекста? 
Есть ли риски, которые ты пропустил?
```

### Live Demo (10 мин)

Инструктор демонстрирует:
1. Плохой запрос → слабый ответ
2. Тот же запрос + РОЛЬ → лучше
3. Тот же запрос + РКЗФО → отличный ответ
4. Добавляем Eval → ещё лучше

### Практика (10 мин)

**Задание:** Перепишите 3 плохих запроса в хорошие.

**Плохие запросы (исходные):**
1. «Напиши письмо клиенту»
2. «Проверь смету»
3. «Дай идеи для поста»

**Ваша задача:** Добавить РОЛЬ, КОНТЕКСТ, ЗАДАЧУ, ФОРМАТ, ОГРАНИЧЕНИЯ.

**Шаблон для переписывания:**
```
РОЛЬ: Ты — [кто?]
КОНТЕКСТ: [о чём? ситуация?]
ЗАДАЧА: [что именно сделать?]
ФОРМАТ: [таблица / список / текст / письмо]
ОГРАНИЧЕНИЯ: [не более N слов / только факты / без предположений]
```
