# Модуль 1: PR / Дирекция по связям с общественностью

> **Источник:** Драфт-презентация + адаптация для 4 направлений.
> **Цель:** Перевести PR-специалистов на уровень 3 (продвинутый пользователь). Научить генерировать пресс-релизы, анализировать тональность, создавать контент для соцсетей с использованием on-premise AI.

## Урок 1.1: Генерация пресс-релизов и нарративов

### Цель
Научиться генерировать и редактировать пресс-релизы, которые невозможно отличить от человеческих. Использовать формулу РКЗФО + Eval.

### Теория (15 мин)

**Структура пресс-релиза (по стандарту):**
1. Заголовок — привлекает внимание, содержит суть
2. Лид (1-й абзац) — отвечает на 5W1H (кто, что, где, когда, почему, как)
3. Цитата — от руководителя, добавляет авторитет
4. Детали — факты, цифры, контекст
5. Закрытие — призыв к действию, контакты

**Проблема AI-генерации:**
- Модель выдумывает цитаты, даты, факты
- Тон может быть неподходящим (слишком рекламный или формальный)
- Нет понимания специфики аудитории (СМИ vs инвесторы vs жители)

**Решение — РКЗФО + Eval:**

| Элемент | Зачем для PR |
|---------|---------------|
| **РОЛЬ** | «Ты — PR-директор строительной компании с 10-летним стажем» → стиль, глубина, нетворкинг |
| **КОНТЕКСТ** | «Компания X, запуск жилого комплекса Y, аудитория — деловые СМИ» → тон, фокус |
| **ЗАДАЧА** | «Напиши пресс-релиз, 300 слов, заголовок с цифрой, цитата директора по проектам» |
| **ФОРМАТ** | «Стандартный пресс-релиз: заголовок, лид, 3 абзаца, цитата, контакты» |
| **ОГРАНИЧЕНИЯ** | «Только подтвержденные факты. Если цитаты нет — напиши [ЦИТАТА УТОЧНИТЬ]» |

**Eval для пресс-релиза:**
1. «Оцени ответ 1–10: насколько этот пресс-релиз отличается от шаблонного?»
2. «Что важного я не указал в контексте, что повлияло бы на тон?»
3. «Найди 3 слабых места: где могут быть выдуманные факты?»
4. «Предложи другой угол: как бы написал журналист, а не PR-директор?»

### Live Demo (15 мин)

**Сценарий:** Запуск очередного этапа строительства жилого комплекса.

**Промпт v1 (плохой):**
> «Напиши пресс-релиз о запуске этапа строительства»

**Промпт v2 (хороший, РКЗФО):**
> «Ты — PR-директор строительной компании «СтройГрад» с 10-летним стажем. 
> Контекст: Запуск 3-й очереди ЖК «Речной» (15 этажей, 240 квартир). Дата: 15 июля 2026. 
> Аудитория: деловые СМИ (Строительная газета, Девелопмент Дайджест). 
> Задача: Напиши пресс-релиз, 300-400 слов. Заголовок с цифрой. 
> Цитата директора по проектам [ИМЯ УТОЧНИТЬ]. Формат: заголовок, лид, 3 абзаца, цитата, контакты. 
> Ограничения: Только подтвержденные факты. Если дата или цитата неизвестны — напиши [УТОЧНИТЬ]. 
> Не указывай конкретные сроки сдачи без подтверждения.»

**Промпт v3 (с Eval):**
> [после ответа v2] «Оцени этот пресс-релиз 1–10. 
> Что я не указал в контексте, что изменило бы тон? 
> Найди 3 места, где могут быть выдуманные факты. 
> Перепиши заголовок в стиле журналиста, а не PR-директора.»

### Hands-on (20 мин)

**Задание:** Написать пресс-релиз по реальному событию компании (или учебному кейсу).

**Шаблон задания:**
```
РОЛЬ: Ты — PR-директор [название компании]. Стаж 10+ лет в строительном PR.
КОНТЕКСТ: [Событие: запуск/завершение/награда/инцидент]. 
          Дата: [ДД.ММ.ГГГГ]. Место: [город].
          Аудитория: [СМИ / инвесторы / жители / регуляторы].
ЗАДАЧА: Напиши пресс-релиз, 300-400 слов. 
        Заголовок с цифрой или фактом.
        Цитата [должность, имя или УТОЧНИТЬ].
ФОРМАТ: Стандартный пресс-релиз (заголовок, лид, 3 абзаца, цитата, контакты).
ОГРАНИЧЕНИЯ: Только подтвержденные факты. 
             Неизвестные даты/имена → [УТОЧНИТЬ].
             Не указывать сроки сдачи без подтверждения.
             Не критиковать конкурентов.
```

**Проверка (чек-лист):**
- [ ] Заголовок привлекает внимание (цифра, факт, контраст)?
- [ ] Лид отвечает на 5W1H (кто, что, где, когда, почему)?
- [ ] Цитата звучит естественно (не шаблонно)?
- [ ] Нет выдуманных фактов (все даты/имена проверены)?
- [ ] Контакты и дата указаны?
- [ ] Тон соответствует аудитории (СМИ = факты, жители = эмоции)?
- [ ] Eval пройден: оценка ≥ 7/10, слабые места найдены?

## Урок 1.2: Анализ тональности и кризисные коммуникации

### Цель
Научиться использовать AI для мониторинга СМИ, анализа тональности и подготовки ответов в кризисах. Скорость + точность.

### Теория (15 мин)

**Тональность:**
- Позитивная (упоминание достижений, наград)
- Негативная (жалобы, инциденты, задержки)
- Нейтральная (информационные, фактические)
- Смешанная (есть и позитив, и негатив)

**Аспектный анализ (что именно критикуют/хвалят):**
- Сроки (задержки, досрочная сдача)
- Качество (дефекты, премии)
- Цена (дорого, акции, рассрочка)
- Коммуникация (ответы, прозрачность)
- Безопасность (инциденты, нарушения)

**Кризисный PR — правила:**
1. Скорость: первый ответ в течение 1 часа (даже если «разбираемся»)
2. Факты: только подтвержденное, нет домыслов
3. Эмпатия: признать эмоцию, даже если не виноваты
4. Действие: что уже сделано, что будет сделано
5. Канал: туда, где кризис (соцсети → отвечать в соцсетях, СМИ → пресс-релиз)

**AI в кризисе:**
- Генерает 3 версии ответа: формальная, эмпатичная, юмористическая
- Анализирует 100+ комментариев за 2 минуты
- Но: **человек утверждает**, AI не публикует сам

### Live Demo (15 мин)

**Сценарий:** Негативный комментарий в Telegram-канале жильцов:
> «Снова задержка! Обещали сдать в июне, уже июль — тишина. Застройщик врет как дышит. Кто-нибудь знает реальные сроки?»

**Промпт (анализ):**
> «Ты — PR-аналитик. Проанализируй комментарий:
> - Тональность (позитив/негатив/нейтральный, шкала 0-10)
> - Аспект (что критикуется: сроки/качество/коммуникация/другое)
> - Эмоция (гнев/страх/разочарование/тревога)
> - Инфоповод (есть ли факт или только эмоция?)
> - Формат: таблица»

**Промпт (ответы, 3 версии):**
> «Ты — PR-директор. Напиши 3 версии ответа на комментарий. 
> Версия 1: Формальная (факты, официальный тон). 
> Версия 2: Эмпатичная (признать эмоцию, объяснить, пообещать). 
> Версия 3: Юмористическая (снижение градуса, осторожно). 
> Ограничения: Максимум 3 предложения. Не оправдываться. Не обещать конкретные сроки без подтверждения.»

**Eval:**
> «Оцени каждую версию 1–10. Какая меньше всего разожжет конфликт? Какая выглядит наиболее искренней? Что важного я не учел в контексте?»

### Hands-on (20 мин)

**Задание:** Проанализировать 5 комментариев и написать ответы.

**Комментарии (учебные):**
1. «ЖК Речной — супер! Вид на реку, парк рядом, детская площадка огонь. Рекомендую!»
2. «Опять шум от стройки в 7 утра! Выходные же! Куда жаловаться?»
3. «Купил квартиру в декабре, обещали ключи в марте. Уже июль — тишина. Судиться буду.»
4. «Кто-нибудь знает, когда школу построят? В рекламе было «рядом», а по факту 2 км.»
5. «Спасибо за прозрачность! Еженедельные отчеты в Telegram — это то, что отличает от других застройщиков.»

**Промпт:**
> «Ты — PR-аналитик. Проанализируй 5 комментариев:
> 
> [вставить комментарии]
> 
> Для каждого:
> 1. Тональность (0-10, шкала негатив→позитив)
> 2. Аспект (сроки/качество/коммуникация/цена/безопасность/другое)
> 3. Эмоция (гнев/страх/разочарование/радость/благодарность/тревога)
> 4. Инфоповод (факт или эмоция?)
> 5. Требует ответа? (да/нет, приоритет 1-5)
> 
> Для каждого негативного (приоритет 1-3):
> - Напиши ответ (2-3 предложения)
> - Тон: эмпатия + факт + действие
> - Пример: «Понимаем ваше беспокойство. По ЖК Речной работы идут по графику, статус обновляем еженедельно в Telegram. Последний отчет: [дата].»
> 
> Формат: Таблица (комментарий, тональность, аспект, эмоция, приоритет, ответ)»

**Проверка (чек-лист):**
- [ ] Все 5 комментариев проанализированы
- [ ] Тональность оценена по шкале 0-10
- [ ] Аспект определен верно (сроки/качество/коммуникация)
- [ ] Для негативных написаны ответы (2-3 предложения)
- [ ] Ответы содержат: эмпатию + факт + действие
- [ ] Нет обещаний конкретных сроков без подтверждения
- [ ] Тон соответствует каналу (Telegram = неформальный, СМИ = формальный)
- [ ] Eval: оценка качества ответов ≥ 7/10

## Урок 1.3: Создание контента для соцсетей с AI

### Цель
Автоматизировать создание контента для разных площадок без потери бренд-голоса. Генерация постов, каруселей, сторис, reels.

### Теория (15 мин)

**Форматы контента:**
- Пост (текст + 1-3 картинки)
- Карусель (3-10 слайдов с текстом)
- Сторис (15 сек, вертикальное видео/картинка)
- Reels (30-60 сек, видео)

**Платформы и тон:**
| Платформа | Тон | Длина | Особенности |
|-----------|-----|-------|-------------|
| **VK** | Разговорный, можно длиннее | 300-500 слов | Подробные посты, опросы, статьи |
| **Telegram** | Лаконичный, информативный | 100-200 слов | Быстрое чтение, ссылки, кнопки |
| **Дзен** | SEO-ориентированный | 500-1000 слов | Ключевые слова, заголовки с цифрами |
| **YouTube** | Визуальный, сторителлинг | Скрипт 2-3 мин | Хук в первые 5 секунд |

**Бренд-голос:**
- Тон (формальный / дружелюбный / технический / вдохновляющий)
- Запретные темы (цены, конкуренты, политика)
- Обязательные элементы (логотип, хэштеги, призыв)

**AI + дизайн:**
- Текст: Llama 3 / Mistral
- Картинки: Stable Diffusion (on-premise) или Kandinsky
- Видео: пока AI не генерирует качественно — только скрипты и идеи

### Live Demo (15 мин)

**Сценарий:** Завершение этапа строительства (монолит 15-этажного дома).

**Промпт (VK):**
> «Ты — SMM-менеджер строительной компании. 
> Контекст: Завершен монолит 15-этажного дома ЖК «Речной». 
> Платформа: VK. Аудитория: потенциальные покупатели (25-45 лет, семьи). 
> Тон: дружелюбный, вдохновляющий, с фактами. 
> Задача: Пост 300-400 слов. Заголовок с цифрой. 
> Формат: Хук → факты → эмоция → призыв. 
> Ограничения: Не указывать цены. Не упоминать конкурентов. 
> Хэштеги: #жкречной #стройград #новостройки [город]»

**Промпт (Telegram — тот же контент, короче):**
> «...Задача: Пост 100-150 слов. Тезисы + факты. 
> Ссылка на полный пост в VK. 
> Кнопки: «Узнать планировки» | «Записаться на просмотр»»

**Промпт (карусель — 5 слайдов):**
> «...Задача: Скрипт карусели 5 слайдов. 
> Слайд 1: Хук (заголовок + картинка)
> Слайд 2: Факт 1 (что сделано)
> Слайд 3: Факт 2 (что дальше)
> Слайд 4: Эмоция (как жить в этом доме)
> Слайд 5: Призыв + контакты
> Формат: Текст для каждого слайда + описание картинки для дизайнера»

### Hands-on (20 мин)

**Задание:** Создать контент-план на неделю для одной платформы.

**Промпт:**
> «Ты — SMM-менеджер строительной компании «СтройГрад». 
> Контекст: ЖК «Речной», 15 этажей, 240 квартир, строительство идет. 
> Платформа: [VK / Telegram / Дзен]
> Постов в день: 2 (утро 9:00 + вечер 19:00)
> Темы: прогресс строительства, интервью с бригадой, 
>        лайфхаки для жильцов, FAQ, закулисье стройки, 
>        экскурсия по планировкам, отзывы покупателей
> Запреты: нет цен, нет конкретных сроков сдачи, 
>          нет критики конкурентов, нет политики
> Формат: Таблица (день, время, тема, формат, текст поста, 
>         хэштеги, примечание для дизайнера)
> 
> Дополнительно:
> - Для каждого поста: текст готов к публикации (не черновик)
> - Для 3 постов: промпт для генерации картинки (Stable Diffusion)
> - Для 1 поста: скрипт для reels (30 сек)
> - Оптимальное время публикации для платформы [VK/Telegram/Дзен]»

**Проверка (чек-лист):**
- [ ] Контент-план на 7 дней (14 постов)
- [ ] Все посты готовы к публикации (не черновики)
- [ ] Темы разнообразны (не только «стройка идет»)
- [ ] Запреты соблюдены (нет цен, сроков, конкурентов)
- [ ] Хэштеги подобраны для платформы
- [ ] 3 промпта для картинок (Stable Diffusion)
- [ ] 1 скрипт для reels (30 сек, хук в первые 5 сек)
- [ ] Eval: оценка разнообразия ≥ 7/10, нет повторов?

## Системный промпт для PR-отдела (готовый шаблон)

```
Ты — PR-директор строительной компании «СтройГрад» с 10-летним стажем.
Специализация: корпоративные коммуникации, кризисный PR, SMM.

ПРАВИЛА:
1. Всегда пиши фактами. Неизвестные даты/имена → [УТОЧНИТЬ].
2. Не указывай конкретные сроки сдачи без подтверждения.
3. Не критикуй конкурентов. Не упоминай политику.
4. Цитаты руководителей: только если подтверждены. 
   Иначе: [ЦИТАТА УТОЧНИТЬ].
5. Тон: деловой для СМИ, дружелюбный для соцсетей.

ФОРМАТ ПРЕСС-РЕЛИЗА:
- Заголовок: с цифрой или фактом, привлекает внимание
- Лид: 5W1H (кто, что, где, когда, почему)
- 3 абзаца: детали, факты, контекст
- Цитата: [УТОЧНИТЬ] или подтвержденная
- Контакты: пресс-служба, телефон, email

ФОРМАТ ОТВЕТА НА НЕГАТИВ:
- 2-3 предложения
- Эмпатия + факт + действие
- Пример: «Понимаем ваше беспокойство. 
  По [объекту] работы идут по графику. 
  Последний отчет: [дата] в [канал].»

ФОРМАТ ПОСТА (VK):
- Хук (вопрос/факт/контраст)
- 2-3 факта
- Эмоция/призыв
- Хэштеги (3-5 штук)

САМОПРОВЕРКА (eval):
Перед ответом:
- Все ли факты подтверждены?
- Нет ли выдуманных цитат или дат?
- Тон соответствует аудитории?
- Нет запрещенных тем?
```

## AI-Агенты для PR
- **Мониторинг СМИ** — агент сканирует новости, классифицирует по тональности и аспектам
- **Генератор отчетов** — еженедельный дайджест упоминаний (таблица + тренды)
- **Алертер** — уведомление о кризисных упоминаниях (топ 10% негатива)
- **Контент-агент** — генерирует посты по расписанию, курирует человек
- **Аналитик** — анализ эффективности постов (охваты, вовлеченность, тональность)

## Практические кейсы для домашней работы

1. **Пресс-релиз:** Написать пресс-релиз о реальном событии компании (или учебном кейсе). Пройти 3 итерации с Eval.
