# Модуль 1: PR / Дирекция по связям с общественностью

## Специфика направления
- **Задачи:** пресс-релизы, нарративы, анализ тональности, кризисные коммуникации, соцсети
- **AI-модели:** текстовые (LLM), анализ тональности, генерация изображений
- **Агенты:** мониторинг СМИ, генерация отчетов, оповещения

---

## Урок 1.1: Генерация пресс-релизов и нарративов

### Цель
Научиться генерировать и редактировать пресс-релизы, которые невозможно отличить от человеческих.

### Теория (15 мин)
1. **Структура пресс-релиза** — заголовок, лид, цитаты, закрытие
2. **Нарратив** — какая история, почему важна, кому интересна
3. **Промпт для пресс-релиза** — шаблон RICE
4. **Итеративное редактирование** — 3 версии, улучшение
5. **Проверка фактов** — что AI может выдумать

### Live Demo (15 мин)
- Генерация пресс-релиза о запуске объекта
- Сравнение: промпт v1 vs v2 vs v3
- Добавление цитат и контекста

### Hands-on (20 мин)
**Задание:** Написать пресс-релиз о [реальном событии компании]

**Промпт-шаблон:**
```
Роль: Ты — PR-директор строительной компании.
Задача: Напиши пресс-релиз о [событие].
Контекст: 
- Компания: [название]
- Событие: [описание]
- Аудитория: [СМИ / инвесторы / жители]
- Тон: [формальный / дружелюбный / технический]
- Объем: 300-400 слов
- Обязательно: цитата руководителя, дата, контакты

Формат: Стандартный пресс-релиз (заголовок, лид, 3 абзаца, цитата, закрытие)
```

**Проверка:**
- [ ] Заголовок привлекает внимание?
- [ ] Лид отвечает на 5W1H?
- [ ] Цитата звучит естественно?
- [ ] Нет выдуманных фактов?
- [ ] Контакты и дата указаны?

### Чек-лист
- [ ] Написан 1 полноценный пресс-релиз
- [ ] Пройдена итерация улучшения (3 версии)
- [ ] Проверены факты вручную

## Урок 1.2: Анализ тональности и кризисные коммуникации

### Цель
Научиться использовать AI для мониторинга и реагирования в кризисах.

### Теория
1. **Тональность** — позитивная, негативная, нейтральная, смешанная
2. **Аспектный анализ** — что именно критикуют/хвалят
3. **Кризисный PR** — скорость vs точность
4. **Правила:** AI генерирует драфт, человек утверждает
5. **Не поддаваться эмоциям** — AI помогает сохранять нейтралитет

### Live Demo
- Анализ 10 комментариев с новостного сайта
- Классификация по тональности и аспектам
- Генерация ответа на негативный комментарий
- 3 версии ответа: формальный, эмпатичный, юмористический

### Hands-on
**Задание:** Проанализировать 5 реальных комментариев и написать ответы

**Промпт:**
```
Роль: Ты — PR-специалист строительной компании.
Задача: Проанализируй комментарии и напиши ответы.

Комментарии:
1. [вставить текст]
2. [вставить текст]
...

Требования:
- Определи тональность каждого (позитив/негатив/нейтраль)
- Определи аспект (что критикуют: сроки, качество, цена, коммуникация)
- Напиши ответ на каждый негативный
- Ответ: максимум 3 предложения, эмпатия + факт + действие
- Пример: "Понимаем ваше беспокойство. В этом районе работы завершены [дата]. Статус: [ссылка]"
```

### Чек-лист
- [ ] Проанализировано 5+ сообщений
- [ ] Написаны ответы с соблюдением тональности
- [ ] Ответы проверены руководителем

## Урок 1.3: Создание контента для соцсетей с AI

### Цель
Автоматизировать создание контента для разных площадок без потери бренд-голоса.

### Теория
1. **Форматы:** пост, карусель, сторис, reels-скрипт
2. **Платформы:** VK, Telegram, Дзен, Rutube, YouTube
3. **Бренд-голос** — тон, стиль, запретные темы
4. **Контент-план** — AI генерирует, человек курирует
5. **Визуалы** — генерация изображений (Stable Diffusion on-premise)

### Live Demo
- Генерация поста про завершение этапа строительства
- Адаптация под VK (длинный), Telegram (краткий), Дзен (SEO)
- Генерация промпта для изображения
- Создание контент-плана на неделю

### Hands-on
**Задание:** Создать контент-план на неделю

**Промпт:**
```
Роль: Ты — SMM-менеджер строительной компании.
Задача: Создай контент-план на неделю.

Контекст:
- Компания: [название]
- Площадки: VK, Telegram
- Постов в день: 2 (утро + вечер)
- Темы: прогресс строительства, интервью с бригадой, 
         лайфхаки для жильцов, FAQ, закулисье
- Запреты: нет цен, нет конкретных сроков сдачи, нет критики конкурентов
- Формат: таблица (день, платформа, тема, формат, текст, примечание)

Дополнительно:
- Для каждого поста напиши полный текст
- Сгенерируй промпт для изображения (для Stable Diffusion)
- Определи лучшее время публикации
```

### Чек-лист
- [ ] Контент-план на 7 дней
- [ ] 14 готовых постов
- [ ] 7 промптов для изображений
- [ ] Проверка на соответствие бренд-голосу
