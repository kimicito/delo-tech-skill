## Урок 2.1: Автоматизация смет (ВОР → AI → Смета)

### Цель
Научиться использовать AI для проверки смет, расчета по ФЕР-2020/БИМ, поиска ошибок.

### Теория (15 мин)
1. **ВОР как единственный вход** — все начинается с Ведомости объемов работ
2. **drawings-to-vor pipeline** — TIFF → OCR → ВОР → Review
3. **Проверка сметы** — AI находит ошибки, которые человек пропускает
4. **БИМ-методика** — разделение по статьям: ОТ, ЭМ, М, ЗПМ, ТЗ
5. **НР и СП** — от ФОТ, не от прямых затрат (121% vs 15%)
6. **Коэффициенты** — П.58 пр.б, Прил.10 т.5 п.1.2 и другие
7. **ФССЦ** — материалы отдельно от монтажных расценок

### Live Demo (15 мин)
- Проверка сметы на ошибки (загрузка в чат, анализ)
- Поиск: неверная база НР, пропущенные коэффициенты, общий индекс
- Сравнение: AI-находки vs профессиональный сметчик
- Красная команда — 10% лучших смет vs 10% худших

### Hands-on (20 мин)
**Задание:** Проверить смету на 5 ошибок

**Промпт-шаблон:**
```
Роль: Ты — проверяющий сметчик с 20-летним стажем. 
Знаешь ФЕР-2020, БИМ-методику, приказ 421/пр.

Задача: Проверь смету на критические ошибки.

Критические ошибки (если есть — указать с точностью до строки):
1. Общий индекс вместо раздельных по статьям (ОТ, ЭМ, М)
2. НР/СП от прямых затрат вместо ФОТ
3. Пропущенные коэффициенты условий работ (П.58 пр.б, Прил.10)
4. Материалы внутри расценки вместо ФССЦ
5. Возврат прихода не отражен в ЛКН АУСН

Формат ответа:
- Ошибка: [описание]
- Строка/позиция: [где найдено]
- Коэффициент правильный: [какой должен быть]
- Сумма занижения/завышения: [руб.]

Смета:
[вставить текст сметы или загрузить файл]
```

### Проверка (чек-лист)
- [ ] Найдены все 5 типов ошибок (или подтверждено их отсутствие)
- [ ] Указаны конкретные строки
- [ ] Даны правильные значения
- [ ] Посчитаны суммарные последствия

## Урок 2.2: Анализ чертежей и извлечение данных (ВОР)

### Цель
Научиться извлекать ВОР из чертежей через AI-vision, проверять автоматически.

### Теория
1. **Чертежи в цифру** — TIFF → OCR → ВОР
2. **Qwen-VL-OCR** — специализированная модель для чертежей
3. **Тайлы** — разбиение на 1000×1000, overlap, дедупликация
4. **Типы элементов** — сваи, ростверки, балки, фундаменты, закладные, каркасы
5. **Unified VOR** — работы + материалы + формулы в одной таблице
6. **vor_reviewer** — автоматическая проверка без API
7. **Путь 1 vs Путь 2** — ручное указание планов vs авто-классификация

### Live Demo
- Загрузка TIFF чертежа в систему
- Автоматическая нарезка на тайлы
- OCR через Qwen-VL
- Извлечение ВОР (количества, размеры, формулы)
- Проверка через vor_reviewer
- Сравнение с reference ВОР сметчика

### Hands-on
**Задание:** Извлечь ВОР из чертежа и проверить

**Пошаговый промпт:**
```
Шаг 1: Нарезка
"Нарежь чертеж КЖ5 на тайлы 1000×1000 с overlap 100px"

Шаг 2: OCR
"Проанализируй тайлы через Qwen-VL-OCR. Извлеки:
- Текстовые линии (марки, позиции, обозначения)
- Таблицы (спецификации, ведомости)
- Размеры (длины, диаметры, высоты)"

Шаг 3: Извлечение ВОР
"Из OCR-результата сформируй ВОР:
- Марка: Рсм1, БФм1, ФОм1 и т.д.
- Наименование: описание элемента
- Единица: шт., м³, м², м.п.
- Количество: из чертежа или по формуле
- Размеры: для формул расчета

Формулы:
- Ростверк: ширина × высота × длина = м³
- Фундамент: площадь основания × высота = м³
- Балка: длина (из чертежа) = м.п."

Шаг 4: Проверка
"Запусти vor_reviewer.py:
- Все марки из OCR есть в ВОР?
- Количества > 0?
- Нет дублей?
- Разумные значения?"
```

### Чек-лист
- [ ] Чертеж загружен и нарезан
- [ ] OCR выполнен (Qwen-VL)
- [ ] ВОР сформирована
- [ ] Проверка пройдена (PASS)
- [ ] Сравнение с сметчиком (если есть reference)

### Примеры промптов для разных элементов

**Сваи (буронабивные):**
```
"Извлеки буронабивные сваи из чертежа:
- Марки: СБН-XX-YYYY (серия, номер)
- Диаметр (мм)
- Длина (м)
- Количество (шт)
- Расчет: π × (D/2)² × L × n = м³"
```

**Ростверки:**
```
"Извлеки ростверки:
- Марки: Рсм1, Рсм2 и т.д.
- Ширина (м)
- Высота (м) 
- Длина (м) — суммировать все участки
- Количество (шт)
- Расчет: ширина × высота × длина × n = м³"
```

## Урок 2.3: Планирование и контроль сроков через AI-агенты

### Цель
Автоматизировать планирование, контроль сроков, аналитику отклонений.

### Теория
1. **AI-планировщик** — генерация графиков работ, критический путь
2. **Gantt-диаграммы** — интерактивные, с обновлением в реальном времени
3. **Предиктивная аналитика** — прогноз рисков срыва сроков
4. **Агент-мониторинг** — отслеживание прогресса, алерты
5. **Отчеты** — автоматическая генерация для руководства

### Live Demo
- Создание графика работ из текстового описания
- Автоматический расчет критического пути
- Сценарий: "Задержка поставки бетона на 3 дня" → AI пересчитывает график
- Генерация отчета для директора

### Hands-on
**Задание:** Создать график и проанализировать риски

**Промпт:**
```
Роль: Ты — планировщик строительных работ с опытом 10+ лет.

Задача: Создай график работ и проанализируй риски.

Исходные данные:
- Объект: Монолитный фундамент под жилой дом (15 этажей)
- Этапы: разработка грунта, бурение свай, армирование, 
         бетонирование, обратная засыпка
- Срок: 45 рабочих дней
- Бригады: 2 смены по 8 часов
- Ограничения: нет работ в ночное время, 
               бетонирование только при +5°C и выше

Требования:
1. Создай Gantt-диаграмму (HTML или таблица)
2. Выдели критический путь
3. Укажи резервы времени
4. Опиши 3 главных риска срыва сроков
5. Дай рекомендации по минимизации рисков

Формат: Markdown таблица + текстовый анализ
```

### Расширенное задание (для аналитиков)
**Анализ отклонений:**
```
"Проанализируй отклонения по проекту:
- Плановые сроки vs фактические
- Отклонение по стоимости
- Причины отклонений (по категориям: поставки, погода, ресурсы)
- Тренд: улучшается или ухудшается?
- Прогноз на завершение проекта

Формат: Таблица + график (текстовый ASCII) + выводы"
```

### Чек-лист
- [ ] График создан с критическим путем
- [ ] Риски идентифицированы и ранжированы
- [ ] Рекомендации даны
- [ ] Отчет сгенерирован и проверен
