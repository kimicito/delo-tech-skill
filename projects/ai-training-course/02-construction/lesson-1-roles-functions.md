## Роль 1: Сметчик

### Что делает сметчик
- Составляет сметы по ФЕР/ГЭСН/ТЕР
- Проверяет сметы подрядчиков
- Ведёт учёт выполненных работ (КС-2, КС-3, КС-11)
- Анализирует дополнительные работы (допники)

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Расчёт сметы** | По описанию работ и объёмам — подбирает расценки ФЕР/ГЭСН | Готовая смета с расценками, коэффициентами, итогом |
| **Проверка сметы подрядчика** | Загружает смету подрядчика → сверяет с ФЕР → находит завышения | Таблица: позиция, цена подрядчика, цена по ФЕР, отклонение, риск |
| **Сравнение смет** | Сравнивает 3 варианта: своя, подрядчик А, подрядчик Б | Конкурентный лист с рекомендацией |
| **Анализ допников** | Проверяет обоснованность дополнительных работ: нужны ли они, не включены ли в основную смету | Решение: принять / отклонить / уточнить |
| **Поиск аналогов** | Ищет замену материалам/работам с сохранением качества | Аналоги с ценами и обоснованием |

### Пример запроса (РКЗФО)
```
РОЛЬ: Ты — главный сметчик с 10-летним стажем, сертифицирован по ФЕР-2020.
КОНТЕКСТ: Объект — жилой дом 15 этажей, монолитный каркас, площадь 12 000 м².
ЗАДАЧА: Составить смету на устройство монолитного железобетонного каркаса.
ФОРМАТ: 
  1. Локальная смета (таблица: № п/п, код ФЕР, наименование, ед.изм, количество, цена, итого)
  2. Накладные расходы (%) 
  3. Сметная прибыль (%)
  4. Итого с НДС
ОГРАНИЧЕНИЯ: ФЕР-2020, регион: Москва. Без применения индексов — только базовые цены.
```

## Роль 2: Проектант

### Что делает проектант
- Разрабатывает чертежи и проектную документацию
- Проверяет соответствие СНиП/СП
- Ищет типовые решения
- Рассчитывает конструкции

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Проверка на СНиП/СП** | Загружает проект → проверяет на соответствие актуальным нормам | Список нарушений с указанием пункта нормы |
| **Поиск типовых решений** | По описанию задачи — ищет аналогичные проекты, типовые чертежи | Описание решения + ссылки на типовые серии |
| **Расчёт конструкций** | По исходным данным (нагрузки, пролёты, материалы) — считает армирование, сечения | Расчётная схема + спецификация материалов |
| **Генерация описания** | По чертежу (загруженному как изображение) — генерирует текстовое описание | Техническое описание для пояснительной записки |
| **Проверка пересечений** | Анализирует описание систем (ВК, ОВ, ЭОМ) → находит конфликты | Список пересечений с рекомендациями |

### Пример запроса
```
РОЛЬ: Ты — ведущий проектировщик ЖБК конструкций.
КОНТЕКСТ: Проект 15-этажного жилого дома, монолитный каркас, сейсмичность 8 баллов.
ЗАДАЧА: Проверь проект на соответствие СП 70.13330.2012 и СП 52-101-2003.
ФОРМАТ:
  1. Список проверенных разделов (фундамент, колонны, балки, плиты)
  2. Таблица нарушений (пункт нормы, требование, что в проекте, риск, рекомендация)
  3. Общий вывод (проект принимается / требует доработки / критические нарушения)
ОГРАНИЧЕНИЯ: Только актуальные нормы (2024-2025). Указывай конкретные пункты СП.
```

## Роль 3: Приёмщик работ (ПТО / ОКС)

### Что делает приёмщик работ
- Принимает выполненные работы по актам КС-2, КС-3
- Проверяет соответствие объёмов проекту
- Выявляет недоделки и дефекты
- Формирует замечания

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Проверка актов КС-2** | Загружает акт выполненных работ → сверяет с сметой и проектом | Таблица: позиция, объём по акту, объём по смете, отклонение, вывод |
| **Анализ фото/видео** | Загружает фото объекта → сравнивает с проектом → находит отклонения | Список замечаний с привязкой к фото |
| **Проверка качества** | По описанию работ — проверяет соответствие СНиП на качество | Замечания по качеству (швы, зазоры, геометрия) |
| **Формирование предписаний** | По найденным замечаниям — генерирует текст предписания | Готовое предписание с ссылками на нормы |
| **Сверка скрытых работ** | Проверяет, все ли скрытые работы задокументированы (акты, фото, схемы) | Список пропущенных актов |

### Пример запроса
```
РОЛЬ: Ты — инженер ПТО с опытом приёмки работ в жилищном строительстве.
КОНТЕКСТ: Акт КС-2 за май 2026. Объект — ЖК "Речной", корпус 1. Подрядчик ООО "СтройМонтаж".
ЗАДАЧА: Проверь акт на соответствие проекту и смете.

Данные по акту:
- Устройство монолитных стен подвала: 450 м³ (проект: 420 м³)
- Армирование стен: 28 т (проект: 25 т)
- Гидроизоляция: 850 м² (проект: 900 м²)
- Бетон Б25: 450 м³ (смета: 420 м³, цена 8500 ₽/м³)

ФОРМАТ:
  1. Таблица сверки (позиция, по акту, по проекту, по смете, отклонение, %)
  2. Анализ отклонений (приемлемо / требует уточнения / критично)
  3. Замечания (если объём превышен — есть ли допник? если нет — риск)
  4. Рекомендация (принять / принять с замечаниями / вернуть на доработку)
ОГРАНИЧЕНИЯ: Без допника превышение сметы не допускается. Проверь наличие актов скрытых работ.
```

## Роль 4: Организатор работ (Производитель работ / Начальник участка)

### Что делает организатор
- Планирует график работ (Гантт)
- Распределяет рабочие бригады и технику
- Анализирует критический путь
- Прогнозирует задержки

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **График работ (Гантт)** | По списку работ и объёмам — строит оптимальный график с учётом технологических пауз | Таблица: работа, начало, окончание, длительность, предшественники |
| **Распределение ресурсов** | По графику — рассчитывает потребность в рабочих, технике, материалах | Ресурсная ведомость по неделям |
| **Анализ критического пути** | Определяет работы, которые нельзя задерживать | Список критических работ + запасы времени |
| **Прогноз задержек** | Если задержка на одной работе — считает влияние на весь проект | Новый график + риски срыва сроков |
| **Оптимизация** | Предлагает: что ускорить, где добавить бригады, какие работы параллелить | Рекомендации с расчётом экономии времени |

### Пример запроса
```
РОЛЬ: Ты — начальник участка с 15-летним опытом, специалист по организации строительства.
КОНТЕКСТ: Жилой дом 15 этажей. Начало работ: 1 июня 2026. Срок: 18 месяцев.
ЗАДАЧА: Построй оптимальный график работ.

Этапы:
1. Подготовка (забивка свай, 30 дней)
2. Фундамент (ростверк, 45 дней, после свай)
3. Каркас (монолит, 180 дней, этаж в 12 дней)
4. Кладка (120 дней, после 3-го этажа каркаса)
5. Кровля (60 дней, после каркаса)
6. Фасад (90 дней, параллельно с кровлей)
7. Внутренние сети (120 дней, после кровли)
8. Отделка (90 дней, после сетей)
9. Благоустройство (60 дней, после отделки)

ФОРМАТ:
  1. Таблица Гантт (работа, начало, окончание, длительность, предшественники)
  2. Критический путь (список работ без запаса времени)
  3. Ресурсная ведомость по месяцам (рабочие, бетон, арматура, кирпич)
  4. Точки контроля (когда нужны материалы, когда подавать заявки)
  5. Риски (что может задержать, план Б)
ОГРАНИЧЕНИЯ: Зима — пауза на бетон (декабрь-февраль). Макс 2 бригады на этапе.
```

## Роль 5: Приёмщик документации (Делопроизводитель / Исполнительная документация)

### Что делает приёмщик документации
- Проверяет комплектность исполнительной документации
- Сверяет акты с сметами
- Проверяет соответствие формам (КС-2, КС-3, КС-6, КС-11, общий журнал)
- Готовит дело для сдачи

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Проверка комплектности** | По списку работ — проверяет, все ли акты, схемы, сертификаты собраны | Чек-лист: что есть, чего не хватает |
| **Сверка актов с сметами** | Загружает акт КС-2 и смету → сверяет позиции, объёмы, цены | Таблица расхождений |
| **Проверка форм** | Проверяет, что акты заполнены по форме, все поля заполнены, подписи стоят | Список ошибок в оформлении |
| **Генерация актов** | По данным о выполненных работах — генерирует текст акта КС-2 | Готовый акт по форме |
| **Формирование дела** | По списку документов — формирует опись дела | Опись с разделами и листами |

### Пример запроса
```
РОЛЬ: Ты — инженер по исполнительной документации с 8-летним стажем.
КОНТЕКСТ: Сдача корпуса 1 ЖК "Речной". Исполнительная документация от подрядчика.
ЗАДАЧА: Проверь комплектность документации.

Документы от подрядчика:
- Общий журнал работ (есть)
- Акты КС-2 (12 шт, за период)
- Акты КС-3 (12 шт)
- Схемы скрытых работ (есть)
- Сертификаты на бетон (есть)
- Сертификаты на арматуру (есть)
- Исполнительные схемы (нет)
- Акты освидетельствования скрытых работ (10 из 15)
- КС-6 (нет)
- КС-11 (нет)

ФОРМАТ:
  1. Таблица проверки (документ, статус, замечание)
  2. Чего не хватает (список обязательных документов)
  3. Рекомендация (что требовать у подрядчика до сдачи)
  4. Сроки (сколько времени на доработку)
ОГРАНИЧЕНИЯ: По СНиП и СП 70.13330.2012. Без полного комплекта — сдача невозможна.
```

## Роль 6: Закупщик услуг по работам (Заказчик-застройщик / Договорной отдел)

### Что делает закупщик услуг
- Формирует ТЗ на подрядные работы
- Получает и сравнивает КП подрядчиков
- Анализирует сметы подрядчиков
- Проверяет договоры

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **ТЗ на подрядные работы** | По проекту и смете — формирует техническое задание на выполнение работ | Готовое ТЗ с объёмами, сроками, требованиями |
| **Сравнение КП подрядчиков** | Загружает 3 КП → сводит в единую таблицу → оценивает по критериям | Конкурентный лист с рейтингом |
| **Анализ сметы подрядчика** | Проверяет смету на завышение цен, лишние позиции, ошибки | Отчёт: что завышено, на сколько, рекомендации |
| **Проверка договора** | Анализирует договор подряда на риски, неопределённости, неравные условия | Список рисков + рекомендуемые правки |
| **Анализ графика** | Проверяет предложенный подрядчиком график на реалистичность | Вывод: реалистично / нет, где риски срыва |

### Пример запроса
```
РОЛЬ: Ты — специалист договорного отдела застройщика, 10 лет в тендерах и подрядах.
КОНТЕКСТ: Тендер на генерального подрядчика ЖК "Речной", корпус 1 (15 этажей, 12 000 м²).
ЗАДАЧА: Составить ТЗ на выполнение строительно-монтажных работ.

Исходные данные:
- Проектная документация: есть (ЖБК, кладка, кровля, фасад, инженерия)
- Смета: 850 млн ₽ (в т.ч. НДС 20%)
- Срок: 18 месяцев с момента выдачи ГПЗУ
- Условия: генподряд, подрядчик несёт риски цены и сроков

ФОРМАТ:
  1. Общие положения (объект, заказчик, сроки, условия)
  2. Объём работ (по разделам с указанием объёмов)
  3. Требования к подрядчику (опыт, финансы, персонал, техника)
  4. Требования к качеству (СНиП, контроль, испытания)
  5. График работ (этапы, точки контроля)
  6. Условия оплаты (аванс, этапы, удержания)
  7. Ответственность (штрафы, неустойка, форс-мажор)
  8. Критерии оценки КП (цена 50%, сроки 20%, опыт 15%, качество 15%)
ОГРАНИЧЕНИЯ: Только СМР. Проектирование и авторский надзор — отдельно. Без ПИР.
```

## Роль 7: Строй контроль (Технадзор / ОТК)

### Что делает строй контроль
- Проверяет качество работ на объекте
- Контролирует соответствие проекту
- Выявляет отклонения и дефекты
- Формирует предписания

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ фото/видео** | Загружает фото с объекта → сравнивает с проектом/СНиП | Список замечаний: что нарушено, пункт нормы, серьёзность |
| **Проверка материалов** | По сертификатам и актам — проверяет соответствие марок, классов | Заключение: материалы соответствуют / не соответствуют |
| **Геометрический контроль** | По замерам — проверяет отклонения от проекта (вертикаль, горизонталь, размеры) | Таблица: параметр, проект, факт, допуск, отклонение, вывод |
| **Тепловизионный анализ** | Описывает, как проверить тепловизором (ИИ не видит тепловизор, но знает методику) | Методика + чек-лист контроля |
| **Формирование акта ОТК** | По замечаниям — генерирует акт выявленных дефектов | Готовый акт с классификацией дефектов |

### Пример запроса
```
РОЛЬ: Ты — инженер технадзора, аттестованный по контролю качества ЖБК.
КОНТЕКСТ: Проверка монолитного каркаса 5-го этажа. Подрядчик ООО "МонолитСтрой".
ЗАДАЧА: Проверь качество работ по замерам и фото.

Данные:
- Высота этажа: проект 3.0 м, замер 3.02 м (отклонение +20 мм)
- Толщина плиты перекрытия: проект 220 мм, замеры: 215, 218, 225, 220, 210 мм
- Вертикальность колонн: проект 0 мм, замеры: +5, +8, +3, +12, +6 мм
- Бетон: марка Б25, сертификат есть, акты испытаний: 28.2, 29.1, 27.8 МПа
- Армирование: сетка 150×150, факт: 160×140 мм (замер)
- Фото: видны непролитые участки (пустоты), следы опалубки на бетоне

ФОРМАТ:
  1. Таблица замеров (параметр, проект, факт, допуск СНиП, отклонение, вывод)
  2. Дефекты (описание, серьёзность: критичный/значительный/незначительный, устранение)
  3. Заключение (работы приняты / приняты с замечаниями / не приняты)
  4. Предписание (что устранить, в какие сроки, повторная проверка)
ОГРАНИЧЕНИЯ: СНиП 52-01-2003, СП 70.13330.2012. Бетон ниже 25 МПа — неприемлемо.
```

## Общие функции для всех ролей

### Фишка 1: Загрузка чертежей (📎)
- Сметчик загружает чертёж → ИИ считает объёмы
- Проектант загружает типовой чертёж → ИИ адаптирует под объект
- Технадзор загружает фото → ИИ сравнивает с проектом

### Фишка 2: System Prompt для строительства
```
Ты — ассистент для строительных специалистов. 
Всегда используй таблицы для расчётов.
Структура ответа: анализ → таблица → риски → рекомендация.
Если данных мало — укажи, что нужно уточнить.
Работай по ФЕР-2020, СНиП, СП (актуальные редакции).
```

### Фишка 3: Шаблоны (/)
- `/смета` — шаблон для сметчика
- `/проверка` — шаблон для технадзора
- `/график` — шаблон для организатора работ
- `/акт` — шаблон для ПТО

### Фишка 4: Knowledge Base
- Загрузить ФЕР/ГЭСН — ИИ будет знать расценки
- Загрузить шаблоны актов — ИИ будет оформлять по форме
