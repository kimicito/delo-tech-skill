## Роль 1: Контроль технических средств охраны (СКУД, камеры, периметр)

### Что делает
- Мониторинг систем видеонаблюдения (камеры, архивы, аналитика)
- Контроль периметра (датчики, тревоги, ложные срабатывания)
- СКУД (система контроля и управления доступом): журналы проходов, нарушения режима
- Реагирование на тревожные события
- Проверка маршрутов патрулирования охраны

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ видео** | Загружает записи с камер → находит аномалии, распознаёт людей/объекты/номера | Отчёт: время, место, событие, кадры |
| **Проверка маршрутов патрулирования** | Анализирует журналы → находит пропуски, задержки, необъяснимые остановки | Таблица нарушений маршрута |
| **Контроль периметра** | Анализирует данные датчиков → выявляет ложные/истинные срабатывания | Рекомендация: настройка чувствительности, ремонт |
| **Распознавание лиц и номеров** | Сравнивает с базой разрешённых/запрещённых лиц и автомобилей | Список совпадений с вероятностью |
| **Анализ СКУД** | Проверяет журналы проходов → находит пропуски без пропуска, ночные входы, массовые выходы | Алерты на нарушения режима |
| **Отчёт по инцидентам** | По описанию события — генерирует протокол, акт, заявление в полицию | Готовый документ по форме |

### Пример запроса
```
РОЛЬ: Ты — специалист по контролю технических средств охраны.
КОНТЕКСТ: Складской комплекс, 45 камер, периметр 2.5 км, СКУД на 12 точек.
ЗАДАЧА: Проанализировать журналы за неделю:
- Датчик периметра, сектор 7: 12 срабатываний, все ночью
- Камера К-23: 3 раза пропадал сигнал по 5-7 мин
- СКУД: 2 ночных входа без регистрации охраной
- Патруль охраны: задержка на посту №4 — среднее 12 мин (норма 5)
ФОРМАТ:
  1. Таблица инцидентов (тип, частота, время, зона, риск)
  2. Анализ паттернов (совпадение по времени/зоне)
  3. Рекомендации (что проверить, что усилить)
  4. Приоритет (высокий/средний/низкий)
ОГРАНИЧЕНИЯ: Без рекомендаций по увольнению. Только технические меры.
```

## Роль 2: Изучение кандидатов и стажёров

### Что делает
- Проверка кандидатов при приёме на работу (резюме, биография, соцсети)
- Проверка стажёров на доступ к конфиденциальной информации
- Периодические проверки действующих сотрудников
- Анализ социальных сетей и открытых источников (в рамках закона)
- Контроль конфликта интересов
- Формирование заключений по результатам проверки

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ резюме** | Загружает резюме → проверяет на противоречия, неточности, разрывы в биографии | Отчёт: риски, вопросы для интервью |
| **Проверка соцсетей** | По открытым данным — анализирует профили (если разрешено законом) | Резюме: что нашлось, риски |
| **Сравнение деклараций** | Сравнивает предыдущие и текущие декларации → находит необъяснимые изменения | Таблица расхождений с обоснованием |
| **Проверка связей** | Анализирует связи кандидата с конкурентами, поставщиками | Карта связей, флаги риска |
| **Генерация анкеты** | По требованиям компании — создаёт анкету для проверки | Готовая анкета с вопросами |
| **Формирование заключения** | По собранным данным — пишет структурированное заключение | Готовый документ: рекомендация принять/отклонить/уточнить |

### Пример запроса
```
РОЛЬ: Ты — специалист по изучению кандидатов службы безопасности.
КОНТЕКСТ: Проверка кандидата на должность руководителя закупок.
ЗАДАЧА: Составить план проверки и список рисков.

Данные кандидата:
- Последнее место работы: конкурент (ушёл 3 мес назад)
- Семья: жена — ИП, оказывает консалтинговые услуги
- Недвижимость: квартира 45 м², но автомобиль 2023 г.в. премиум-класса
- Соцсети: активно публикует критику предыдущего работодателя

ФОРМАТ:
  1. Чек-лист проверки (что проверить, где, как)
  2. Выявленные риски (риск, обоснование, критичность)
  3. Вопросы для интервью (по каждому риску)
  4. Рекомендация (принять/отклонить/уточнить)
ОГРАНИЧЕНИЯ: Только законные методы. Без нарушения 152-ФЗ (ПДн).
```

## Роль 3: Проверка контрагентов

### Что делает
- Проверка компаний-поставщиков, партнёров, инвесторов, подрядчиков
- Анализ юридической чистоты (ЕГРЮЛ, ЕГРИП, реестры)
- Проверка репутации, судов, арбитражных дел, банкротств
- Выявление скрытой аффилированности
- Оценка финансового состояния и платёжеспособности
- Формирование заключений по результатам проверки

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ ЕГРЮЛ/ЕГРИП** | По ИНН — извлекает данные, находит изменения, связи | Карточка компании с флагами |
| **Проверка судебных дел** | Ищет дела: истец/ответчик, суммы, статусы | Список дел с оценкой риска |
| **Проверка арбитража** | Анализирует арбитражные дела, задолженности | Отчёт по финансовым рискам |
| **Выявление связей** | Анализирует учредителей, директоров, связанные компании | Схема связей, аффилированность |
| **Проверка репутации** | Мониторит новости, отзывы, рейтинги | Дайджест: что нашлось, риски |
| **Сравнение контрагентов** | Сравнивает 3+ компании по критериям | Конкурентный лист СБ |
| **Оценка платёжеспособности** | Анализирует выручку, прибыль, дебиторку | Вердикт: платёжеспособность, рекомендация |

### Пример запроса
```
РОЛЬ: Ты — аналитик due diligence службы безопасности.
КОНТЕКСТ: Проверка поставщика перед контрактом на 50 млн ₽.
ЗАДАЧА: Составить профиль рисков компании.

Данные:
- ООО "СтройМонтаж", ИНН 7701234567
- Учредитель: Иванов А.А. (доля 51%), ООО "СМ-Консалтинг" (49%)
- Директор: Сидоров П.П. (сменился 2 раза за год)
- Выручка: 2023 — 180 млн, 2024 — 45 млн
- Арбитраж: 5 дел как ответчик, 2 взыскания на 12 млн
- Соцсети: негативные отзывы подрядчиков о невыплатах

ФОРМАТ:
  1. Профиль компании (таблица: параметр, значение, риск)
  2. Финансовые риски (оценка платёжеспособности)
  3. Юридические риски (испы, арбитраж, банкротство)
  4. Репутационные риски (отзывы, новости)
  5. Связи и аффилированность (схема)
  6. Рекомендация (работать/не работать/уточнить)
ОГРАНИЧЕНИЯ: Только открытые источники. Оценка — вероятностная.
```

## Роль 4: Проверка закупочной деятельности компании

### Что делает
- Мониторинг цен на закупаемые товары и услуги
- Изучение поставщиков (репутация, история, связи)
- Проверка смет, КП, договоров на завышение цен и необоснованные затраты
- Анализ закупочных процедур (конкурентность, прозрачность)
- Выявление сговоров, коррупционных рисков, переплат
- Финансовый мониторинг платежей по закупкам

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Сравнение цен с рынком** | По позициям сметы/КП — ищет рыночные цены | Таблица: позиция, цена в смете, рыночная, отклонение |
| **Проверка смет подрядчика** | Загружает смету → сверяет с ФЕР/ГЭСН | Список завышений с обоснованием |
| **Анализ КП** | Сравнивает 3+ КП → находит аномалии | Конкурентный лист + флаги |
| **Проверка договоров** | Анализирует цену, сроки, штрафы, форс-мажор | Список рисков, рекомендуемые правки |
| **Мониторинг платежей** | Анализирует историю платежей → находит аномалии (круглые суммы, частые платежи одному контрагенту) | Алерты на подозрительные платежи |
| **Анализ процедур** | Проверяет, были ли конкурентные процедуры | Отчёт: нарушения, риски сговора |
| **Выявление переплат** | Сравнивает цены с историей закупок | Список позиций с необоснованным ростом цен |

### Пример запроса
```
РОЛЬ: Ты — специалист по проверке закупочной деятельности.
КОНТЕКСТ: Проверка сметы подрядчика на строительство офиса.
ЗАДАЧА: Найти необоснованные затраты и завышение цен.

Данные по смете:
- Бетон Б25: 8500 ₽/м³ (рынок: 7200-7800)
- Арматура А500: 58 000 ₽/т (рынок: 52 000-55 000)
- Опалубка: аренда 350 ₽/м²/мес (рынок: 200-250)
- Накладные расходы: 18% (норма: 12-15%)
- Сметная прибыль: 10% (норма: 8%)
- Закупка: прямой договор без конкурентной процедуры

ФОРМАТ:
  1. Таблица сравнения (позиция, цена сметы, рыночная, отклонение, %)
  2. Накладные расходы (расчёт, сравнение с нормой)
  3. Анализ процедуры (была ли конкуренция, риски)
  4. Итоговое завышение (сумма, % от сметы)
  5. Рекомендации (что оспорить, на что настоять)
ОГРАНИЧЕНИЯ: Без обвинений в мошенничестве. Только фактический анализ.
```

## Роль 5: Проверка взаимосвязей (аффилированность)

### Что делает
- Строит карты связей между людьми и компаниями
- Выявляет скрытую аффилированность (родство, совместный бизнес, адреса, телефоны)
- Находит конфликт интересов (закупщик-поставщик, руководитель-конкурент)
- Анализирует социальные и деловые связи
- Отслеживает смену руководства и учредителей у контрагентов
- Выявляет номинальных учредителей и директоров

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Карта связей** | По ИНН/ФИО — строит схему связей (учредители, директора, адреса, телефоны) | Визуальная схема или таблица связей |
| **Поиск совпадений** | Сравнивает данные сотрудников с данными контрагентов | Список совпадений (адреса, телефоны, родство) |
| **Анализ смены директоров** | Отслеживает смену руководства у контрагентов | Таймлайн: кто, когда, с чем связано |
| **Выявление номиналов** | Анализирует учредителей — находит признаки номинальности | Флаги: множественное участие, связь с СНГ, массовые адреса |
| **Конфликт интересов** | Проверяет связи закупщиков/руководителей с поставщиками | Отчёт: связь, риск, рекомендация |
| **Социальные связи** | Анализирует связи через соцсети (в рамках закона) | Карта связей, флаги риска |

### Пример запроса
```
РОЛЬ: Ты — аналитик по связям и аффилированности.
КОНТЕКСТ: Проверка закупщика Петрова А.В. и поставщика ООО "Поставка+".
ЗАДАЧА: Найти возможные связи и конфликт интересов.

Данные:
- Петров А.В. (закупщик): прописка — ул. Ленина 15
- Жена Петрова: ИП "Петрова М.А.", оказывает консалтинг
- ООО "Поставка+": учредитель — Смирнов К.Л., адрес: ул. Ленина 15 (тот же дом)
- Смирнов К.Л.: ранее работал в ООО «Логистика», где Петров А.В. — начальник отдела
- "Поставка+": телефон +7(495)123-45-67 — тот же, что у ИП Петровой (по открытым данным)

ФОРМАТ:
  1. Таблица связей (кто, с кем, тип связи, источник, уверенность)
  2. Карта связей (текстовая схема)
  3. Факторы риска (что указывает на аффилированность)
  4. Рекомендация (продолжать работу / прекратить / проверить)
ОГРАНИЧЕНИЯ: Только открытые данные. Без выводов о преступлении. Только риски.
```

## Роль 6: Служебные расследования (по фактам, обстоятельствам и лицам)

### Что делает
- Сбор и анализ доказательств по фактам нарушений
- Проведение служебных расследований (внутри компании и в отношении контрагентов)
- Допросы/опросы сотрудников, контрагентов, сторонних лиц (планирование)
- Построение хронологии событий и анализ обстоятельств
- Оформление результатов: акты, заключения, рекомендации
- Взаимодействие с правоохранительными органами при необходимости

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Хронология событий** | По разрозненным данным — строит таймлайн | Таблица: время, событие, источник, доказательство |
| **Анализ показаний** | Сравнивает показания разных лиц → находит противоречия | Таблица: вопрос, ответ А, ответ Б, противоречие |
| **План расследования** | По описанию инцидента — составляет план | Чек-лист: что проверить, где, у кого, сроки |
| **Генерация документов** | По фактам — пишет протокол опроса, объяснительную, акт | Готовый документ по форме |
| **Оценка доказательств** | Классифицирует доказательства по силе | Таблица: доказательство, тип, сила, достаточность |
| **Анализ обстоятельств** | Находит скрытые связи и мотивы | Карта: факты, версии, обстоятельства, подтверждения |
| **Прогноз сценариев** | На основе данных — строит версии и прогнозы | Список версий с вероятностями |

### Пример запроса
```
РОЛЬ: Ты — следователь службы безопасности.
КОНТЕКСТ: Служебное расследование по факту пропажи материалов со склада.
ЗАДАЧА: Составить план расследования и проанализировать обстоятельства.

Инцидент: Пропажа кабеля ВВГ, 500 м, ~200 тыс ₽.

Известно:
- Последняя инвентаризация: 2 недели назад, расхождений не было
- Доступ на склад: 5 человек (охранник, кладовщик, 3 сотрудника СМР)
- Камеры: 3 шт, запись хранится 14 дней
- Сигнализация: срабатывала 1 раз 5 дней назад, ложная (по журналу)
- Кладовщик за 2 недели до инцидента сообщил о финансовых проблемах
- Один из сотрудников СМР — родственник кладовщика

ФОРМАТ:
  1. План расследования (этап, что делать, у кого, срок, приоритет)
  2. Вопросы для каждого из 5 человек (по обстоятельствам и мотивам)
  3. Что проверить по документам (накладные, акты, журналы)
  4. Что проверить по видео (время, зоны, лица)
  5. Хронология предполагаемого события
  6. Версии и вероятности (что могло произойти)
  7. Рекомендации по усилению контроля
ОГРАНИЧЕНИЯ: Только законные методы. Без давления на сотрудников. Версии — гипотезы, не обвинения.
```

## Роль 7: Разработка, оценка и экспертиза документов

### Что делает
- Разработка внутренних регламентов, положений, инструкций СБ
- Оценка и экспертиза договоров, смет, актов, протоколов
- Проверка соответствия документов законодательству и внутренним нормам
- Экспертиза приказов, распоряжений, служебных записок
- Разработка шаблонов документов для расследований, проверок, отчётов
- Правовая оценка рисков в документах

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Экспертиза договора** | Анализирует договор → находит риски, непрописанные случаи, невыгодные условия | Список рисков + рекомендуемые правки |
| **Проверка сметы** | Сверяет смету с нормами, находит ошибки и завышения | Таблица: позиция, норма, факт, отклонение |
| **Разработка регламента** | По описанию процесса — пишет структуру регламента | Готовый черновик регламента |
| **Экспертиза акта** | Проверяет акт выполненных работ на соответствие смете и договору | Список замечаний, риски оплаты |
| **Разработка шаблонов** | Создаёт шаблоны: протокол опроса, акт расследования, заключение | Готовые шаблоны по форме |
| **Оценка соответствия закону** | Проверяет документ на соответствие 44-ФЗ, 223-ФЗ, ТК РФ, 152-ФЗ | Список нарушений, рекомендации |
| **Сравнение версий документа** | Сравнивает 2 версии договора/сметы → находит изменения | Таблица: что изменилось, риск изменения |

### Пример запроса
```
РОЛЬ: Ты — эксперт по документам службы безопасности.
КОНТЕКСТ: Экспертиза договора подряда на строительные работы.
ЗАДАЧА: Найти риски и непрописанные случаи.

Данные договора:
- Цена: фиксированная, 50 млн ₽, без индексации
- Срок: 180 дней, штраф за просрочку — 0.01% в день (низкий)
- Акты КС-2: принимаются в течение 5 дней без претензий
- Форс-мажор: не определён перечень
- Претензионный порядок: не указан срок рассмотрения
- Гарантия: 1 год (норма для таких работ — 2-3 года)
- Страхование: отсутствует

ФОРМАТ:
  1. Риски по пунктам (пункт договора, риск, почему критично, рекомендация)
  2. Непрописанные случаи (что не урегулировано, последствия)
  3. Сравнение с рыночной практикой (что обычно прописывают)
  4. Рекомендуемые правки (текст для включения в договор)
  5. Итоговая оценка риска договора (высокий/средний/низкий)
ОГРАНИЧЕНИЯ: Только анализ документа. Без юридических консультаций. Рекомендации — для передачи юристу.
```

## Роль 8: Информационная безопасность (фаерволы, DLP, SOC-аналитика, профилактика)

### Что делает
- Мониторинг утечек данных (DLP-системы)
- Анализ логов фаерволов, IDS/IPS, SIEM
- SOC-аналитика: выявление инцидентов ИБ, реагирование
- Профилактика инцидентов: оценка уязвимостей, тестирование
- Контроль доступа к конфиденциальной информации
- Защита от инсайдеров (сотрудники с доступом к данным)
- Обучение сотрудников правилам ИБ

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ логов фаервола** | Анализирует логи → находит аномалии (необычное время, массовая выгрузка, подозрительные IP) | Алерты: кто, когда, что, риск |
| **Анализ DLP** | Проверяет срабатывания DLP → классифицирует по серьёзности | Отчёт: инциденты, утечки, рекомендации |
| **SOC-аналитика** | Анализирует массив данных SIEM → находит корреляции | Таблица инцидентов с приоритетами |
| **Проверка политик доступа** | Сравнивает текущие настройки доступа с политикой ИБ | Список нарушений (лишние права, неотозванные доступы) |
| **Анализ утечек** | По описанию инцидента — определяет источник, масштаб, последствия | Отчёт: что утекло, откуда, к кому, что делать |
| **План реагирования** | По типу инцидента — генерирует план реагирования | Чек-лист: шаги, ответственные, сроки |
| **Оценка уязвимостей** | Анализирует описание уязвимости → оценивает риск | CVSS-оценка, рекомендации по устранению |
| **Обучение сотрудников** | Создаёт материалы для обучения (фишинг, пароли, утечки) | Тесты, сценарии, памятки |
| **Профилактика инсайдеров** | Анализирует поведение сотрудников → находит аномалии | Алерты: подозрительная активность, риски |

### Пример запроса
```
РОЛЬ: Ты — аналитик ИБ, специалист SOC.
КОНТЕКСТ: Анализ инцидента утечки коммерческой тайны — прайс-лист конкуренту.
ЗАДАЧА: Провести первичный анализ инцидента и составить план реагирования.

Данные:
- Конкурент опубликовал прайс, идентичный внутренней версии
- Доступ к прайсу: 12 сотрудников (отдел продаж, руководство)
- Логи DLP: 3 сотрудника скачивали файл за последний месяц
- Один из 3 уволился 2 недели назад
- Прайс был отправлен на личную почту одного из сотрудников (по логам DLP)
- Фаервол: зафиксированы 2 подключения с неизвестных IP в нерабочее время

ФОРМАТ:
  1. Хронология событий (время, действие, источник)
  2. Круг подозреваемых (вероятность, мотив, возможность, доказательства)
  3. Технический анализ (что показали логи, DLP, фаервол)
  4. Доказательства (что есть, чего не хватает)
  5. План реагирования (шаги, сроки, ответственные)
  6. Рекомендации по профилактике (технические, организационные)
ОГРАНИЧЕНИЯ: Без обвинений. Только анализ и рекомендации. Соблюдение 152-ФЗ.
```
