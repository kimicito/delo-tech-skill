## Роль 1: Физическая безопасность (контроль камер, периметра, доступа)

### Что делает
- Мониторинг камер наблюдения
- Контроль периметра (датчики, охрана)
- СКУД (система контроля и управления доступом)
- Реагирование на тревоги

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ видео** | Загружает записи с камер → находит аномалии, распознаёт людей/объекты/номера | Отчёт: время, место, событие, кадры |
| **Проверка маршрутов патрулирования** | Анализирует журналы → находит пропуски, задержки, необъяснимые остановки | Таблица нарушений маршрута |
| **Контроль периметра** | Анализирует данные датчиков → выявляет ложные/истинные срабатывания | Рекомендация: настройка чувствительности, ремонт |
| **Распознавание лиц** | Сравнивает фото с базой разрешённых/запрещённых лиц | Список совпадений с вероятностью |
| **Отчёт по инцидентам** | По описанию события — генерирует протокол, акт, заявление в полицию | Готовый документ по форме |

### Пример запроса
```
РОЛЬ: Ты — специалист физической безопасности.
КОНТЕКСТ: Складской комплекс, 45 камер, периметр 2.5 км.
ЗАДАЧА: Проанализировать журнал тревог за неделю:
- Датчик периметра, сектор 7: 12 срабатываний, все ночью
- Камера К-23: 3 раза пропадал сигнал по 5-7 мин
- Патруль охраны: задержка на посту №4 — среднее 12 мин (норма 5)
ФОРМАТ:
  1. Таблица инцидентов (тип, частота, время, зона, риск)
  2. Анализ паттернов (совпадение по времени/зоне)
  3. Рекомендации (что проверить, что усилить)
  4. Приоритет (высокий/средний/низкий)
ОГРАНИЧЕНИЯ: Без рекомендаций по увольнению. Только технические меры.
```

## Роль 2: Кадровая безопасность (проверка сотрудников)

### Что делает
- Проверка кандидатов при приёме
- Периодические проверки действующих сотрудников
- Анализ соцсетей и открытых источников
- Контроль конфликта интересов

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ резюме** | Загружает резюме → проверяет на противоречия, неточности, разрывы | Отчёт: риски, вопросы для интервью |
| **Проверка соцсетей** | По открытым данным — анализирует профили (если разрешено законом) | Резюме: что нашлось, риски |
| **Сравнение деклараций** | Сравнивает предыдущие и текущие декларации → находит необъяснимые изменения | Таблица расхождений с обоснованием |
| **Проверка связей** | Анализирует связи кандидата с конкурентами, поставщиками | Карта связей, флаги риска |
| **Генерация анкеты** | По требованиям компании — создаёт анкету для проверки | Готовая анкета с вопросами |

### Пример запроса
```
РОЛЬ: Ты — специалист кадровой безопасности.
КОНТЕКСТ: Проверка кандидата на должность руководителя закупок.
ЗАДАЧА: Составить план проверки и список рисков.

Данные кандидата:
- Последнее место работы: конкурент (ушёл 3 мес назад)
- Семья: жена — ИП, оказывает консалтинговые услуги
- Недвижимость: квартира 45 м², но автомобиль 2023 г.в. премиум-класса
- Соцсети: активно публикует критику предыдущего работодателя

ФОРМАТ:
  1. Чек-лист проверки (что проверить, где, как)
  2. Выявленные риски (риск, обоснование, критичность)
  3. Вопросы для интервью (по каждому риску)
  4. Рекомендация (принять/отклонить/уточнить)
ОГРАНИЧЕНИЯ: Только законные методы. Без нарушения 152-ФЗ (ПДн).
```

## Роль 3: Проверка контрагентов (due diligence)

### Что делает
- Проверка компаний-поставщиков, партнёров, инвесторов
- Анализ юридической чистоты
- Проверка репутации, судов, банкротств
- Выявление аффилированности

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ ЕГРЮЛ/ЕГРИП** | По ИНН — извлекает данные, находит изменения, связи | Карточка компании с флагами |
| **Проверка судебных дел** | Ищет дела: истец/ответчик, суммы, статусы | Список дел с оценкой риска |
| **Проверка арбитража** | Анализирует арбитражные дела, задолженности | Отчёт по финансовым рискам |
| **Выявление связей** | Анализирует учредителей, директоров, связанные компании | Схема связей, аффилированность |
| **Проверка репутации** | Мониторит новости, отзывы, рейтинги | Дайджест: что нашлось, риски |
| **Сравнение контрагентов** | Сравнивает 3+ компании по критериям | Конкурентный лист СБ |

### Пример запроса
```
РОЛЬ: Ты — аналитик due diligence.
КОНТЕКСТ: Проверка поставщика перед контрактом на 50 млн ₽.
ЗАДАЧА: Составить профиль рисков компании.

Данные:
- ООО "СтройМонтаж", ИНН 7701234567
- Учредитель: Иванов А.А. (доля 51%), ООО "СМ-Консалтинг" (49%)
- Директор: Сидоров П.П. (сменился 2 раза за год)
- Выручка: 2023 — 180 млн, 2024 — 45 млн
- Арбитраж: 5 дел как ответчик, 2 взыскания на 12 млн
- Соцсети: негативные отзывы подрядчиков о невыплатах

ФОРМАТ:
  1. Профиль компании (таблица: параметр, значение, риск)
  2. Финансовые риски (оценка платёжеспособности)
  3. Юридические риски (испы, арбитраж, банкротство)
  4. Репутационные риски (отзывы, новости)
  5. Связи и аффилированность (схема)
  6. Рекомендация (работать/не работать/уточнить)
ОГРАНИЧЕНИЯ: Только открытые источники. Оценка — вероятностная.
```

## Роль 4: Экономическая безопасность (проверка цен, смет, переплат)

### Что делает
- Анализ смет, КП, договоров на завышение цен
- Проверка рыночных цен
- Выявление переплат и необоснованных затрат
- Финансовый мониторинг платежей

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Сравнение цен с рынком** | По позициям сметы — ищет рыночные цены | Таблица: позиция, цена в смете, рыночная, отклонение |
| **Проверка смет подрядчика** | Загружает смету → сверяет с ФЕР/ГЭСН | Список завышений с обоснованием |
| **Анализ КП** | Сравнивает 3+ КП → находит аномалии | Конкурентный лист + флаги |
| **Проверка договоров** | Анализирует цену, сроки, штрафы, форс-мажор | Список рисков, рекомендуемые правки |
| **Мониторинг платежей** | Анализирует историю платежей → находит аномалии (круглые суммы, частые платежи одному контрагенту) | Алерты на подозрительные платежи |

### Пример запроса
```
РОЛЬ: Ты — экономист службы безопасности.
КОНТЕКСТ: Проверка сметы подрядчика на строительство офиса.
ЗАДАЧА: Найти необоснованные затраты и завышение цен.

Данные по смете:
- Бетон Б25: 8500 ₽/м³ (рынок: 7200-7800)
- Арматура А500: 58 000 ₽/т (рынок: 52 000-55 000)
- Опалубка: аренда 350 ₽/м²/мес (рынок: 200-250)
- Накладные расходы: 18% (норма: 12-15%)
- Сметная прибыль: 10% (норма: 8%)

ФОРМАТ:
  1. Таблица сравнения (позиция, цена сметы, рыночная, отклонение, %)
  2. Накладные расходы (расчёт, сравнение с нормой)
  3. Итоговое завышение (сумма, % от сметы)
  4. Рекомендации (что оспорить, на что настоять)
ОГРАНИЧЕНИЯ: Без обвинений в мошенничестве. Только фактический анализ.
```

## Роль 5: Анализ взаимосвязей (люди, компании, конфликт интересов)

### Что делает
- Строит карты связей между людьми и компаниями
- Выявляет скрытую аффилированность
- Находит конфликт интересов
- Анализирует социальные связи

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Карта связей** | По ИНН/ФИО — строит схему связей (учредители, директора, адреса, телефоны) | Визуальная схема или таблица связей |
| **Поиск совпадений** | Сравнивает данные сотрудников с данными контрагентов | Список совпадений (адреса, телефоны, родство) |
| **Анализ смены директоров** | Отслеживает смену руководства у контрагентов | Таймлайн: кто, когда, с чем связано |
| **Выявление номиналов** | Анализирует учредителей — находит признаки номинальности | Флаги: множественное участие, связь с СНГ, массовые адреса |
| **Конфликт интересов** | Проверяет связи закупщиков/руководителей с поставщиками | Отчёт: связь, риск, рекомендация |

### Пример запроса
```
РОЛЬ: Ты — аналитик по связям и аффилированности.
КОНТЕКСТ: Проверка закупщика Петрова А.В. и поставщика ООО "Поставка+".
ЗАДАЧА: Найти возможные связи и конфликт интересов.

Данные:
- Петров А.В. (закупщик): прописка — ул. Ленина 15
- Жена Петрова: ИП "Петрова М.А.", оказывает консалтинг
- ООО "Поставка+": учредитель — Смирнов К.Л., адрес: ул. Ленина 15 (тот же дом)
- Смирнов К.Л.: ранее работал в ООО «Логистика», где Петров А.В. — начальник отдела
- "Поставка+": телефон +7(495)123-45-67 — тот же, что у ИП Петровой (по открытым данным)

ФОРМАТ:
  1. Таблица связей (кто, с кем, тип связи, источник, уверенность)
  2. Карта связей (текстовая схема)
  3. Факторы риска (что указывает на аффилированность)
  4. Рекомендация (продолжать работу / прекратить / проверить)
ОГРАНИЧЕНИЯ: Только открытые данные. Без выводов о преступлении. Только риски.
```

## Роль 6: Внутренние расследования (проверки фактов, инциденты)

### Что делает
- Сбор и анализ доказательств
- Проведение служебных расследований
- Допросы/опросы (планирование)
- Оформление результатов

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Хронология событий** | По разрозненным данным — строит таймлайн | Таблица: время, событие, источник, доказательство |
| **Анализ показаний** | Сравнивает показания разных лиц → находит противоречия | Таблица: вопрос, ответ А, ответ Б, противоречие |
| **План проверки** | По описанию инцидента — составляет план расследования | Чек-лист: что проверить, где, у кого, сроки |
| **Генерация протоколов** | По фактам — пишет протокол опроса, объяснительную, акт | Готовый документ по форме |
| **Оценка доказательств** | Классифицирует доказательства по силе (прямые/косвенные, достаточность) | Таблица: доказательство, тип, сила, достаточность |

### Пример запроса
```
РОЛЬ: Ты — следователь службы безопасности.
КОНТЕКСТ: Пропажа материалов со склада (кабель ВВГ, 500 м, ~200 тыс ₽).
ЗАДАЧА: Составить план расследования.

Известно:
- Последняя инвентаризация: 2 недели назад, расхождений не было
- Доступ на склад: 5 человек (охранник, кладовщик, 3 сотрудника СМР)
- Камеры: 3 шт, запись хранится 14 дней
- Сигнализация: срабатывала 1 раз 5 дней назад, ложная (по журналу)

ФОРМАТ:
  1. План расследования (этап, что делать, у кого, срок, приоритет)
  2. Вопросы для каждого из 5 человек
  3. Что проверить по документам (накладные, акты, журналы)
  4. Что проверить по видео (время, зоны, лица)
  5. Хронология предполагаемого события
  6. Рекомендации по усилению контроля
ОГРАНИЧЕНИЯ: Только законные методы. Без давления на сотрудников.
```

## Роль 7: Информационная безопасность (защита данных, инсайды)

### Что делает
- Мониторинг утечек данных
- Контроль доступа к конфиденциальной информации
- Защита от инсайдеров (сотрудники с доступом)
- Анализ инцидентов ИБ

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **Анализ логов** | Анализирует логи доступа → находит аномалии (необычное время, массовая выгрузка) | Алерты: кто, когда, что, риск |
| **Проверка политик** | Сравнивает текущие настройки доступа с политикой ИБ | Список нарушений (лишние права, неотозванные доступы) |
| **Анализ утечек** | По описанию инцидента — определяет источник, масштаб, последствия | Отчёт: что утекло, откуда, к кому, что делать |
| **План реагирования** | По типу инцидента — генерирует план реагирования | Чек-лист: шаги, ответственные, сроки |
| **Обучение сотрудников** | Создаёт материалы для обучения (фишинг, пароли, утечки) | Тесты, сценарии, памятки |

### Пример запроса
```
РОЛЬ: Ты — аналитик ИБ.
КОНТЕКСТ: Подозрение на утечку коммерческой тайны — прайс-лист конкуренту.
ЗАДАЧА: Провести первичный анализ инцидента.

Данные:
- Конкурент опубликовал прайс, идентичный нашему (внутренняя версия)
- Доступ к прайсу: 12 сотрудников (отдел продаж, руководство)
- Логи: 3 сотрудника скачивали файл за последний месяц
- Один из 3 уволился 2 недели назад
- Прайс был отправлен на личную почту одного из сотрудников (по логам DLP)

ФОРМАТ:
  1. Хронология событий
  2. Круг подозреваемых (вероятность, мотив, возможность)
  3. Доказательства (что есть, чего не хватает)
  4. Рекомендации (технические, организационные, правовые)
  5. План реагирования (шаги, сроки, ответственные)
ОГРАНИЧЕНИЯ: Без обвинений. Только анализ и рекомендации. Соблюдение 152-ФЗ.
```

## Роль 8: Аналитика и разведка (OSINT, мониторинг угроз, мошенничество)

### Что делает
- Мониторинг открытых источников
- Аналитика данных (Big Data)
- Противодействие мошенничеству (фрод)
- Прогнозирование угроз

### Что покажет ИИ

| Задача | Что делает ИИ | Результат |
|--------|--------------|-----------|
| **OSINT-мониторинг** | Мониторит новости, соцсети, реестры по ключевым словам | Дайджест: угрозы, риски, тренды |
| **Анализ больших данных** | Анализирует массивы данных (платежи, заявки, логи) → находит паттерны | Аномалии, корреляции, прогнозы |
| **Выявление фрода** | Находит признаки мошенничества (круглые суммы, частые мелкие платежи, разделение) | Алерты с обоснованием |
| **Прогноз угроз** | На основе данных строит прогноз (вероятность хищения, время, место) | Карта рисков, тепловая карта |
| **Анализ инцидентов** | Сравнивает текущий инцидент с историческими → находит похожие | Профиль инцидента, вероятные сценарии |
| **Генерация отчётов** | По данным — генерирует аналитический отчёт с графиками | Готовый отчёт для руководства |

### Пример запроса
```
РОЛЬ: Ты — аналитик СБ, специалист по OSINT и фроду.
КОНТЕКСТ: Мониторинг угроз и выявление аномалий в закупках.
ЗАДАЧА: Проанализировать подозрительные закупки.

Данные (за 6 мес):
- 15 закупок у одного поставщика (ООО "Единый Поставщик")
- Суммы: все круглые (500 000, 1 000 000, 750 000)
- Закупщик: Иванов А.А. (все 15 закупок)
- Сроки поставки: всегда 1-2 дня (подозрительно быстро)
- Конкурентные процедуры: не проводились, прямой договор
- Цены: на 15-20% выше рыночных

ФОРМАТ:
  1. Таблица аномалий (признак, описание, критичность)
  2. Анализ паттерна (что общего, почему подозрительно)
  3. Сравнение с рынком (цены, сроки, процедуры)
  4. Вероятные сценарии (ошибка / халатность / мошенничество)
  5. Рекомендации (что проверить, какие документы запросить)
  6. План действий (срочный, краткосрочный, долгосрочный)
ОГРАНИЧЕНИЯ: Без прямых обвинений. Только факты и вероятности. Законные методы.
```
