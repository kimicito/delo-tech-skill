## Специфика направления
- **Задачи:** сравнение цен, поиск аналогов, оптимизация маршрутов, тендеры, контроль поставок

## Урок 4.1: AI для сравнения цен и подбора аналогов

### Цель
Научиться использовать AI для автоматического сравнения цен поставщиков, поиска аналогов и снижения закупочной стоимости.

### Теория (15 мин)
1. **Price Comparison Pipeline** — загрузка, сравнение, аналоги, отчет
2. **Типы аналогов:**
   - Другая марка (Huawei вместо Cisco)
   - Та же марка, отклонения по параметрам (приемлемые)
3. **TCO-анализ** — Total Cost of Ownership (не только цена закупки)
4. **Red Team** — проверка рисков для каждого аналога
5. **Кэширование** — результаты сохраняются, обновляются
6. **Источники:** B2B-каталоги, маркетплейсы, API поставщиков

### Live Demo (15 мин)
- Загрузка Excel с 5 позициями (свитчи, кабели, шкафы)
- Автоматический поиск цен у 2 поставщиков
- Подбор аналогов (другая марка + тот же бренд, отклонения)
- TCO-анализ (цена + доставка + гарантия + совместимость)
- Red Team: какие риски у аналога?
- Финальный Excel: 3 вкладки (все цены, аналоги той же марки, аналоги другой марки)

### Hands-on (20 мин)
**Задание:** Сравнить 3 позиции и найти аналоги

**Промпт-шаблон:**
```
Роль: Ты — закупщик с опытом 5+ лет. Знаешь рынок IT-оборудования, 
строительных материалов, электрики.

Задача: Сравни предложения и найди оптимальные варианты.

Позиция 1: Коммутатор Cisco Catalyst 9200-24P-E
- Поставщик A: 106,714 ₽ (Наг, Москва, 2 дня)
- Поставщик B: 182,112 ₽ (Эдис, СПб, 5 дней)
- Поставщик C: 95,000 ₽ (серый рынок, гарантия 6 мес)

Требования:
1. Сравни по критериям (цена, срок, гарантия, репутация)
2. Найди аналоги ДРУГОЙ марки с похожими параметрами:
   - 24 порта PoE+
   - 4×10G uplink
   - Layer 3
   - Гарантия 1+ год
3. Для каждого аналога — Red Team анализ рисков:
   - Совместимость с существующим оборудованием?
   - Гарантийное обслуживание в РФ?
   - Срок поставки стабильный?
   - Отзывы/репутация?
4. TCO-анализ:
   - Цена оборудования
   - Доставка
   - Установка/настройка
   - Гарантийное обслуживание (3 года)
   - Итоговая стоимость владения

Формат: Таблица сравнения + текстовый анализ + рекомендация
```

### Практическое задание (для строительных материалов)
```
Позиция: Кассета MTP/MPO 12 волокон, SM, типа А
- Поставщик A: 1,250 ₽/шт (Москва, в наличии)
- Поставщик B: 980 ₽/шт (Казань, 2 недели)
- Поставщик C: 1,100 ₽/шт (с аналогами под брендом, Китай)

Задача: найти аналоги, проверить соответствие ГОСТ, сравнить TCO.
```

### Чек-лист
- [ ] 3+ позиции сравнены
- [ ] Аналоги найдены (другая марка + тот же бренд)
- [ ] Red Team риски оценены
- [ ] TCO посчитан для каждого варианта
- [ ] Рекомендация обоснована

## Урок 4.2: Оптимизация маршрутов и складской логистики

### Цель
Научиться использовать AI для оптимизации доставок, планирования загрузки складов и прогнозирования.

### Теория
1. **Маршрутизация** — задача коммивояжера с ограничениями (время, грузоподъемность, окна)
2. **Складская оптимизация** — размещение, зоны, пиковая загрузка
3. **Прогноз спроса** — сезонность, тренды, буферные запасы
4. **Ограничения:** габариты, вес, хрупкость, температурный режим
5. **Стохастика** — пробки, погода, поломки (план Б)

### Live Demo
- Данные: 10 точек доставки в Москве
- AI строит оптимальный маршрут (минимум времени, пробки, топливо)
- Сценарий: "Добавилась срочная точка" → пересчет за 10 секунд
- Склад: AI рекомендует зоны размещения по частоте обращения

### Hands-on
**Задание:** Спланировать доставку и оптимизировать склад

**Промпт (маршрутизация):**
```
Роль: Ты — логист по доставке строительных материалов.

Задача: Построй оптимальный маршрут доставки.

Данные:
- Склад: МКАД, 65 км (55.7558, 37.6173)
- Машина: Газель, 1.5 тонн, 12 м³
- Ограничения: хрупкое (стекло, плитка) — только верхний ярус

Точки доставки:
1. Объект А (Тушино) — 500 кг плитки, окно 9:00-12:00
2. Объект Б (Марьино) — 300 кг клея, 200 кг грунта, окно 10:00-14:00
3. Объект В (Бутово) — 400 кг сантехники, окно 13:00-17:00
4. Объект Г (Химки) — 200 кг инструментов, гибкое окно
5. Дополнительно: заехать за 100 кг песка (Зеленоград, 15 мин)

Требования:
1. Оптимальный маршрут (минимум км, учет пробок, окна)
2. Порядок погрузки (что вниз, что верх, что в кабину)
3. Время на каждую точку (прибытие, разгрузка, отъезд)
4. Запас топлива (проверить, хватит ли)
5. Риски: что может пойти не так, план Б

Формат: Таблица маршрута + схема погрузки + timeline
```

**Промпт (склад):**
```
Роль: Ты — складской менеджер. Задача: оптимизировать размещение.

Данные:
- Склад: 500 м², 4 стеллажа, 2 зоны (приемка, отгрузка)
- Товаров: 200 SKU (строительные материалы)
- ABC-анализ: A (20% SKU, 80% оборота), B (30%, 15%), C (50%, 5%)
- Ограничения: химия отдельно, тяжелое внизу, хрупкое отдельно

Требования:
1. Зонирование (A — ближе к выходу, C — дальше)
2. ABC-распределение по стеллажам
3. Рекомендации по размещению новых SKU
4. Прогноз: хватит ли места через 6 месяцев (тренд +20%)
5. Проблемы: что затормозит работу и как решить

Формат: Схема размещения + таблица + рекомендации
```

### Чек-лист
- [ ] Маршрут оптимизирован (время, км, топливо)
- [ ] Погрузка спланирована (хрупкое, тяжелое)
- [ ] Окна доставки соблюдены
- [ ] Склад зонирован по ABC
- [ ] Прогноз на 6 месяцев даны

## Урок 4.3: Автоматизация тендеров и документации

### Цель
Автоматизировать подготовку тендерной документации, проверку контрактов, анализ предложений.

### Теория
1. **Тендерный документ** — структура, обязательные разделы, типовые ошибки
2. **AI-проверка** — полнота, соответствие ТЗ, арифметика
3. **Сравнение предложений** — не только цена, но и условия, риски
4. **Контракты** — проверка ключевых пунктов, риски, штрафы
5. **RAG на шаблонах** — поиск по базе прошлых тендеров

### Live Demo
- Генерация ТЗ на поставку кабеля из промпта
- Проверка тендерного предложения на полноту
- Сравнение 3 предложений (цена, условия, риски)
- Проверка драфта контракта — AI находит рисковые пункты

### Hands-on
**Задание:** Подготовить тендерный пакет

**Промпт (ТЗ):**
```
Роль: Ты — специалист по тендерам (заказчик). 
Опыт: подготовка 50+ тендеров на строительные материалы.

Задача: Составить техническое задание (ТЗ) на поставку.

Предмет: Поставка силового кабеля ВВГнг-LS для объекта
"Жилой комплекс, 15 этажей, 2 подъезда, подземный паркинг"

Требования к ТЗ:
1. Общие положения
   - Наименование закупки
   - Место поставки
   - Сроки поставки (этапы)
2. Технические требования
   - Марки кабеля (сечения, длины)
   - ГОСТ/ТУ
   - Упаковка и маркировка
   - Сертификаты и паспорта
3. Количественные параметры
   - Таблица: марка, сечение, длина, количество бухт
   - Итоговая сумма (ориентировочная)
4. Требования к поставщику
   - Опыт (аналогичные объекты)
   - Гарантия (срок, условия)
   - Сервис (замена брака, сроки)
5. Условия контракта
   - Оплата (аванс/постоплата/аккредитив)
   - Пени за просрочку
   - Форс-мажор
6. Критерии оценки
   - Цена (вес 60%)
   - Сроки (вес 20%)
   - Гарантия/сервис (вес 20%)

Формат: Официальный документ, структурированный, готовый для публикации.
```

**Промпт (проверка предложения):**
```
Роль: Ты — эксперт по тендерам (заказчик). 
Задача: Проверить полноту и риски предложения поставщика.

Предложение:
[вставить текст предложения или договора]

ТЗ заказчика:
[вставить ТЗ]

Проверить:
1. Полнота (все пункты ТЗ отражены?)
2. Арифметика (сходятся ли суммы, количества?)
3. Риски:
   - Неопределенные цены ("по факту", "ориентировочно")
   - Неясные сроки ("в течение месяца")
   - Ограниченная ответственность
   - Отсутствие штрафов за просрочку
   - Неясные условия приемки
4. Рекомендации:
   - Что уточнить?
   - Что требовать дополнительно?
   - Какие пункты обсудить на переговорах?

Формат: Таблица проверки + список рисков + рекомендации
```

### Расширенное задание (сравнение 3 предложений)
```
"Сравни 3 тендерных предложения по кабелю:
- Предложение A: цена 2.5M, срок 30 дней, гарантия 1 год
- Предложение B: цена 2.2M, срок 45 дней, гарантия 2 года
- Предложение C: цена 2.8M, срок 14 дней, гарантия 6 мес, отсрочка 30 дней

Оцени по: цена, сроки, гарантия, условия оплаты, репутация (если известна).
Рекомендуй лучшее с обоснованием."
```

### Чек-лист
- [ ] ТЗ составлено полностью
- [ ] Предложение проверено на риски
- [ ] Арифметика сверена
- [ ] 3 предложения сравнены по критериям
- [ ] Рекомендация обоснована
