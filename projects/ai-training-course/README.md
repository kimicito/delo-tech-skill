# Обучение Генеративному ИИ — Корпоративный курс

## Цель
Практико-ориентированное обучение сотрудников 4 направлений работе с on-premise Generative AI (OpenWebUI + локальные модели + AI-агенты).

## Структура курса

### Модуль 0: Общий (вводный)
- Урок 0.1: Что такое Generative AI — за 30 минут
- Урок 0.2: OpenWebUI — интерфейс и возможности
- Урок 0.3: Промпт-инжиниринг для начинающих

### Модуль 1: PR / Дирекция по связям с общественностью
- Урок 1.1: Генерация пресс-релизов и нарративов
- Урок 1.2: Анализ тональности и кризисные коммуникации
- Урок 1.3: Создание контента для соцсетей с AI

### Модуль 2: Строители (сметчики, плановый, приемка, аналитики)
- Урок 2.1: Автоматизация смет (ВОР → AI → смета)
- Урок 2.2: Анализ чертежей и извлечение данных
- Урок 2.3: Планирование и контроль сроков через AI-агенты

### Модуль 3: Служба безопасности
- Урок 3.1: Анализ видео и распознавание объектов
- Урок 3.2: Генерация отчетов и документации
- Урок 3.3: Аналитика угроз и паттернов

### Модуль 4: Закупки и логистика
- Урок 4.1: AI для сравнения цен и аналога подбора
- Урок 4.2: Оптимизация маршрутов и складской логистики
- Урок 4.3: Автоматизация тендеров и документации

## Формат урока (шаблон)
Каждый урок = 45-60 минут:
1. **Теория** (15 мин) — презентация 10-15 слайдов
2. **Демо** (15 мин) — live в OpenWebUI
3. **Практика** (20 мин) — hands-on задание
4. **Чек-лист** — что запомнить

## Технический стек
- **OpenWebUI** — интерфейс для моделей
- **Ollama** / **vLLM** — запуск on-premise моделей
- **OpenClaw** — AI-агенты для автоматизации
- **Qwen-VL** / **LLaVA** — vision модели для чертежей/видео
