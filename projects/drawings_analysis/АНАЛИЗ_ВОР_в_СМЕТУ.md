## Часть 3. Логика преобразования (понятно / непонятно)

### ✅ ПОНЯТНО

1. **Разбиение объёмных работ на ГЭСН:**
   - Объём в м³ → делим на единицу измерения ГЭСН (1000 м³, 100 м³, м³)
   - Пример: 1163 м³ грунта → 1.163 × 1000 м³

2. **Материалы отдельно (ПСЦ):**
   - Бетон, арматура, опалубка — всё вынесено в отдельные позиции
   - Цены указаны за единицу (руб./м³, руб./т, руб./м²)

3. **Добавление перевозки:**
   - К земляным работам добавлена перевозка грунта (1918.95 т)
   - К ПГС добавлена перевозка ПГС (637.1 м³)

4. **Детализация по элементам:**
   - ПФм1 (крупная плита) → 70 позиций (бетон, опалубка, арматура, закладные, каркасы)
   - Фом1-4 (мелкие фундаменты) → 9 позиций каждый
   - Логика: чем крупнее элемент → тем больше материалов → тем больше позиций

5. **НР и СП:**
   - Применяются отдельно для каждого подраздела
   - Проценты разные в зависимости от типа работ (земляные, бетон, металл)

### ❓ НЕ ПОНЯТНО (вопросы и ОТВЕТЫ)

| № | Вопрос | Ответ |
|---|--------|-------|
| 1 | **Как выбирать код ГЭСН?** Есть ли алгоритм или только опыт? | Расценка определяется по конструкции из РД и ВОР, **с учётом опыта сметчика**. Алгоритм формальный (тип работы + объём + условия), но выбор конкретного кода — на основе опыта. |
| 2 | **Почему ПФм1 — 70 позиций, Фом1 — 9?** Только объём? | **Нет, не только объём.** ПФм1 сложнее по конструкции — каналы, ниши, отверстия, усиленное армирование, закладные, швеллер. |
| 3 | **Как рассчитывать количества материалов?** Опалубка 133.3 м²? | **По норме ГЭСН** (площадь боковых поверхностей с учётом оборачиваемости опалубки). Арматура — **по спецификации РД**. |
| 4 | **"Доп. затраты" (ГЭСН06-02-001-08)** — что сложного? | **Сложная форма и конфигурация:** каналы, ниши, отверстия, усиленное армирование. |

| 6 | **Цены материалов (ПСЦ)** — откуда? | **Протокол согласования цен** Коммерческого департамента (на основании прайсов поставщиков). Не ФССЦ. |

| 8 | **Каркас КП1 (154166 руб./т)** — почему дороже арматуры? | **Готовое изделие/конструкция** (сварной каркас из арматуры), а не прокат. |

### ✅ Теперь понятно полностью

**Ключевые инсайты:**

1. **Опыт сметчика = ключевой фактор.** Формально есть правила (тип работы + объём), но выбор конкретного кода ГЭСН — это навык, который приходит с опытом. Без ГРАНД-Сметы и практики — сложно.

2. **РД (рабочая документация) = источник объёмов.** Не только ВОР, но и спецификации арматуры, закладных, швеллера — всё из РД.

3. **ПСЦ = протокол цен, не ФССЦ.** Цены согласованы коммерческим департаментом на основе прайсов поставщиков. Это важно — ФССЦ может отличаться.

4. **Нормы ГЭСН = расчёт материалов.** Опалубка, расход материалов — всё по нормам выбранной расценки. Не нужно считать вручную.

5. **НР/СП по подразделам = методология.** Это не удобство, а требование. Каждый тип работ имеет свои %.

6. **"Сложные фундаменты" = конкретные признаки.** Каналы, ниши, отверстия, усиленное армирование — это объективные критерии.

## Итог

**Как смета получилась из ВОР:**

1. Каждая позиция ВОР → разбивается на работу (ГЭСН) + материалы (ПСЦ)
2. Для монолитных конструкций добавляются: опалубка, арматура, закладные
3. Для каждого элемента применяются свои НР/СП
4. Коэффициент расширения ~5.6x (24 → 134 позиций)

**Что требует разъяснений:**
- Алгоритм выбора кода ГЭСН
- Расчёт количеств материалов (опалубка, арматура)
- Обоснование "дополнительных затрат"
- Источник цен материалов
- Логика перевозки (1918.95 т)
