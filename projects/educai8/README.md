# educai8 — Обучение ИИ для производственной компании

## Контекст
Алюминиевый дивизион: колесные диски, рамы для окон, трубы. 6 служб: Производство (upstream/downstream), Продажи, Закупки, Финансы, Юристы, Маркетинг.

## Платформа
Open Web UI (on-premise), модели Kimi + Qwen

## Структура курса
- `lesson-01.md` — Промпт-мастерство (LLM vs Агент, R-T-F-C)
- `lesson-02.md` — Агент с памятью (SOUL, MEMORY, HEARTBEAT)
- `lesson-03.md` — Агент с руками (SKILLS, RAG, Function Calling)
- `lesson-04.md` — Агент дивизиона (Agent Team, оркестрация)

## Дополнительно

- `prompts/` — Библиотека промптов по службам
