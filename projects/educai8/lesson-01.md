## Слайд 2. LLM: сверхспособности на ваших задачах

**1. Excel-анализ за 10 секунд**
> «Вот таблица 10 000 строк расхода электроэнергии по цехам за год. Найди аномалии, покажи месяцы с отклонением >15%, построй график.»

**2. Дашборд из воздуха**
> «Создай дашборд OEE цеха экструдирования в Python/Streamlit. Источник: CSV с колонками date, planned_time, actual_time, good_units, total_units.»

**3. Код для рутины**
> «Напиши скрипт, который сверяет накладные со счетами поставщиков и выдаёт расхождения. Формат: Excel с подсветкой красным.»

**4. Анализ фото**
> «Посмотри фото дефекта на литом диске. Какой тип дефекта? Вероятная причина? Рекомендуй корректировку параметров литья.»

**5. Документы**
> «Проанализируй 200-страничный договор. Выдели пункты без штрафных санкций, односторонние отказы, неразумные сроки претензий.»

**Вывод:** LLM — универсальный интеллект. Но он **одноразовый и без памяти**.

## Слайд 3. LLM vs Агент: на пальцах

| Задача | LLM (Kimi/Qwen) | Агент (OpenClaw) | Почему |
|--------|-----------------|------------------|--------|
| Написать КП по шаблону | ✅ Да | ✅ Да | Оба генерируют текст |
| Помнить, что клиент X берёт с отсрочкой 45 дней | ❌ Нет | ✅ Да | LLM не помнит между сессиями |
| Каждый понедельник 8:00 проверять цены LME | ❌ Нет | ✅ Да | LLM не просыпается сам |
| Запустить расчёт себестоимости в Excel | ❌ Нет | ✅ Да | LLM пишет код, агент **выполняет** |
| Согласовать изменение сплава между цехом, закупками и продажами | ❌ Нет | ✅ Да | LLM — один. Агент — **команда** |

**Вывод:** LLM — мозг. Агент — мозг + **память + руки + будильник + команда**.

## Слайд 4. Агент 2026: новые возможности

**Vision** — смотрит фото и чертежи
- Дефект диска → тип → причина → корректировка
- Сравнение чертежа с фактической заготовкой

**Code Execution** — Python прямо внутри
- Расчёт себестоимости не текстом, а запуском скрипта
- Построение графиков, экспорт в Excel

**RAG** — поиск по вашим документам
- ГОСТ 4784-2019, регламенты, договоры — агент отвечает **на основе ваших файлов**

**Function Calling** — вызов API
- Подключение к MES/ERP: реальные данные остатков, планов, отгрузок
- Отправка заявки в 1С по команде

**Multi-Agent** — команда агентов
- Технолог + Закупки + Продажи решают изменение сплава **параллельно**

## Слайд 6. R-T-F-C — формула профессионального промпта

**Структура любого промпта:**
- **R**ole — роль: «Ты — финансовый аналитик...»
- **T**ask — задача: «Проанализируй отклонение...»
- **F**ormat — формат: «Верни в виде таблицы...»
- **C**onstraint — ограничения: «Не более 200 слов, без воды...»

**Пример «До» vs «После»:**

❌ **До (любительский):**
«Проанализируй затраты на электроэнергию»

✅ **После (профессиональный, R-T-F-C):**
> «**[R]** Ты — финансовый аналитик цеха экструдирования.  
> **[T]** Проанализируй отклонение фактических затрат на электроэнергию от плана за май 2026. Факт: 4.2 млн руб, План: 3.8 млн руб.  
> **[F]** Верни: таблицу с 3 главными причинами отклонения + меры.  
> **[C]** Без общих фраз. Только конкретные цифры и действия.»

## Слайд 7. Продвинутые техники промптинга

### Few-Shot (покажи пример)
```
Напиши КП в таком же стиле, как эти 3 примера:
[Пример 1: КП для ООО МеталлСнаб]
[Пример 2: КП для ООО ПромАлюм]
[Пример 3: КП для ООО ТехноПрофиль]

Задача: КП для ООО СтройАлюм, объем 3000 дисков/мес.
```

### Chain-of-Thought (думай шаг за шагом)
```
Проанализируй отклонение затрат. Рассуждай шаг за шагом:
1. Сравни факт с планом по категориям
2. Найди категорию с максимальным отклонением
3. Предположи 3 причины
4. Предложи меры
```

### JSON-mode (машиночитаемый результат)
```
Верни результат строго в JSON:
{
  "сплав": "АД31Т",
  "температура_зона_1": 480,
  "дефекты_ожидаемые": ["пористость", "раковины"]
}
```

### Constraint Layer
```
[Must] Используй только сплавы из ГОСТ 4784-2019
[Must] Цена в рублях без НДС
[Nice] Добавь сравнение с прошлым кварталом
[Never] Не используй слова "инновационный", "премиум"
```

## Слайд 9. Продажи

> **[T]** Сгенерируй коммерческое предложение для производителя автокомпонентов на поставку алюминиевых дисков, 5000 шт/мес.  
> **[F]** Деловое письмо: 1 абзац вступление, 2 абзац условия (FCA, отсрочка 45 дней), 3 абзац 3 конкурентных преимущества.

**Ещё задачи:** анализ тендерной заявки, ответ на запрос технического заказчика, сравнение конкурентных предложений.
