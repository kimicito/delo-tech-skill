# educai8 — Roadmap: 4 занятия

## Контекст
Алюминиевый дивизион. Цель: каждая служба создаёт своего агента, затем объединяем в «Агента дивизиона».

---

## Занятие 1: Промпт-мастерство
**Дата:** —
**Цель:** Каждый пишет профессиональные промпты.
**Формат:** 13 слайдов, 50 минут.

### Содержание
- LLM-возможности (Excel, дашборды, фото, документы)
- LLM vs Агент: на пальцах
- Агент 2026: Vision, Code Execution, RAG, Function Calling, Multi-Agent
- R-T-F-C формула
- Few-Shot, Chain-of-Thought, JSON-mode, Constraint Layer
- Живые промпты для 6 служб

### Результат
**Библиотека промптов дивизиона** — 30+ рабочих промптов.

### Домашнее задание
1. Применить 3 промпта к реальным задачам
2. Зафиксировать результат и доработки
3. Принести топ-3 документа для загрузки в агента

---

## Занятие 2: Агент с памятью
**Дата:** —
**Цель:** Агент помнит контекст, характер, документы.

### Содержание
- Разбор домашки: лучшие промпты, типичные ошибки
- **SOUL** — пишем характер агента (2 примера: технолог, продажник)
- **MEMORY** — загружаем 5 документов в Open Web UI, настраиваем RAG
- **HEARTBEAT** — 1 автоматическая задача (мониторинг цен / плана / сроков)
- Практика: каждый настраивает своего агента

### Результат
**6 персональных агентов** — каждый знает свои ГОСТы, шаблоны, клиентов.

### Домашнее задание
1. Доработать SOUL агента после тестов
2. Добавить 5+ документов в MEMORY
3. Настроить 1 HEARTBEAT на реальную задачу

---

## Занятие 3: Агент с руками
**Дата:** —
**Цель:** Агент не просто отвечает, а выполняет: считает, генерирует, проверяет.

### Содержание
- **SKILLS** — создаём скрипты: расчёт себестоимости, проверка договора, дашборд
- **Code Execution** — Python прямо внутри агента
- **RAG глубже** — агент ищет по ГОСТам, не галлюцинирует
- **Function Calling** — подключаем API: MES/ERP, 1С
- Практика: каждая служба создаёт 1 skill

### Результат
**Агенты считают и генерируют** — Excel с формулами, проверки договоров, дашборды.

### Домашнее задание
1. Довести 1 skill до production (работает без ручной правки)
2. Протестировать на 5 реальных задачах
3. Документировать: входные данные → выходной формат

---

## Занятие 4: Агент дивизиона
**Дата:** —
**Цель:** Единый агент для всего дивизиона с командой субагентов.

### Содержание
- **Agent Team** — иерархия: Директор → Службы → Специалисты
- **Оркестрация** — как директор решает межфункциональные вопросы
- **Shared Memory** — общий файл-реестр для обмена между агентами
- **Telegram-бот** — релиз агента в общий доступ
- Кейс: «Изменение сплава» — 3 службы решают параллельно

### Результат
**«Агент дивизиона» в Telegram** + команда субагентов под капотом.

### Финальный проект
Каждая служба представляет: «Вот что мой агент умеет» + демо.
