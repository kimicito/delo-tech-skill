# Data Directory

Здесь хранятся сметы и ВОР по объектам.

## Структура объекта

```
data/<object_name>/
├── ВОР.xlsx              # Исходная ведомость (IMMUTABLE, только чтение)
├── README.md             # Описание объекта
├── смета_v1.xlsx         # Черновик (если нужен)
├── смета_v2.xlsx         # Исправленная
├── ...
└── смета_итог.xlsx       # Итоговая (после прохождения eval)
```

## Правила

1. **ВОР никогда не редактируется** — это исходный документ
2. **Сметы версионируются** — v1, v2, v3... до итоговой
3. **Только итоговая смета** отправляется заказчику
4. **Перед итоговой** — обязательно запустить eval:
   ```bash
   make eval SMETA=data/<object>/смета_итог.xlsx VOR=data/<object>/ВОР.xlsx
   ```

## Как добавить новый объект

```bash
mkdir data/<название_объекта>
cp ВОР.xlsx data/<название_объекта>/
make template OUTPUT=data/<название_объекта>/смета_v1.xlsx REGION="<регион>" YEAR=2026 Q=2
# Заполнить смету
make eval SMETA=data/<название_объекта>/смета_v1.xlsx VOR=data/<название_объекта>/ВОР.xlsx
```
