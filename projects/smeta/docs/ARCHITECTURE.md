# Architecture

## Smeta Project — Architecture v3.0

### Цель

Устойчивая инфраструктура для составления смет по ФЕР-2020 с БИМ-методикой, которая:
- Не ломается при обновлениях нормативов
- Не забывает проверять актуальность данных
- Версионирует сметы и ВОР
- Проверяет методологию автоматически

---

## Компоненты

### 1. Config (Единый источник правды)

`config/indexes.json` — индексы по регионам и кварталам
```json
{
  "Иркутская область": {
    "2Q2026": {
      "INDEX_ZP": 66.60,
      "INDEX_MACH": 16.34,
      "INDEX_MAT": 9.93
    }
  }
}
```

`config/norms.json` — нормативы НР/СП по шифрам
```json
{
  "Пр/812-016.0-1": {
    "nr_percent": 121,
    "sp_percent": 72
  }
}
```

**Правило:** Все скрипты читают индексы и нормы из config/. Не хардкодить!

### 2. Eval (Проверка корректности)

`src/eval_smeta.py` — проверяет:
- Соответствие ВОР (объёмы, позиции)
- БИМ-методику (индексы по статьям, НР/СП от ФОТ, ФССЦ)
- Актуальность индексов (дата, квартал)

**Выход:** FAIL / WARN / OK

### 3. Templates (Шаблоны)

`templates/ШАБЛОН_ЛСР_БИМ_Методика2.xlsx` — Excel с колонками ОТ, ЭМ, М, формулами для текущих цен

### 4. Data (Объекты)

Каждый объект — отдельная папка:
```
data/иркутск_вентиляция_2026/
├── ВОР.xlsx              # Исходная ведомость (immutable)
├── смета_v1.xlsx         # Черновик
├── смета_v2.xlsx         # Исправленная
└── смета_итог.xlsx       # Итоговая (после eval)
```

**Правило:** ВОР никогда не редактируется. Сметы версионируются.

### 5. Raw (Сборники)

`raw/ФЕР-20_Вентиляция.pdf` — PDF сборники (immutable, только для чтения)

### 6. Cron (Автоматическая проверка)

`scripts/check_updates.sh` — 1-го числа каждого месяца:
- Проверяет доступность ФГИС ЦС
- Проверяет доступность publication.pravo.gov.ru
- Логирует результат
- Требует ручной проверки

## Поток данных (составление сметы)

```
[ВОР] → [Шаблон БИМ] → [Заполнение позиций] → [Eval] → [Итог]
  ↓           ↓                ↓                 ↓
config/   config/        src/           src/
indexes   norms      eval_smeta.py    create_bim_template.py
```

## Поток данных (обновление нормативов)

```
[Cron 1-го числа] → [check_updates.sh] → [Лог] → [Уведомление]
                                              ↓
                                         [Ручная проверка] → [Обновление config/]
```

## Устойчивость к ошибкам

| Проблема | Решение |
|----------|---------|
| ФГИС недоступен | Использовать последние индексы из config/ + уведомить пользователя |
| Ошибка в eval | FAIL блокирует отправку сметы |
| Устаревшие индексы | eval ловит: "Не найдена дата индексов" |
| Потеря данных | Git + версионирование смет (v1, v2, v3...) |
| Неправильный метод | eval ловит: общий индекс, НР/СП от прямых |
