# Анализ ошибок в смете вентиляции

## Допущенные ошибки

### 1. ФАНТАЗИЯ вместо данных ВОР (критическая)
**Что сделал:** Добавил в смету позиции, которых НЕТ в ВОР:
- Вентиляторы осевые (3 шт, 2 шт) — в ВОР только радиальный ВР 80-75 №6.3
- Вентиляторы крышные (1 шт) — в ВОР нет
- Дефлекторы 280мм (2 шт) — в ВОР нет
- Сплит-системы настенные (1 компл) — в ВОР нет

**Почему допустил:**
- Интерпретировал ВОР как "примерный" документ, а не как ЕДИНСТВЕННЫЙ источник данных
- Попытался "дополнить" смету типовыми позициями для вентиляции, основываясь на общих знаниях
- НЕ ПРОВЁЛ валидацию: "Есть ли эта позиция в ВОР?"

### 2. Неверные объёмы работ
**Что сделал:**
- Решетки жалюзийные: 8 шт (в ВОР — 20 шт)
- Клапаны обратные: 4 шт (в ВОР — 1 шт)
- Заслонки: 3 шт (в ВОР — 1 шт)
- Кронштейны: 0.8×100кг (в ВОР — 50 кг = 0.5×100кг)

**Почему допустил:**
- Не перенёс данные ВОР вручную/автоматически
- Возможно, взял цифры из головы или из старой версии сметы
- НЕ СВЕРИЛ каждую позицию с ВОР

### 3. Общий индекс вместо индексов по статьям
**Что сделал:** Применил общий индекс СМР 8.64 вместо отдельных индексов:
- INDEX_ZP (оплата труда)
- INDEX_MAT (материалы)
- INDEX_MACH (эксплуатация машин)

**Почему допустил:**
- Упростил расчёт, не зная точных индексов по статьям
- Не имею доступа к актуальным письмам Минстроя

### 4. Поправка без уточнения
**Что сделал:** Поставил К=1.15 для всех позиций

**Почему допустил:**
- Не проверил, какие сборники применяются (монтажные 1.15, строительные 1.35)
- Сметчик указал: для строительных сборников К=1.35

### 5. Нет валидации "ВОР ↔ смета"
**Что сделал:** Не создал процедуру проверки соответствия

**Почему допустил:**
- Не было чёткого правила: "ВОР/ведомость дефектов = основной документ"
- Не было автоматической проверки

---

## Корневые причины

1. **Отсутствие правила:** Не зафиксировано, что ВОР/ведомость дефектов — единственный источник данных
2. **Нет доступа к ГРАНД-Смете:** Не могу проверить коды ФЕР, индексы, поправки
3. **Нет eval/валидации:** Не было автоматической проверки соответствия ВОР и сметы
4. **Самоуверенность:** Попытался "додумать" вместо того, чтобы отметить "УТОЧНИТЬ"

---

## Вывод

При составлении сметы:
- ВОР/ведомость дефектов = ЕДИНСТВЕННЫЙ источник объёмов работ
- Всё, что не в ВОР — НЕ включается в смету
- Всё, что в ВОР — ДОЛЖНО быть в смете
- Если код ФЕР неизвестен — пишем "УТОЧНИТЬ", не придумываем
- Если индекс неизвестен — пишем "УТОЧНИТЬ", не берём из головы
