# ПРАВИЛО: ВОР/Ведомость дефектов = основной документ для сметы

## Обязательное правило (red line)

При составлении любой сметы:

1. **ВОР (Ведомость объёмов работ) или ведомость дефектов — ЕДИНСТВЕННЫЙ источник объёмов работ.**
2. **Всё, что указано в ВОР → ДОЛЖНО быть в смете.**
3. **Всё, что в смете → ДОЛЖНО быть в ВОР.**
4. **Если позиция не в ВОР → она НЕ включается в смету, без исключений.**
5. **Если код ФЕР неизвестен → пишем "УТОЧНИТЬ", не придумываем.**
6. **Если индекс/поправка неизвестны → пишем "УТОЧНИТЬ", не берём из головы.**

## Проверка перед отправкой сметы

```bash
# Запустить eval
python3 eval_smeta.py --smetа <файл_сметы.xlsx> --vor <файл_ВОР.xlsx>
```

**Если eval выдаёт FAIL → смета не отправляется, исправляем.**

## Типичные ошибки (чек-лист)

- [ ] Добавлены "типовые" позиции, которых нет в ВОР
- [ ] Неверные количества (не сверены с ВОР)
- [ ] Общий индекс вместо индексов по статьям
- [ ] Поправка без уточнения (1.15 vs 1.35)
- [ ] Отсутствуют НР и СП в итогах
- [ ] Позиции без кода ФЕР не помечены "УТОЧНИТЬ"

## Процедура составления сметы

1. Получить ВОР/ведомость дефектов
2. Скопировать ВОР в проект (чтобы не потерять)
3. Для каждой позиции ВОР подобрать код ФЕР (или отметить "УТОЧНИТЬ")
4. Перенести количества СТРОГО из ВОР
5. Запустить eval_smeta.py
6. Исправить FAIL
7. Отметить WARN
8. Отправить смету с пометками "УТОЧНИТЬ"
