# Промышленность Таганки

Статья для сборника к 90-летию Таганского района (Москва)

## Параметры
- Объём: 23 000 знаков
- Формат: DOCX
- Аудитория: массовая, краеведческая
- Стиль: повествовательный, связный текст

## Соотношение периодов
- До 1917: 20% (~4 600 зн.)
- 1917–1990: 60% (~13 800 зн.)
- 1991–н.в.: 20% (~4 600 зн.)

## Название
Промышленность таганки

- Введение
- Часть I. От ремёсел к фабрикам (XVI–XIX вв.)
- Часть II. Советская индустриализация (1917–1990)
- Часть III. Постсоветская трансформация (1991–н.в.)
