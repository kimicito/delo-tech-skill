# check-understanding — Квиз по фазе курса

## Description

Контроль знаний без преподавателя: после фазы студент отвечает на вопросы, получает вердикт (сдано/повторить) и точечный список уроков на повтор.

## Triggers

- `/check-understanding <phase>`
- "проверь понимание фазы N"
- "квиз по фазе"
- "что повторить"

## Usage

1. Возьми банк фазы: `BANKS[phase]` (готовы банки для фаз 1, 4, 8).
2. Задай вопросы, для каждого покажи варианты с номерами и попроси выбрать индекс.
3. Собери ответы как список индексов и посчитай результат через `check_understanding.py`.
4. Покажи: `score`, `verdict` (порог сдачи 80%), и `review_lessons` — какие уроки повторить по неверным ответам.

## Files

- `check_understanding.py` — движок (`BANKS`, `grade`, `run_quiz`).

## How to Extend

Чтобы добавить фазу — допиши `BANKS[<phase>]` списком вопросов `{q, options, correct, lesson}`.
