# doc-assistant — RAG над своими документами

## Description

Складываешь документы в векторное хранилище и спрашиваешь их на естественном языке: retrieve → augment → ответ.

## Triggers

- `/doc-assistant`
- "спроси мои документы"
- "найди в корпусе"
- "ответь по базе знаний"

## Usage

1. **Индексация:** добавь документы в хранилище (`add(id, text)`); при необходимости сохрани на диск (`save`).
2. **Retrieval:** на вопрос достань топ-k релевантных кусков (`query(text, k)`).
3. **Augment + ответ:** подложи найденные куски в промпт модели и попроси ответить **только по ним** (снижает галлюцинации).

## Files

- `vector_store.py` — `VectorStore` (`add/query/save/load`), `embed`, `cosine`.

## Rules

- Документы дроби на куски (chunking) перед индексацией.
- В промпте требуй ответ строго по найденному контексту и проси цитаты.
- Качество ретрива измеряй (eval-harness): попадает ли нужный кусок в топ-k.
