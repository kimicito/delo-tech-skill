# editor — Редакторский конвейер

## Description

Обрабатывает текст стадиями: черновик/резюме → редактура → смена тона. Каждая стадия независима, можно оценивать отдельно.

## Triggers

- `/editor`
- "сократи текст"
- "отредактируй"
- "сделай в деловом тоне"
- "сделай резюме"

## Usage

1. **Черновик/резюме** — сжать до главного (extractive или промптом «сожми в N пунктов»).
2. **Редактура** — убрать воду, филлеры, повторы; короче и яснее.
3. **Тон** — привести под аудиторию (деловой / нейтральный / дружелюбный).

```python
import editing_pipeline as e
print(e.run_pipeline('привет очень всем', [e.tighten, lambda t: e.set_tone(t,'formal')]))
```

## Files

- `editing_pipeline.py` — `summarize_extractive`, `tighten`, `set_tone`, `run_pipeline`.

## Rules

- Стадии независимы — меняй и оценивай по одной (eval-harness).
- Для длинных документов сначала chunking + map-reduce, потом редактура.
