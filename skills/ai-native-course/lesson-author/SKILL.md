# lesson-author — Автор уроков курса AI Native

## Description

Скилл помогает писать уроки единообразно по каркасу курса: 6 шагов, фиксированная структура папок, definition of done.

## Triggers

- «напиши урок <id>»
- "сделай урок"
- "заполни docs/ru.md"
- "scaffold lesson"
- упоминание Build It / Use It / Ship It или папки phases/

## Usage

1. **Определи папку** из колонки «Папка» в README. Создай `code/`, `docs/`, `outputs/` если их нет.
2. **Напиши `docs/ru.md`** по шаблону — все 6 шагов, на русском.
3. **Build It → `code/`** — реализуй механизм урока с нуля, без внешних фреймворков; должно запускаться на CPU офлайн.
4. **Тест → `code/test_<name>.py`** — минимум один проходящий юнит-тест на ключевое поведение.
5. **Use It** — покажи то же через реальный инструмент/API.
6. **Ship It → `outputs/`** — положи артефакт (prompt/skill/agent/MCP) и опиши переиспользование.
7. **Проверь DoD** — прогони `pytest` по папке урока.
8. **Отметь готовность** — в `PROGRESS.md` поменяй `- [ ]` на `- [x]`.

## Template

```markdown
# Урок <id> · <название>

**Фаза <N> — <фаза>** · **Результат фазы:** <outcome>

> **MOTTO.** <идея в одну строку>

## PROBLEM
<конкретная боль>

## CONCEPT
<интуиция, диаграмма ASCII/mermaid>

## BUILD IT
<что собираем с нуля; ссылка на code/>

## USE IT
<то же через реальный инструмент/API>

## SHIP IT
**Артефакт:** <из колонки Ship It> → `outputs/`
<как переиспользовать>

## Материалы
- [<название>](<проверенный URL>) — <чем полезно>

---
**Часы:** ~<n> · **DoD:** ru.md заполнен, артефакт на месте (код запускается и тест зелёный — если урок их предполагает).
```

## Rules

- Никаких заглушек — только рабочий код.
- Объяснения по-русски, код по-английски, минимум зависимостей.
- Не меняй зафиксированные слаги папок.
- Коммит после фазы: `git add -A && git commit -m "Phase <N> (<phase-slug>): lessons complete"`
