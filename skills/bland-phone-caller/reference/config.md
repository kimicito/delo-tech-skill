# Bland.ai — Настройки по умолчанию

## Конфигурация звонков

### Язык и голос
| Параметр | Значение |
|----------|----------|
| **language** | `ru` (русский) |
| **voice** | `2d8fd873-ea3c-4914-9b0f-84b3e1b75dd6` (Allie) |
| **max_duration** | 600 сек (10 минут) |

### Доступные голоса
| ID | Имя | Описание |
|----|-----|----------|
| `2d8fd873-ea3c-4914-9b0f-84b3e1b75dd6` | **Allie** | Рекомендуется для русского |
| `4c5db7cb-f097-4880-8634-139f2567033d` | Mitch | Мужской, английский |
| `10a8fbe0-3d74-4bd4-9788-7f565c7e76a8` | Drew | Мужской, английский |

### Поведение звонка
| Параметр | Значение | Описание |
|----------|----------|----------|
| `wait_for_greeting` | `true` | Ждать "Алло" на том конце |
| `answered_by_enabled` | `true` | Определять, человек или автоответчик |
| `record` | `false` | Запись (включается флагом --record) |

### Шаблоны промптов

#### 1. Запись на приём
```
Вы — менеджер компании. Ваша задача записать клиента на приём. 
Будьте вежливы, кратки и профессиональны. 
Уточните: дату, время, ФИО клиента.
Если клиент согласен — подтвердите запись. 
Если нет — предложите альтернативное время.
```

#### 2. Уточнение заказа
```
Вы — менеджер по работе с клиентами. 
Уточните статус заказа и сроки доставки. 
Будьте дружелюбны и информативны.
```

#### 3. Напоминание
```
Вы — ассистент. Напомните клиенту о предстоящей встрече. 
Уточните время и место. 
Подтвердите, что клиент получил напоминание.
```

### Анализ результатов

Каждый звонок возвращает:
```json
{
  "success": true/false,
  "summary": "Краткое описание разговора",
  "details": "Детали: что согласовано, контакты, время"
}
```

## Использование

```bash
# Базовый звонок
node skills/bland-phone-caller/reference/scripts/call.js \
  --to +79001234567 \
  --task "Запишите на приём завтра в 15:00"

# С записью разговора
node skills/bland-phone-caller/reference/scripts/call.js \
  --to +79001234567 \
  --task "Уточните статус заказа №12345" \
  --record true

# С другим голосом
node skills/bland-phone-caller/reference/scripts/call.js \
  --to +79001234567 \
  --task "Напомните о встрече" \
  --voice 4c5db7cb-f097-4880-8634-139f2567033d
```

## Примечания

- Все звонки на русском языке по умолчанию
- Голос Allie — оптимизирован для русского
- Максимальная длительность: 10 минут
- Запись включается флагом `--record true`
