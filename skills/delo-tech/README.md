# delo-tech-skill

**OpenClaw skill для автоматизации ДЕЛО ТЕХ (rlisystems.ru/conterra/)**

[![GitHub](https://img.shields.io/badge/GitHub-delo--tech--skill-blue)](https://github.com/kimicito/delo-tech-skill)

## Что это?

Автоматизация работы с личным кабинетом **ДЕЛО ТЕХ** — системой управления контейнерными терминалами RLISystems.

## 💬 Примеры запросов

Вот какие вопросы можно задавать агенту:

### 📊 Отчёты (готово)

| Запрос | Результат |
|--------|-----------|
| "Выгрузи отчёт 13 за август" | Excel с движением по импорту |
| "Отчёт по импорту с 1 по 21 августа" | Фильтр по датам |
| "Сделай выгрузку из делотех за последнюю неделю" | Авто-расчёт периода |
| "Выгрузи движение по импорту в Excel" | Конвертация .xlsx |
| "Покажи отчёт по контейнерам" | Отчёт 13 |
| "Нужен отчёт 13 по договору 11640" | Фильтр по договору |

### 📦 Контейнеры (в разработке)

| Запрос | Результат |
|--------|-----------|
| "Где сейчас контейнер TKRU3055043?" | Статус и местоположение |
| "Проверь статус моих контейнеров" | Список активных |
| "Когда прибыл контейнер...?" | Дата прибытия |
| "Контейнер уже на терминале?" | Проверка локации |

### 📋 Релиз-ордера (в разработке)

| Запрос | Результат |
|--------|-----------|
| "Проверь релиз-ордера" | Список ордеров |
| "Есть новые релизы?" | Фильтр по статусу |

### 💰 Баланс и документы (в разработке)

| Запрос | Результат |
|--------|-----------|

### 🔄 Общие

| Запрос | Результат |

## 🚀 Быстрый старт

```bash
# Установка
pip install -r requirements.txt

# Отчёт 13 (Импорт)
python delo_tech.py --action report --report-type 13 \
    --start-date 01.08.2026 --end-date 21.08.2026
```

```python
from delo_tech import DeloTechCore

core = DeloTechCore()
result = core.run_report("13", "01.08.2026", "21.08.2026")
# → report_13_import.xlsx
```
