## 🎯 Цель

Получить отчёт 13 («Движение по импорту») для Терминала Врангель за указанный период с правильным договором.

---

## 🔑 Ключевые открытия

### 1. Разные терминалы = разные договоры

| Терминал | Договор | Статус |
|----------|---------|--------|
| **ПКТ АО** | РУСАЛТРАНС ООО, КЭ/ПКТ-22-2023 | ✅ Работает |
| **Терминал Врангель ООО** | РУСАЛТРАНС ООО, КЭ/ТВ-19-2024 | ✅ Работает |

**⚠️ Важно:** Если выбрать ПКТ АО + договор КЭ/ПКТ-22-2023, а затем сменить терминал на Врангель — отчёт покажет данные от ПКТ (или будет пустым), потому что договор привязан к терминалу.

**Решение:** После смены терминала обязательно выбрать правильный договор КЭ/ТВ-19-2024.

### 2. Сессия истекает очень быстро

- Время жизни сессии: ~5–10 минут бездействия
- При истечении — алерт "Сессия устарела" → переброс на страницу входа
- **Решение:** Обновлять страницу перед каждым действием, повторно входить

### 3. Навигация только через Playwright

- CDP-клики (synthetic) → Vaadin игнорирует ❌
- JavaScript `element.click()` → игнорирует ❌
- Playwright `page.click('text=Отчеты')` → ✅ Работает!

## 📊 Пошаговая инструкция (ручная)

### Шаг 1: Авторизация

1. Открыть `https://rlisystems.ru/conterra/`
2. Ввести логин: `pl_11640`
3. Ввести пароль: `Qwerty123`
4. Нажать "Вход"
5. Проверить: в заголовке должно быть `pl_11640 (4922-АП)` + баланс

### Шаг 2: Выбор терминала

1. В левом верхнем углу — combobox с текущим терминалом (по умолчанию "ПКТ")
2. Кликнуть на combobox → откроется выпадающий список
3. Выбрать "Терминал Врангель"
4. **Страница перезагрузится** — это нормально

### Шаг 3: Переход в отчёт 13

1. Левое меню → "Отчеты" (со стрелкой ▶)
2. Подменю → "Отчетность по обработке груза"
3. Пункт → "13. Движение по импорту"
4. Откроется форма параметров (справа)

### Шаг 4: Заполнение параметров

| Поле | Значение | Примечание |
|------|----------|------------|
| Стивидор | `ТЕРМИНАЛ ВРАНГЕЛЬ ООО` | Автоматически подставляется |
| Договор | `РУСАЛТРАНС ООО, договор КЭ/ТВ-19-2024` | Выбрать из списка! |
| Начало периода | `09.08.2026` | Формат: DD.MM.YYYY |
| Окончание периода | `29.08.2026` | Макс. 30 дней от начала |
| Представление | `Импорт` | По умолчанию |

### Шаг 5: Генерация отчёта

1. Нажать кнопку **"ПОКАЗАТЬ ОТЧЁТ"**
2. Подождать загрузки (2–5 секунд)
3. Данные появятся во фрейме справа

### Шаг 6: Просмотр данных

Заголовки таблицы:
- `N` — порядковый номер
- `Контейнер` — номер контейнера (например, TKRU3059412)
- `ISO тип` — тип контейнера (22G1)
- `Размер` — размер (DC)
- `Высотность` — высота (DC)
- `Вес брутто` — вес с грузом
- `Вес нетто` — вес груза
- `Вес тары` — вес пустого контейнера
- `Трафарет` — маркировка
- `Порожний` — пломбы
- `№ коносамента` — номер коносамента

### Шаг 7: Скачивание

- Кнопка **дискета** в тулбаре отчёта (вверху слева)
- Скачивает в формате Excel (.xlsx)

## 🤖 Автоматизация (через Playwright)

### Полный скрипт

```python
import asyncio
from playwright.async_api import async_playwright

async def get_report13_vrangel():
    """
    Получение отчёта 13 для Терминала Врангель.
    Требует активной сессии ДЕЛО ТЕХ.
    """
    playwright = await async_playwright().start()
    
    # Подключаемся к существующему Chrome
    browser = await playwright.chromium.connect_over_cdp("http://127.0.0.1:18800")
    
    # Находим страницу ДЕЛО ТЕХ
    page = None
    for context in browser.contexts:
        for p in context.pages:
            if "rlisystems.ru" in p.url:
                page = p
                break
        if page:
            break
    
    if not page:
        raise Exception("❌ Страница ДЕЛО ТЕХ не найдена")
    
    # Проверяем авторизацию
    content = await page.content()
    if "Вход в систему" in content:
        raise Exception("❌ Требуется авторизация")
    
    # Шаг 1: Выбираем Терминал Врангель
    await page.click('.v-filterselect:first-child', force=True)
    await asyncio.sleep(2)
    await page.click('text=Терминал Врангель', force=True)
    await asyncio.sleep(3)
    print("✅ Терминал Врангель выбран")
    
    # Шаг 2: Навигация в Отчеты → 13. Движение по импорту
    await page.click('text=Отчеты', force=True)
    await asyncio.sleep(2)
    await page.click('text=Отчетность по обработке груза', force=True)
    await asyncio.sleep(3)
    await page.click('text=13. Движение по импорту', force=True)
    await asyncio.sleep(5)
    print("✅ Отчёт 13 открыт")
    
    # Шаг 3: Заполняем параметры
    # Даты
    await page.fill('input[id*="gwt-uid-13"]', '09.08.2026')
    await page.fill('input[id*="gwt-uid-15"]', '29.08.2026')
    
    # Выбор договора (КЭ/ТВ-19-2024)
    # Примечание: combobox Vaadin требует особой обработки
    # См. ниже раздел "Особенности Vaadin combobox"
    
    print("✅ Параметры заполнены")
    
    # Шаг 4: Нажимаем "ПОКАЗАТЬ ОТЧЁТ"
    await page.click('text=ПОКАЗАТЬ ОТЧЁТ')
    await asyncio.sleep(5)
    print("✅ Отчёт сгенерирован")
    
    # Шаг 5: Извлечение данных
    data = await page.evaluate("""
        () => {
            const iframes = document.querySelectorAll('iframe');
            for (let f of iframes) {
                try {
                    const doc = f.contentDocument || f.contentWindow.document;
                    const tables = doc.querySelectorAll('table');
                    if (tables.length > 0) {
                        let result = [];
                        for (let table of tables) {
                            const rows = table.querySelectorAll('tr');
                            for (let row of rows) {
                                const cells = row.querySelectorAll('td, th');
                                const rowData = Array.from(cells).map(c => c.textContent.trim());
                                result.push(rowData);
                            }
                        }
                        return result;
                    }
                } catch(e) {}
            }
            return [];
        }
    """)
    
    print(f"✅ Извлечено {data.length} строк")
    return data

# Запуск
# asyncio.run(get_report13_vrangel())
```

## ⚠️ Особенности Vaadin combobox

**Проблема:** Поля "Стивидор" и "Договор" — это Vaadin combobox, не обычные `<input>`.

**Решение для выбора договора:**

```python
# Кликаем на combobox договора
await page.click('.v-filterselect:nth-child(3)')  # или по id
await asyncio.sleep(1)

# Вводим текст для фильтрации
await page.keyboard.type("КЭ/ТВ-19-2024")
await asyncio.sleep(1)

# Выбираем из списка
await page.click('text=РУСАЛТРАНС ООО, договор КЭ/ТВ-19-2024')
```

**Альтернатива:** Если combobox не открывается, можно:
1. Очистить поле (Triple-click + Delete)
2. Ввести текст полностью
3. Нажать Tab для подтверждения

## 🐛 Известные проблемы и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| "Сессия устарела" | Неактивность > 10 мин | Обновить страницу, повторно войти |
| Пустой отчёт | Неверный договор | Проверить договор (КЭ/ТВ-19-2024 для Врангеля) |
| Не кликается меню | Synthetic events | Использовать Playwright, не CDP |
| Не открывается combobox | Vaadin overlay | Кликать по кнопке ▼, не по полю |
| Данные из ПКТ при выборе Врангеля | Кэш/привязка договора | Заново выбрать договор КЭ/ТВ-19-2024 |
