# delo-tech

**Skill для автоматизации работы с личным кабинетом ДЕЛО ТЕХ (rlisystems.ru/conterra/)**

## Описание

Автоматизирует вход, навигацию и извлечение отчётов из системы «ДЕЛО ТЕХ» (RLISystems / Контейнерный терминал). Используется для логистики и таможенного документооборота.

## Триггеры

- Пользователь упоминает: "delo tech", "дело тех", "rlisystems", "conterra", "контейнерный терминал"
- Запрос на проверку статуса контейнера, релиз-ордеров, баланса
- Запрос на выгрузку отчёта (особенно отчёт 13 — «Движение по импорту»)

### ✅ Новый рабочий процесс (август 2026) — ПРОРЫВ

**Что работает:**
- ✅ **Навигация через Playwright** — клики по меню Vaadin работают!
- ✅ **Автоматическое открытие отчёта 13** — без участия пользователя
- ✅ **Заполнение дат** — поля "Начало/Окончание периода"
- ✅ **Нажатие "ПОКАЗАТЬ ОТЧЕТ"** — генерация отчёта
- ✅ **Извлечение данных** — из iframe с таблицей
- ✅ **Сохранение в CSV и Excel**

**Ключевое открытие:**
> Playwright `page.click('text=Отчеты')` использует **реальные события браузера**, которые Vaadin **принимает**.
> 
> CDP `Input.dispatchMouseEvent` = synthetic event → Vaadin **отбрасывает** ❌

**Рабочий процесс (полностью автоматический):**
1. Пользователь авторизован в ДЕЛО ТЕХ (активная сессия)
2. Агент подключается через CDP к авторизованной странице
3. **Навигация:** Playwright кликает: "Отчеты" → "Отчетность по обработке груза" → "13. Движение по импорту"
4. **Параметры:** Заполняет даты (максимум 30 дней)
5. **Генерация:** Нажимает "ПОКАЗАТЬ ОТЧЕТ"
6. **Извлечение:** Данные загружаются в iframe → извлекаются через CDP
7. **Сохранение:** CSV + Excel

### ⚠️ Ограничения

| Ограничение | Описание |
|-------------|----------|
| **30 дней макс** | Система не даёт выбрать период > 30 дней |
| **Активная сессия** | Требуется авторизация (сессия не должна протухнуть) |
| **Chrome CDP** | Должен быть запущен с `--remote-debugging-port=18800` |
| **Данные в iframe** | Отчёт загружается во iframe (извлекаем через `contentDocument`) |

## 🚀 Быстрый старт

### Установка

```bash
pip install -r requirements.txt
# Для навигации также нужен Playwright:
pip install playwright
playwright install chromium
```

### Полный цикл: Навигация + Извлечение

```bash
# Шаг 1: Навигация (Playwright кликает по меню)
python navigate_report13.py --start-date 12.08.2026 --end-date 28.08.2026

# Шаг 2: Извлечение данных (CDP)
python delo_tech.py --action report --report-type 13 \
    --start-date 12.08.2026 --end-date 28.08.2026
```

### Или через Python API

```python
from skills.delo-tech.delo_tech import DeloTechCore
from skills.delo-tech.navigate_report13 import DeloTechNavigator
import asyncio

# Навигация
async def run():
    nav = DeloTechNavigator()
    await nav.connect()
    await nav.navigate_to_report13()
    await nav.fill_dates("12.08.2026", "28.08.2026")
    await nav.click_show_report()

asyncio.run(run())

# Извлечение
core = DeloTechCore()
result = core.run_report("13", "12.08.2026", "28.08.2026")
print(f"✅ {result.row_count} строк сохранено")
```

## 🔧 Технические детали

### Почему два шага? (Навигация + Извлечение)

| Шаг | Инструмент | Причина |
|-----|-----------|---------|
| **Навигация** | Playwright | Реальные клики, которые Vaadin принимает |
| **Извлечение** | CDP | Прямой доступ к DOM, быстро и надёжно |

### Ключевые отличия: CDP vs Playwright

| Метод | Synthetic Events | Реальные Events | Работает с Vaadin |
|-------|-----------------|-----------------|-------------------|
| CDP `dispatchMouseEvent` | ✅ Да | ❌ Нет | ❌ Игнорирует |
| Playwright `click()` | ❌ Нет | ✅ Да | ✅ Принимает |
| JavaScript `element.click()` | ✅ Да | ❌ Нет | ❌ Игнорирует |

## 📝 CDP-скрипты для извлечения

### Проверка авторизации

```javascript
const hasDashboard = document.querySelector('.v-app') !== null;
const hasLogin = document.querySelector('input[type="password"]') !== null;
const hasBalance = document.body.textContent.includes('Баланс:');
return (hasDashboard && !hasLogin) || hasBalance;
```

### Извлечение таблицы из iframe

```javascript
const iframes = document.getElementsByTagName('iframe');
for (let f of iframes) {
    try {
        const doc = f.contentDocument || f.contentWindow.document;
        if (doc && doc.body) {
            const tables = doc.querySelectorAll('table');
            if (tables.length > 0) {
                let csv = '';
                for (let table of tables) {
                    const rows = table.querySelectorAll('tr');
                    for (let row of rows) {
                        const cells = row.querySelectorAll('td, th');
                        const rowData = Array.from(cells).map(c => c.textContent.trim());
                        csv += rowData.join(';') + '\n';
                    }
                }
                return csv;
            }
        }
    } catch(e) {}
}
return 'no data';
```
