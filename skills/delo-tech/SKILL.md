# delo-tech

**Skill для автоматизации работы с личным кабинетом ДЕЛО ТЕХ (rlisystems.ru/conterra/)**

## Описание

Автоматизирует вход, навигацию и извлечение отчётов из системы «ДЕЛО ТЕХ» (RLISystems / Контейнерный терминал). Используется для логистики и таможенного документооборота.

## Триггеры

- Пользователь упоминает: "delo tech", "дело тех", "rlisystems", "conterra", "контейнерный терминал"
- Запрос на проверку статуса контейнера, релиз-ордеров, баланса
- Запрос на выгрузку отчёта (особенно отчёт 13 — «Движение по импорту»)

### ⚠️ Важно: Как работает извлечение (август 2026)

**Что работает:**
- ✅ Подключение к CDP к авторизованной странице (с `pl_` в title)
- ✅ Извлечение данных таблицы из основного документа (Vaadin больше не в iframe)
- ✅ Сохранение в CSV и Excel

**Что НЕ работает:**
- ❌ Автоматическая навигация по меню Vaadin (клики игнорируются)
- ❌ Открытие отчёта без участия пользователя
- ❌ Переход по прямым URL (Vaadin использует History API без перезагрузки)

**Рабочий процесс:**
1. Пользователь входит в ДЕЛО ТЕХ в браузере вручную
2. Пользователь открывает нужный отчёт (например, Отчёт 13)
3. Агент подключается через CDP к авторизованной странице
4. Агент извлекает таблицу и сохраняет в файлы

### Принцип: Одно ядро — много операций

**Почему один skill, а не оркестратор:**
- ✅ **Общая сессия** — логин один раз на все операции
- ✅ **Общий CDP-клиент** — не дублируем код подключения к браузеру
- ✅ **Простота** — не нужен сложный оркестратор
- ✅ **Легко расширять** — добавляем модуль → добавляем операцию

**Когда переходить на оркестратор:**
- Когда операций станет > 15
- Когда нужны параллельные задачи
- Когда появятся независимые команды разработки

    """Моя новая операция."""

        // JavaScript для CDP

        const doc = frame.contentDocument || frame.contentWindow.document;
        
        // ... логика операции ...

    result = await cdp.execute(script)
    return json.loads(result)

# delo_tech.py → class DeloTechCore

## 🏛 Архитектура системы ДЕЛО ТЕХ

### Компоненты

| Компонент | URL | Назначение |
|-----------|-----|------------|
| Основной сайт | `https://rlisystems.ru/conterra/` | iframe-контейнер |
| SSO | `https://rlisystems.ru/webiom/sso/` | Аутентификация |
| Отчёты | `https://rlisystems.ru/conterra/reports/~<ID>.html` | Vaadin-отчёты |

### Технический стек

- **Frontend:** Vaadin Framework (GWT-based), теперь в основном документе (было в iframe)
- **Аутентификация:** SSO (Single Sign-On)
- **Отчёты:** Таблицы Vaadin в основном документе
- **Защита:** Элементы меню игнорируют синтетические события (клики, hover)

### Почему CDP?

| Подход | Результат |
|--------|-----------|
| curl/requests | ❌ 403/SSO |
| Playwright headless | ❌ Vaadin не рендерит |
| Playwright + клики | ❌ Элементы не реагируют |
| **CDP + авторизованная страница** | ✅ Извлечение данных работает |

## 📝 Примеры CDP-скриптов

### Проверка авторизации

```javascript
const hasDashboard = document.querySelector('.v-app') !== null;
const hasLogin = document.querySelector('input[type="password"]') !== null;
const hasBalance = document.body.textContent.includes('Баланс:');
return (hasDashboard && !hasLogin) || hasBalance;
```

### Извлечение таблицы (основной документ)

```javascript
// Vaadin теперь в основном документе, не в iframe
let csv = '';
const tables = document.querySelectorAll('table');

for (let t of tables) {
    const rows = t.querySelectorAll('tr');
    for (let r of rows) {
        const cells = r.querySelectorAll('td, th');
        if (cells.length > 3) {
            let row = [];
            for (let c of cells) {
                row.push(c.textContent.trim().replace(/\s+/g, ' '));
            }
            csv += row.join(';') + '\n';
        }
    }
}
return csv;
```

## 🎓 Универсальный шаблон разработки агента

Этот skill демонстрирует **полный цикл разработки** для enterprise-систем:

### Этапы (применимо к любой системе)

1. **Разведка** — анализ SPA/iframe/SSO/API
2. **Выбор стратегии** — curl → Playwright → CDP
3. **Реализация доступа** — подключение через CDP
4. **Извлечение данных** — JavaScript в контексте iframe
5. **Обработка** — CSV → Excel
6. **Проверка** — wc -l, head -5

### Антипаттерны

❌ Playwright + iframe (Vaadin теперь в основном документе)  
❌ Попытка кликнуть по меню Vaadin (synthetic events игнорируются)  
❌ Переход по прямым URL (History API без перезагрузки)  
❌ Ожидание автоматической навигации (требуется ручное открытие отчёта)  
✅ CDP + авторизованная страница + ручное открытие отчёта — рабочий путь
