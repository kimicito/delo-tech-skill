**Ключевое открытие:**
> Playwright `page.click('text=Отчеты')` использует **реальные события браузера**, которые Vaadin **принимает**.
> 
> CDP `Input.dispatchMouseEvent` = synthetic event → Vaadin **отбрасывает** ❌

**Рабочий процесс (полностью автоматический):**
1. Пользователь авторизован в ДЕЛО ТЕХ (активная сессия)
2. Агент подключается через CDP к авторизованной странице
3. **Навигация:** Playwright кликает: "Отчеты" → "Отчетность по обработке груза" → "13. Движение по импорту"
4. **Параметры:** Заполняет даты (максимум 30 дней)
5. **Генерация:** Нажимает "ПОКАЗАТЬ ОТЧЕТ"
6. **Извлечение:** Данные загружаются в iframe → извлекаются через CDP
7. **Сохранение:** CSV + Excel

### ⚠️ Ограничения

| Ограничение | Описание |
|-------------|----------|
| **30 дней макс** | Система не даёт выбрать период > 30 дней |
| **Активная сессия** | Требуется авторизация (сессия не должна протухнуть) |
| **Chrome CDP** | Должен быть запущен с `--remote-debugging-port=18800` |
| **Данные в iframe** | Отчёт загружается во iframe (извлекаем через `contentDocument`) |
| **Навигация Vaadin** | ❌ Автоклики по меню НЕ работают — только ручная навигация |

### ❌ Что НЕ работает автоматически

**Vaadin Menu Navigation:**
- CDP synthetic mouse events → Vaadin игнорирует ❌
- Playwright `mouse.click()` → Submenu не открывается ❌
- JavaScript `element.click()` → Vaadin блокирует ❌
- Прямой URL с параметрами → Vaadin игнорирует ❌

**Причина:** Компонент `ekp_menu_item_label` требует реальные события ОС (trusted events), которые невозможно эмулировать через CDP/Playwright на headless/remote сервере.

**Решение:** Ручная навигация пользователем + автоматическое извлечение данных агентом.

## 🔧 Технические детали

### Почему два шага? (Навигация + Извлечение)

| Шаг | Инструмент | Причина |
|-----|-----------|---------|
| **Навигация** | Playwright | Реальные клики, которые Vaadin принимает |
| **Извлечение** | CDP | Прямой доступ к DOM, быстро и надёжно |

### Ключевые отличия: CDP vs Playwright

| Метод | Synthetic Events | Реальные Events | Работает с Vaadin |
|-------|-----------------|-----------------|-------------------|
| CDP `dispatchMouseEvent` | ✅ Да | ❌ Нет | ❌ Игнорирует |
| Playwright `click()` | ❌ Нет | ✅ Да | ✅ Принимает |
| JavaScript `element.click()` | ✅ Да | ❌ Нет | ❌ Игнорирует |

## 📝 CDP-скрипты для извлечения

### Проверка авторизации

```javascript
const hasDashboard = document.querySelector('.v-app') !== null;
const hasLogin = document.querySelector('input[type="password"]') !== null;
const hasBalance = document.body.textContent.includes('Баланс:');
return (hasDashboard && !hasLogin) || hasBalance;
```

### Извлечение таблицы из iframe

```javascript
const iframes = document.getElementsByTagName('iframe');
for (let f of iframes) {
    try {
        const doc = f.contentDocument || f.contentWindow.document;
        if (doc && doc.body) {
            const tables = doc.querySelectorAll('table');
            if (tables.length > 0) {
                let csv = '';
                for (let table of tables) {
                    const rows = table.querySelectorAll('tr');
                    for (let row of rows) {
                        const cells = row.querySelectorAll('td, th');
                        const rowData = Array.from(cells).map(c => c.textContent.trim());
                        csv += rowData.join(';') + '\n';
                    }
                }
                return csv;
            }
        }
    } catch(e) {}
}
return 'no data';
```

### 🤖 Автоматизация (через Playwright)

#### Полный скрипт

```python
import asyncio
from playwright.async_api import async_playwright

async def get_report13_vrangel():
    """
    Получение отчёта 13 для Терминала Врангель.
    Требует активной сессии ДЕЛО ТЕХ.
    """
    playwright = await async_playwright().start()
    
    # Подключаемся к существующему Chrome
    browser = await playwright.chromium.connect_over_cdp("http://127.0.0.1:18800")
    
    # Находим страницу ДЕЛО ТЕХ
    page = None
    for context in browser.contexts:
        for p in context.pages:
            if "rlisystems.ru" in p.url:
                page = p
                break
        if page:
            break
    
    if not page:
        raise Exception("❌ Страница ДЕЛО ТЕХ не найдена")
    
    # Проверяем авторизацию
    content = await page.content()
    if "Вход в систему" in content:
        raise Exception("❌ Требуется авторизация")
    
    # Шаг 1: Выбираем Терминал Врангель
    await page.click('.v-filterselect:first-child', force=True)
    await asyncio.sleep(2)
    await page.click('text=Терминал Врангель', force=True)
    await asyncio.sleep(3)
    print("✅ Терминал Врангель выбран")
    
    # Шаг 2: Навигация в Отчеты → 13. Движение по импорту
    await page.click('text=Отчеты', force=True)
    await asyncio.sleep(2)
    await page.click('text=Отчетность по обработке груза', force=True)
    await asyncio.sleep(3)
    await page.click('text=13. Движение по импорту', force=True)
    await asyncio.sleep(5)
    print("✅ Отчёт 13 открыт")
    
    # Шаг 3: Заполняем параметры
    # Даты
    await page.fill('input[id*="gwt-uid-13"]', '09.08.2026')
    await page.fill('input[id*="gwt-uid-15"]', '29.08.2026')
    
    # Выбор договора (КЭ/ТВ-19-2024)
    # Примечание: combobox Vaadin требует особой обработки
    # См. ниже раздел "Особенности Vaadin combobox"
    
    print("✅ Параметры заполнены")
    
    # Шаг 4: Нажимаем "ПОКАЗАТЬ ОТЧЁТ"
    await page.click('text=ПОКАЗАТЬ ОТЧЁТ')
    await asyncio.sleep(5)
    print("✅ Отчёт сгенерирован")
    
    # Шаг 5: Извлечение данных
    data = await page.evaluate("""
        () => {
            const iframes = document.querySelectorAll('iframe');
            for (let f of iframes) {
                try {
                    const doc = f.contentDocument || f.contentWindow.document;
                    const tables = doc.querySelectorAll('table');
                    if (tables.length > 0) {
                        let result = [];
                        for (let table of tables) {
                            const rows = table.querySelectorAll('tr');
                            for (let row of rows) {
                                const cells = row.querySelectorAll('td, th');
                                const rowData = Array.from(cells).map(c => c.textContent.trim());
                                result.push(rowData);
                            }
                        }
                        return result;
                    }
                } catch(e) {}
            }
            return [];
        }
    """)
    
    print(f"✅ Извлечено {data.length} строк")
    return data

# Запуск

```
