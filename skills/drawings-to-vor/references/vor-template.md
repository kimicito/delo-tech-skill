# Стандартный формат ВОР (Вариант C — Объединённый)

## Структура документа

```
# ВЕДОМОСТЬ ОБЪЁМОВ РАБОТ № [N]

**Объект:** [название объекта]
**Проект:** [шифр проекта]
**Код ИСР:** [код]
**Основание:** [ссылка на чертежи]

---

## Раздел [N]. [Название раздела]

### [Марка элемента / Позиция]

| № п/п | Наименование работ и материалов | Ед.изм | Кол-во | Формула расчёта / Примечание |
|-------|--------------------------------|--------|--------|------------------------------|
| 1 | [Вид работы] | [м3/м2/шт/м/т/кг] | [число] | [формула] |
| 2 | [Материал на эту работу] | [ед] | [число] | [с учётом нормы расхода / формула] |
| 3 | [Следующая работа] | [ед] | [число] | [примечание] |

**Итого по [марке]:** [основной материал] — [X ед]

---

## Сводный итог

| Материал | Ед.изм | Всего | Примечание |
|----------|--------|-------|------------|
| Бетон [марка] | м3 | [X] | |
| Арматура [класс] | т / кг | [Y] | |
| [Другой материал] | [ед] | [Z] | |

**Подписи:**
Составил: _________________ / _________________
Проверил: _________________ / _________________
Дата: "____" _____________ 202__ г.
```

## Правила заполнения

### 1. Нумерация
- № п/п — сквозная по всей ведомости
- Внутри раздела — подпункты (1, 2, 3...)
- После каждой марки — подытог

### 2. Работы и материалы
- Сначала работа (укладка, устройство, монтаж)
- Сразу под ней — материал на эту работу
- Примечание: "с учётом нормы расхода" для материалов

### 3. Формулы
- Обязательно указывать формулу расчёта
- Примеры: `1163/1000`, `91,71/100`, `π×0.225²×12×14`
- Результат формулы = колонке "Кол-во"

### 4. Единицы измерения
- Объёмы: м3 (бетон, грунт)
- Площади: м2 (плёнка, окраска, щиты)
- Длины: м (швы, углы, балки)
- Масса: т / кг (арматура, металл)
- Количество: шт (закладные, детали)

### 5. Итоги
- По каждой марке — подытог основного материала
- В конце — сводная таблица по всем материалам
- Округление: до 2 знаков для м3/т, до 3 для м2

## Реквизиты для автоматического извлечения из чертежей

При распознавании чертежей извлекать:
1. **Марка элемента** (СБН12-450, П1, Фм1)
2. **Геометрические размеры** (D, L, H, B)
3. **Количество** (из таблицы спецификации)
4. **Марки материалов** (БСТ В25, арматура А500С)
5. **Формулы** (если указаны на чертеже)

## Автоматический расчёт

```python
# Сваи
pile_concrete = π * (diameter/2)**2 * length * count
pile_armature = pile_concrete * 120  # кг/м3
pile_extraction = pile_concrete * 1.15  # коэф. разрыхления

# Плиты
slab_concrete = length * width * height * count
slab_film = length * width * count * 1.225  # с расходом

# Фундаменты
foundation_concrete = sum([base_area * height for each])
```
