# Ozon Tax Calculator — Skill для расчёта налога Ozon на АУСН

## Назначение

Skill помогает рассчитать налог для ООО «Интернет Решения» (Ozon) на АУСН.
Алгоритм учитывает возвраты и услуги маркетплейса из отчётов о реализации и взаиморасчётах.

## Как использовать

Пользователь пишет: **«Рассчитай налог Ozon»** или **«Налог Озон»**.

### Диалог (что я должен спросить)

1. **За какой период?** (например, январь 2026)
2. **Отчёт о реализации** (Финансы → Документы → Отчёты о реализации). Нужны столбцы:
   - «Возвращено на сумму, руб.»
   - «Выплаты по механикам лояльности партнёров, руб.»
3. **Отчёт о взаиморасчётах** (Финансы → Документы → Аналитические отчёты). Нужен столбец:
   - «Суммы дебиторской задолженности» в строках:
     - Отчёт о реализации
     - Акт выполненных работ
     - Отчёт о перевыставлении услуг
     - Акт об оказанных услугах (Звёздные товары)

### Алгоритм расчёта

#### Шаг 1: Возвраты из «Отчёта о реализации»
- Сумма возвратов = Σ(«Возвращено на сумму, руб.») + Σ(«Выплаты по механикам лояльности партнёров, руб.»)

#### Шаг 2: Услуги из «Отчёта о взаиморасчётах»
- Комиссия (услуги) = Σ по строкам:
  - Отчёт о реализации
  - Акт выполненных работ
  - Отчёт о перевыставлении услуг
  - Акт об оказанных услугах (Звёздные товары)
- Столбец: «Суммы дебиторской задолженности»

#### Шаг 3: Внесение в ЛКН АУСН (операция «Взаимозачёт»)
- **Приход:** сумма комиссии + сумма возвратов
- **Возврат прихода:** сумма возвратов
- **Расход:** сумма комиссии
- Если возвратов нет — можно внести одной суммой (общей суммой удержаний)

## Формат ответа

| Показатель | Сумма |
|---|---|
| Возвраты | X руб. |
| Услуги (комиссия) | Y руб. |
| **Приход (в ЛКН)** | **X + Y руб.** |
| **Возврат прихода (в ЛКН)** | **X руб.** |
| **Расход (в ЛКН)** | **Y руб.** |

- Возвраты: 2 533,17 + 2,71 = **2 535,88 руб.**
- Услуги: 5 259,00 + 120 518,84 + 32 829,52 + 6 563,57 = **165 166,93 руб.**
- **Приход:** 165 166,93 + 2 535,88 = **167 702,81 руб.**
- **Возврат прихода:** **2 535,88 руб.**
- **Расход:** **165 166,93 руб.**
