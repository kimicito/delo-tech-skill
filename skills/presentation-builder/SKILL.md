# SKILL.md — Presentation Builder

## Назначение

Создание презентаций (PPTX/PDF) из нескольких источников:
- Объединение информации из документов
- Выделение ключевых тезисов
- Структурирование по слайдам
- Создание визуально чистой презентации

## Входные данные

| Тип | Формат | Пример |
|-----|--------|--------|
| Готовые презентации | PPTX | Шаблон структуры |
| Документы | PDF, DOCX, TXT | Исходный материал |
| Изображения | JPG, PNG | Иллюстрации |
| Ссылки | URL | Доп. источники |

## Алгоритм создания презентации

### Шаг 1: Анализ
1. Прочитать все входные файлы
2. Выделить ключевые тезисы
3. Определить хронологию/логику повествования

### Шаг 2: Структура
```
Слайд 1:  Титул (тема, докладчик, дата)
Слайд 2:  Введение (зачем это важно)
Слайд 3:  Определение ключевого понятия
Слайд 4-7: Основной контент (по блокам)
Слайд 8:  Примеры/кейсы
Слайд 9:  Современность/следы в настоящем
Слайд 10: Выводы/призыв к действию
```

### Шаг 3: Содержание слайда
- Заголовок: 3-7 слов
- Текст: 3-7 bullet points
- Максимум 40-60 слов на слайд
- Одна мысль = один слайд

### Шаг 4: Визуал
- Минимум текста, максимум смысла
- Изображения/схемы вместо абзацев
- Единый стиль (цвета, шрифты)

## Шаблон оформления

### Цвета (на примере слобод):
- Фон: Тёмный (#1a1a2e) или светлый (#f5f5f5)
- Акцент: Терракотовый (#c75b39) — кирпич, история
- Текст: Белый/чёрный в зависимости от фона

### Шрифты:
- Заголовки: Oswald, Playfair Display (исторические темы)
- Текст: Roboto, Open Sans

### Элементы:
- Карты (исторические + современные)
- Иллюстрации зданий
- Хронологические линии
- Схемы сравнения

## Инструменты создания

| Инструмент | Когда использовать |
|------------|-------------------|
| python-pptx | Генерация PPTX программно |
| LibreOffice Impress | Ручная сборка |
| Canva API | Шаблонные презентации |
| Marp (Markdown) | Быстрые текстовые презентации |

## Команды

```bash
# Python + python-pptx
pip install python-pptx

# Создание из Markdown
npm install -g @marp-team/marp-cli
marp input.md -o output.pdf
```
