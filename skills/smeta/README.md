# Smeta Skill — Составление смет по ФЕР-2020

## Архитектура пайплайна

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│   Чертежи PDF   │ ──▶ │  drawings-to-vor │ ──▶ │     smeta       │
│  (КЖ, КР, АР)   │     │  (ВОР.xlsx)     │     │  (Смета.xlsx)   │
└─────────────────┘     └─────────────────┘     └─────────────────┘
        │                       │                       │
        ▼                       ▼                       ▼
   PDF/PNG/JPG            Excel с объёмами        ЛСР с ценами
   Масштаб, спецификации  Позиции, ед.изм,        ФЕР-2020, БИМ
                          количества              НР, СП, ФССЦ
```

**Этот репозиторий — Stage 2** пайплайна. Принимает `ВОР.xlsx` из Stage 1 и формирует смету.

**Stage 1:** `github.com/kimicito/drawings-to-vor`

---

## Быстрый старт

```bash
# === STAGE 1: Подготовить ВОР (если ещё не готов) ===
cd ../drawings-to-vor
# ... см. README drawings-to-vor ...

# === STAGE 2: Составить смету ===
cd skills/smeta

# 1. Скопировать ВОР в data проекта
cp ../drawings-to-vor/ВОР.xlsx data/<object>/ВОР.xlsx

# 2. Составить смету по БИМ-методике
# → использовать SKILL.md (БИМ, ФЕР-2020, НР/СП, ФССЦ)

# 3. Проверить
python3 eval_smeta.py --smeta смета.xlsx --vor data/<object>/ВОР.xlsx
```

## Контракт с Stage 1 (drawings-to-vor)

| Что принимается | Откуда | Формат |
|-----------------|--------|--------|
| ВОР.xlsx | `../drawings-to-vor/` или `data/<object>/` | Excel (позиции, ед.изм, количества) |
| knowledge_base.md | Symlink к `drawings-to-vor/knowledge_base.md` | Markdown (коэффициенты) |

**Правило:** Всё, что в ВОР → должно быть в смете. Всё, что в смете → должно быть в ВОР.

## БИМ-методика: Ключевые правила

| Правило | Описание | Ошибка если нарушить |
|---------|----------|---------------------|
| **Индексы по статьям** | ОТ×INDEX_ZP, ЭМ×INDEX_MACH, М×INDEX_MAT | 7× занижение |
| **НР/СП от ФОТ** | Не от прямых затрат | 10× занижение |
| **ФССЦ отдельно** | Материалы через ФССЦ, не в ФЕР | Недоучёт |
| **Поправки по статьям** | Разные коэфф. для ОТ, ЭМ, М | Неверная цена |

**Подробнее:** см. `SKILL.md`

## 🔍 Проверка eval (ОБЯЗАТЕЛЬНО — без этого смета = черновик)

```bash
python3 scripts/eval_smeta.py --smeta смета.xlsx --vor ВОР.xlsx
```

**Без eval — отправлять нельзя.**

Проверяет 10 пунктов (FAIL = ошибка):
1. Все позиции ВОР есть в смете
2. Количества совпадают (±1%)
3. Нет лишних позиций
4. Нет «УТОЧНИТЬ» без пометки
5. НР/СП присутствуют (не пустые)
6. Индексы по статьям (не общий INDEX_SMR)
7. НР/СП от ФОТ (не от прямых)
8. Есть ФССЦ для материалов
9. Поправки до индексирования (не после)
10. Нет дублей кодов ФЕР

**Если FAIL → исправить → перезапустить eval → только потом отправлять.**
