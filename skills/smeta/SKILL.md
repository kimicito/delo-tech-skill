# ГРАНД-Смета — Составление смет

## Быстрый старт

1. **Выбор базы**: Файл → Выбор базы → ФСНБ-2022 (для РИМ)
2. **Создание структуры**: Объекты → Мои сметы → Создать папку → Создать смету
3. **Режим отображения**: Внизу окна — Форма локальной сметы 2020 (F7), Ресурсный расчёт (РМ)
4. **Параметры сметы**: F6 → Свойства (номер, наименование, даты, подписи)
5. **Добавление позиций**: Поиск расценок → добавление в смету → ввод объёмов
6. **Расчёт**: Загрузка текущих цен из ФГИС → применение индексов → печать

## Основные разделы

- **Создание сметы** — выбор базы, структура папок, параметры (F6)
- **Добавление позиций** — поиск расценок, обоснование, объёмы, разделы
- **Работа с ресурсами** — замена, добавление неучтённых, текущие цены
- **Коэффициенты** — к позиции, к смете, тендерные поправки
- **Индексы и цены** — загрузка из ФГИС, применение по категориям
- **Выходные документы** — печатные формы, экспорт в Excel

### Работа с ФЕР-2020 без доступа к ФГИС (offline / geo-blocked)

Когда доступ к ФГИС (fgisrf.ru) или FreeSmetaOnline ограничен (geo-block, нет API, сессия нестабильна), используй следующий пайплайн:

#### 1. Получение базовых цен ФЕР-2020 из PDF сборников
- **Источник**: PDF сборника ФЕР-2020 (например, ФЕР-20 «Вентиляция») с smetdlysmet.ru или meganorm.ru
- **Скачивание**: `curl -L "URL.pdf" -o fer20.pdf`
- **Извлечение цен**: Используй `pdf` tool с prompt для извлечения таблиц расценок
- **Что искать**: Таблицы ФЕР20-XX-XXX-XX с прямыми затратами (рубли 2000 года)
- **Пример позиций**:
  - ФЕР20-03-001-01 — Вентиляторы радиальные до 0.05т = 78.77 руб (2000)
  - ФЕР20-03-001-02 — Радиальные 0.05-0.1т = 152.60 руб (2000)
  - ФЕР20-03-002-01 — Осевые до 0.025т = 36.87 руб (2000)
  - ФЕР20-02-002-01 — Решетки жалюзийные до 0.5м² = 18.67 руб (2000)
  - ФЕР20-02-004-01 — Клапаны обратные до 355мм = 18.09 руб (2000)

#### 2. Применение индексов Минстроя
- **Источник**: Письма Минстроя России (например, №20212-ИФ/09 от 08.04.2026 для 2Q2026)
- **Где найти**: its.i-tat.ru/indexes/ или ergro.ru (фильтр по регионам и кварталам)
- **Структура индексов** (по элементам прямых затрат):
  - Оплата труда (INDEX_ZP)
  - Материалы, изделия, конструкции (INDEX_MAT)
  - Эксплуатация машин и механизмов (INDEX_MACH)
  - Общий индекс СМР (INDEX_SMR) — к базе ФЕР-2001/ФЕР-2020
- **Регион**: Иркутская область (1 зона), 2Q2026:
  - INDEX_SMR = 8.64
  - INDEX_ZP = 66.60
  - INDEX_MAT = 9.93 (кирпичные здания)
  - INDEX_MACH = 16.34

#### 3. Коэффициенты условий работ
- **К=1.15**: Работа в действующем здании без остановки технологического процесса (п.4.16 ФЕР-2020)
- Применяется к базовой цене перед индексированием

#### 4. Формула расчета
```
Текущая цена = Базовая цена ФЕР-2020 × К_условий × INDEX_SMR
Текущая сумма = Текущая цена × Количество
```

#### 5. Python-скрипт для генерации Excel-сметы
```python
import openpyxl
# Создает смету с 10 колонками:
# № | Код ФЕР | Наименование | Ед | Кол-во | Базовая цена | К=1.15 | Базовая сумма | Текущая цена | Текущая сумма
# Итоговые суммы автоматически через SUM
```
- **Сохранение**: `/tmp/smeta_FER2020_[регион]_[квартал].xlsx`
- **Формат**: 10 колонок, формулы, числовые форматы

#### 6. Ограничения и альтернативы
| Проблема | Решение |
|----------|---------|
| ФГИС geo-blocked | Использовать PDF сборники + индексы Минстроя |
| FreeSmetaOnline не имеет API | Ручной ввод или Excel-генерация |
| Браузерная сессия нестабильна | Не полагаться на automation, использовать offline-метод |
| Нужны точные текущие цены | Пользователь предоставляет данные из ГРАНД-Сметы / ФГИС |

#### 7. Типовые сборники ФЕР-2020
- Сборник 20 — Вентиляция и кондиционирование (475 позиций)
- Сборник 6 — Железобетонные и бетонные конструкции
- Сборник 8 — Отделочные работы
- Сборник 11 — Электротехнические работы
- Сборник 26 — Теплоизоляция

## Типичные задачи


### Составить локальную смету с нуля
1. Создать объект и смету
2. Выбрать нормативную базу (ФСНБ-2022 для РИМ)
3. Настроить параметры (F6): свойства, даты, подписи, шаблон расчёта
4. Добавить позиции из сборников или по аналогу
5. Ввести объёмы работ
6. Загрузить текущие цены из ФГИС ЦС
7. Применить индексы и коэффициенты
8. Сформировать итоги и выходные документы

### Пересчитать смету в новую базу
- Предварительная экспертиза позиций
- Пересчёт в ГЭСН-2020/ФЕР-2020
- Сравнение и корректировка

### Работа с актами выполненных работ
- Планируемое выполнение
- Отчёты по группе актов за период
