# Подробная инструкция по ГРАНД-Смете

## 1. Создание локальной сметы

### 1.1. Выбор нормативной базы
После запуска ПК «ГРАНД-Смета» выберите тип нормативной базы:
- **Файл → Выбор базы**
- Для ресурсно-индексного метода — **Учебная база ФСНБ-2022**

### 1.2. Создание папки объекта
- Объекты → Мои сметы → правая кнопка мыши → Создать папку
- Введите название объекта (например, «Жилой дом»)

### 1.3. Создание сметы
- Двойной клик по объекту → правая кнопка → Создать → Смета
- Введите название (например, «Общестроительные работы»)
- Двойной клик — открыть смету

### 1.4. Режим отображения и способ расчёта
- Внизу окна: **Форма локальной сметы 2020** (или F7)
- Способ расчёта: **Ресурсный расчёт (РМ)**

### 1.5. Параметры сметы (F6)

**Вкладка «Свойства»:**
- Локальный номер: ЛСР-02-01-01
- Наименование работ: Общестроительные работы
- Наименование стройки: тема ВКР или название проекта
- Даты составления/утверждения
- Уровень базисных цен: 01.01.2022
- Уровень текущих цен: квартал, год (загружается из ФГИС)

**Вкладка «Подписи»:**
- Основание: Ведомость объёмов работ №1
- Составил, Проверил — ФИО и должности

**Вкладка «Расчёт» — шаблон:**
- Эталонные шаблоны → Методики 2020-2024 → Новое строительство (НС) → Ресурсно-индексный метод

## 2. Добавление позиций

### 2.1. Поиск расценок
- Переход к сборникам нормативной базы
- Полнотекстовый поиск по наименованию
- Ручной переход к таблице сборника

### 2.2. Добавление в смету
- Найденная расценка → добавить в смету
- Указание обоснования (номер расценки в сборнике)
- Ввод объёмов работ в натуральных единицах или через формулу

### 2.3. Структура сметы
- Добавление разделов (по видам работ)
- Копирование/удаление позиций
- Нумерация позиций

## 8. Работа с ФЕР-2020 без доступа к ФГИС

### 8.1. Когда использовать
- Нет доступа к ФГИС (fgisrf.ru) — geo-block или технические проблемы
- FreeSmetaOnline не доступен или требует ручного ввода
- Нужно быстро получить ориентировочную смету с нормативными ценами

### 8.2. Пайплайн работы
1. **Определить сборник ФЕР-2020** (например, сборник 20 для вентиляции)
2. **Скачать PDF сборника** с smetdlysmet.ru или meganorm.ru
3. **Извлечь базовые цены** через pdf tool — искать таблицы ФЕР20-XX-XXX-XX
4. **Найти индексы Минстроя** для региона и квартала (its.i-tat.ru или ergro.ru)
5. **Применить коэффициенты** условий работ (например, К=1.15 для работы в действующем здании)
6. **Сгенерировать Excel** через Python (openpyxl) с формулами

### 8.3. Формула расчета
```
Базовая сумма (2000) = Базовая цена × Количество × К_условий
Текущая цена (2026) = Базовая цена × INDEX_SMR
Текущая сумма (2026) = Базовая сумма (2000) × INDEX_SMR
```

### 8.4. Источники данных
| Данные | Источник | URL |

| PDF сборники ФЕР-2020 | smetdlysmet.ru | https://smetdlysmet.ru/fer/ |

### 8.6. Пример расчета (Иркутская обл., 2Q2026)
- ФЕР20-03-001-01: 78.77 руб (2000) × 2 шт × 1.15 × 8.64 = 1,566.32 руб (2026)
- Индекс СМР Иркутск (1 зона): 8.64 (письмо №20212-ИФ/09)
- Коэффициент 1.15: п.4.16 ФЕР-2020 (работа в действующем здании)

## 9. Типовые коэффициенты ФЕР-2020

### 9.1. Коэффициенты условий работ
- **К=1.15**: Работа в действующих зданиях без остановки технологического процесса (п.4.16)
- **К=1.10**: Работа в ограниченных условиях (п.4.17)
- **К=1.20**: Работа на высоте свыше 6 м (п.4.18)
- **К=1.25**: Работа в зимний период (п.4.19)

### 9.2. Поправки к сборникам
- Сборник 20 (вентиляция): коэффициенты на материал воздуховодов (оцинкованная сталь, алюминий, коррозионностойкая сталь)
- Применение из приложений к сборнику
