# Полезные ресурсы по ГРАНД-Смете

## Методички и PDF

**Методичка Гранд-Смета 2024 РИМ (PDF, 50 стр.)**
- ННГАСУ, кафедра строительной экономики
- Содержание: создание сметы, разделы, поиск норм, добавление позиций, учёт ресурсов, нумерация, коэффициенты, перевозка, текущие цены, допзатраты, печать
- Ссылка: https://bibl.nngasu.ru/electronicresources/uch-metod/construction_economics/877924.pdf

## Видеокурсы (бесплатные)

**Видеокурс от all-smety.ru**
- Разделы: нормативная база, объекты и сметы, добавление позиций, объёмы, выходные документы
- Ссылка: https://www.all-smety.ru/programs/smetnye_programmy/grandsmeta/rukovodstvo-grand-smeta-5/

**Видеоуроки на Яндекс-Видео**

- Темы: составление смет на ремонт, фундамент, РИМ, ГЭСН-2022, акты выполнения
- Пример: https://ya.ru/video/preview/6445787661135192605

**Как извлечь цены из PDF:**
1. Скачать: `curl -L "URL.pdf" -o ferXX.pdf`
2. Скопировать в workspace: `cp ferXX.pdf /root/.openclaw/workspace/ferXX.pdf`
3. Извлечь таблицы: `pdf` tool с prompt для поиска таблиц ФЕР20-XX-XXX-XX
4. Искать колонку "Прямые затраты" или "Всего" в рублях 2000 года

## Ключевые горячие клавиши

- **F6** — Параметры сметы
- **F7** — Вид документа (Локальная смета 2020)
- **Ctrl+S** — Сохранить смету
- **Ctrl+Z** — Отменить изменение

## Базовые понятия

- **ЛСР** — Локальный сметный расчёт
- **ВОР** — Ведомость объёмов работ
- **ФСНБ** — Федеральная сметная нормативная база
- **ГЭСН** — Государственные элементарные сметные нормы
- **ФЕР** — Федеральные единичные расценки
- **РИМ** — Ресурсно-индексный метод
- **БИМ** — Базисно-индексный метод
- **ФГИС ЦС** — Федеральная государственная информационная система ценообразования в строительстве
