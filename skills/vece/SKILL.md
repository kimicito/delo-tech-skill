# 🏛️ Вече — Мудрый Совет для Тяжёлых Решений

## Команды

| Команда | Описание | Пример |
|---------|----------|--------|
| `созови вече [вопрос]` | Созвать совет из 4 мудрецов | созови вече Как монетизировать SafeMind? |
| `вече --triad [домен] [вопрос]` | Конкретная триада | вече --triad strategy Как выйти на рынок? |
| `вече --duo [вопрос]` | Дуэль двух мудрецов | вече --duо Подписка или разовая оплата? |
| `вече --быстро [вопрос]` | 2 раунда быстрого совета | вече --быстро Какой цвет кнопки? |

## Пример Использования

**Пользователь:** созови вече Как монетизировать SafeMind?

**Система:**
1. Анализирует вопрос → определяет домен (monetization = economics)
2. Выбирает 4 мудрецов: Мангер, Сунь-Цзы, Макиавелли, Аврелий
3. Создаёт 4 subagent'ов с ролями мудрецов
4. Проводит 3 раунда дискуссии
5. Выдаёт вердикт с рекомендациями

**Протокол:**
- Раунд 1: Независимый анализ (300 слов каждый)
- Раунд 2: Перекрёстный допрос (критика других, 200 слов)
- Раунд 3: Финальные позиции (100 слов, голосование)
- Вердикт: Синтез + нерешённые вопросы + следующие шаги

## Формат Вердикта

```
🏛️ ВЕРДИКТ ВЕЧЕ

📋 Вопрос: [исходный вопрос]
👥 Мудрецы: [имена]

🔑 КЛЮЧЕВЫЕ ВЫВОДЫ:
1. [вывод 1]
2. [вывод 2]
3. [вывод 3]

⚖️ ГОЛОСОВАНИЕ:
- За вариант А: [голоса]
- За вариант Б: [голоса]
- Воздержались: [голоса]

🎯 РЕКОМЕНДАЦИЯ:
[конкретное действие]

❓ НЕРЕШЁННЫЕ ВОПРОСЫ:
- [вопрос 1]
- [вопрос 2]

📌 СЛЕДУЮЩИЕ ШАГИ:
1. [действие 1]
2. [действие 2]
```

## Интеграция с Council of High Intelligence

Этот skill использует файлы персонажей из:
`~/.openclaw/workspace/skills/council-of-high-intelligence/agents/`

Каждый мудрец — это markdown-файл с system prompt для subagent.

## Требования

- Доступ к `sessions_spawn` (subagent runtime)
- Модель kimi (или другая, поддерживающая system prompts)
- 18 файлов мудрецов в `council-of-high-intelligence/agents/`
