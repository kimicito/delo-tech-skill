# WB Tax Calculator (РВБ / Wildberries) — РАСЧЁТ НАЛОГА АУСН

## Источники данных

| Документ | Для чего | Формат |
|----------|----------|--------|
| **Еженедельные отчёты о реализации** | Основная комиссия | PDF |
| **Детализация к отчёту о реализации** | Возвраты | Excel |
| **Уведомления о выкупе** | Проверка выкупов | PDF |
| **Реестр еженедельных операций** | Только для выкупов | Excel |

## Алгоритм расчёта

### Шаг 1: Комиссия по еженедельным отчётам (PDF)

**Если в отчёте НЕТ отрицательных сумм в строках 2.1 и 2.2:**
```
Комиссия = (2) Итого зачтено + (3) Удержания в пользу третьих лиц + (6) Баллы лояльности + (7) Разовое изменение срока
```

**Если в отчёте ЕСТЬ отрицательные суммы в строках 2.1 и 2.2:**
```
Комиссия = Σ(2.3-2.10 положительные) + (3) + (6) + (7)
```

**Суммируем по всем отчётам за месяц.**

### Шаг 2: Возвраты (из Детализации Excel)

1. Открыть детализацию к отчёту о реализации (не к выкупу!)
2. Отфильтровать: `Тип документа` = "Возврат"
3. Взять сумму из столбца `Вайлдберриз реализовал Товар (Пр)`
4. Суммировать по всем отчётам

**Важно:** Возвраты из детализации к выкупам НЕ используются!

### Шаг 3: Комиссия по выкупам (Реестр + Уведомления)

1. В Реестре отфильтровать: `Тип отчета` = "По выкупам"
2. Для каждого выкупа сравнить:
   - Уведомление о выкупе (PDF)
   - Реестр → `Итого к оплате`
3. Если суммы равны → комиссия = 0
4. Если различаются → комиссия = Уведомление − Итого к оплате
5. Если Итого к оплате отрицательное → комиссия = Уведомление + |Итого к оплате|

### Шаг 4: Итоговые суммы для ЛКН АУСН

| Поле | Формула |
|------|---------|
| **Приход** | Комиссия (отчёты) + Возвраты + Комиссия (выкупы) |
| **Возврат прихода** | Возвраты |
| **Расход** | Комиссия (отчёты) + Комиссия (выкупы) |

### Если возвратов НЕТ:
Внести общей суммой (одно число) = Комиссия (отчёты) + Комиссия (выкупы)

## Пример из инструкции (январь 2026)

**Еженедельные отчёты:**
| Период | Комиссия |
|--------|----------|
| 01.01-04.01 | 9 655,01 |
| 05.01-11.01 | 10 618,99 |
| 12.01-18.01 | 20 072,91 |
| 19.01-25.01 | 10 500,00 |
| **Итого** | **50 846,91** |

**Возвраты:**
| Период | Сумма |
|--------|-------|
| 05.01-11.01 | 38 934,00 |
| 19.01-25.01 | 6 455,00 |
| **Итого** | **45 389,00** |

**Выкупы:**
| № Уведомления | Уведомление | Реестр | Комиссия |
|---------------|-------------|--------|----------|
| 608322128 | 13 856,59 | 11 554,60 | 2 301,99 |
| 601767378 | 10 555,75 | 10 555,75 | 0,00 |
| **Итого** | | | **2 712,75** |

**Итог для ЛКН АУСН:**
- Приход: 50 846,91 + 45 389,00 + 2 712,75 = **98 948,66**
- Возврат прихода: **45 389,00**
- Расход: 50 846,91 + 2 712,75 = **53 559,66**

## Критически важно

1. **Комиссия считается из PDF отчётов**, не из Реестра Excel
2. **Реестр нужен только для выкупов**
3. **Возвраты только из детализации к отчёту о реализации** (не к выкупу)
4. **Отличить детализацию:** в детализации к выкупу — только страны ЕАЭС; к отчёту — Россия и другие
