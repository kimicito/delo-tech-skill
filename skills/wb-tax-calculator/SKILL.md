# WB Tax Calculator — Skill для расчёта налога РВБ (Wildberries) на АУСН

## Назначение

Skill помогает рассчитать сумму взаимозачёта для ООО «РВБ» (Wildberries) на АУСН «Доходы» (8%).

## Как использовать

Пользователь пишет: **«Рассчитай налог»** или **«Налог РВБ»**.

### Диалог (что я должен спросить)

1. **За какой месяц/период?** (например, январь 2026)
2. **Загрузите реестр еженедельных операций** (Финансы → Финансовые отчеты → Сохранить → Скачать реестр). Нужен файл со столбцами: «Тип отчета», «Продажа», «Итого к оплате».
3. **Данные из Аналитики** — Доходы и расходы → период → «Потери, подмены и товары с дефектами» (если были).

## Алгоритм расчёта (верный)

### Шаг 1: Комиссия (Основной)
```
Комиссия = Σ(Продажа) − Σ(Итого к оплате)
```
— только для строк с `Тип отчета = "Основной"`

### Шаг 2: Дополнительные удержания
```
Доп. удержания = Σ(Логистика) + Σ(Хранение) + Σ(Приёмка) + Σ(Прочие) + Σ(Штрафы) + Σ(Корректировка ВВ) + Σ(Лояльность) + Σ(Баллы)
```

### Шаг 3: Итого для взаимозачёта
```
Итого = Комиссия + Доп. удержания
```

### Шаг 4: Внесение в ЛКН АУСН
- Если **нет возвратов** → внести общей суммой (одно число)
- Если **есть возвраты** → разбить на 3 операции:
  | Поле | Формула |
  |------|---------|
  | Приход | Итого + Возвраты |
  | Возврат прихода | Возвраты |
  | Расход | Итого |

## Формат ответа

| Показатель | Сумма |
|---|---|
| Комиссия (Основной) | X руб. |
| Доп. удержания (логистика, приёмка и др.) | Y руб. |
| **Итого для взаимозачёта** | **X+Y руб.** |

**Важно:** При АУСН «Доходы» налог = Полные продажи × 8%. Сумма X+Y — это удержания маркетплейса, которые нужно отразить в ЛКН АУСН как взаимозачёт.

## Пример (апрель 2026)

| Компонент | Сумма |
|-----------|-------|
| Продажа | 11,941.00 |
| Итого к оплате | 11,765.88 |
| **Комиссия** | **175.12** |
| Логистика | 455.39 |
| Приёмка | 15.00 |
| **ИТОГО для взаимозачёта** | **645.51 ≈ 648** |
