# WB Tax Calculator — Skill для расчёта налога РВБ (Wildberries) на АУСН

## Назначение

Skill помогает рассчитать налог для ООО «РВБ» (Wildberries) на АУСН.  
Алгоритм учитывает комиссию маркетплейса, возвраты, выкупы и дополнительные расходы (потери, подмены, дефекты).

## Как использовать

Пользователь пишет: **«Рассчитай налог»** или **«Налог РВБ»**.

### Диалог (что я должен спросить)

1. **За какой месяц/период?** (например, январь 2026)
2. **Загрузите реестр еженедельных операций** (Финансы → Финансовые отчеты → Сохранить → Скачать реестр). Нужен файл со столбцами: «Тип отчета», «Продажа», «Итого к оплате».
3. **Загрузите детализации отчётов** (Финансы → Финансовые отчеты → Детализация). Нужен столбец «Тип документа» и «Вайлдберриз реализовал Товар (Пр)».
4. **Уведомления о выкупе** — нужны суммы из раздела «Документы» для отчётов типа «По выкупам».
5. **Данные из Аналитики** — Доходы и расходы → период → «Потери, подмены и товары с дефектами» (если были).

### Алгоритм расчёта

#### Шаг 1: Реестр операций
- Отфильтровать по типу «Основной» → суммировать столбцы «Продажа» и «Итого к оплате»
- Комиссия (Основной) = Σ(Продажа) − Σ(Итого к оплате)

#### Шаг 2: Выкупы
- Для каждого отчёта типа «По выкупам» сравнить сумму в реестре (столбец «Итого к оплате») с суммой из «Уведомления о выкупе»
- Комиссия (выкуп) = Сумма Уведомления − Сумма в реестре (если равны — 0)
- Итоговая комиссия по выкупам = Σ всех комиссий по выкупам

#### Шаг 3: Дополнительные расходы
- Аналитика → Доходы и расходы → «Потери, подмены и товары с дефектами» (если есть)

#### Шаг 4: Итоговая комиссия
- Итого комиссия = Комиссия (Основной) + Комиссия (выкупы) + Доп. расходы

#### Шаг 5: Возвраты
- Из детализации отчётов: фильтр по «Тип документа» = возврат
- Сумма возвратов = Σ столбца «Вайлдберриз реализовал Товар (Пр)»
- Проверить по всем отчётам с типом «Основной»

#### Шаг 6: Внесение в ЛКН АУСН
- Комиссия + услуги маркетплейса → операция взаимозачета
- Если возвраты → несколько операций: приход, возврат прихода, расход

## Формат ответа

| Показатель | Сумма |
|---|---|
| Комиссия (Основной) | X руб. |
| Комиссия (Выкупы) | Y руб. |
| Доп. расходы (потери/подмены) | Z руб. |
| **Итого комиссия** | **X+Y+Z руб.** |
| Возвраты | V руб. |
| **Рекомендация по ЛКН АУСН** | Внести взаимозачет на сумму X+Y+Z, возвраты на V |
