# Школа № 1270 «Вектор» (Таганский район, ЦАО Москва)

## Основные факты

| Параметр | Значение |
|----------|----------|
| **Полное название** | ГБОУ «Школа № 1270 «Вектор»» |
| **Год основания** | 1936 |
| **Расположение** | Москва, Таганский район, ЦАО |
| **Адрес** | Товарищеский пер., д. 21 |
| **Директор** | Кинешова Вера Павловна |
| **Учащиеся** | ~1 200 |
| **Рейтинг** | топ 221–300 (2025) |

## История

| Год | Событие |
|-----|---------|
| **1936** | Школа открыта как **женская восьмилетняя школа**. Средняя наполняемость классов — до 50 человек, общее число учащихся около 1 100 |
| **Довоенные годы** | Школа носила номер **№ 477**, неоднократно меняла районную принадлежность |
| **Великая Отечественная война** | Школа продолжала работу, не прекращая обучение |
| **1995** | Переезд в нынешнее здание «дворцового типа». К основному корпусу 1936 года добавлена пристройка |
| **1997** | Утверждён статус **СОШ с углубленным изучением английского языка**. Школе присвоен номер **1270** |
| **2017** | Школа получила имя **«Вектор»**. Подключена к проекту «Математическая вертикаль» |
| **2019** | Выпускники заняли **24-е место в Москве** по баллам ЕГЭ. Три диплома финала ВсОШ по истории и английскому языку |
| **2022** | Включена в **50 лучших школ России** по направлению «Социальные и гуманитарные науки» (рейтинг RAEX) |

## Архитектура

Здание школы стилизовано под **старинный замок**:
- Высокая арка у центрального входа
- Башенка с винтовой лестницей
- Основной корпус — 1936 года постройки
- Пристроенная часть — 1995 года

## Английская специализация

- Английский язык изучается **углубленно во всех классах**
  - Начальная школа: 3 урока в неделю
  - Основная школа: 5 уроков в неделю
- **Второй иностранный**: немецкий, китайский или французский
- **МХК** ведётся на английском языке
- **Кембриджский сертификат** — программа подготовки
- Дни открытых дверей: весной и осенью

## Профили обучения

- Медийные классы (журналистика, видеожурналистика, арт-менеджмент)
- Предпринимательские классы
- Сотрудничество с РГГУ, РЭУ им. Плеханова, МПГУ, ГУ нефти и газа им. Губкина

## Дополнительное образование

- Шахматы (за счёт часов физкультуры)
- Лего-конструирование
- Театральное творчество
- Вокальный ансамбль
- Компьютерный дизайн
- Предметные олимпиады

## Достижения

| Год | Достижение |
|-----|------------|
| **2016** | Более 54% выпускников набрали 220+ баллов за три ЕГЭ (65-й результат по Москве) |
| **2017** | Из 65 старшеклассников 42 человека преодолели отметку 220 баллов |
| **2019** | 24-е место в Москве по ЕГЭ. Финал ВсОШ — 3 диплома |
| **2022** | 2/3 выпускников вышли за уровень 220 баллов. Вход в топ-50 России (RAEX) |
| **2023** | Прыжок на сотню позиций вверх по рейтингу ДОНМ |

## Интересные факты

- Школа — чисто гуманитарная: доминируют языки, история, обществознание, литература
- В 2019 году 30 из 35 выпускников сдавали ЕГЭ по английскому языку
- Подготовительные курсы для дошкольников («М-школа»): 7 500 ₽/месяц
- Экскурсии за кулисы Большого театра, лекции в Театральном институте им. Б. Щукина

## Известные выпускники

В открытых источниках **не найдены** широко известные выпускники мирового уровня. Школа славится высокими результатами ЕГЭ и олимпиад.
