# Generative AI

## Definition

AI-системы, которые создают новый контент: текст, изображения, код, данные. Основная технология — Large Language Models (LLM).

## В банковском секторе

Применяется для:
- Генерации ответов в чат-ботах
- Анализа неструктурированных документов
- Создания кредитных заключений
- Персонализации коммуникаций

## Кейсы

- [[Т-Банк]]: RAG + LLM для поддержки клиентов
- [[Сбер]]: LLM для анализа неструктурированных данных в кредитовании

## Регуляторные риски

- Требование explainability (особенно для кредитных решений)
- «Чёрный ящик» — сложность интерпретации
- Провал одного из топ-10 банков: LLM для кредитных заключений отключён через 3 месяца из-за регуляторного давления

## Доля внедрений

23 % крупных банков — пилоты (2026).
