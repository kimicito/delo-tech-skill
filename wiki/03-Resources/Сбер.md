# Сбер

## Описание

Крупнейший банк России. Лидер по внедрению AI в кредитование.

## AI-кейс: Платформа для кредитования

- **Задача:** сократить срок рассмотрения заявки с 5 дней до 2 минут
- **Решение:** ансамбль из 40+ ML-моделей + LLM для анализа неструктурированных данных
- **Результат:** 95 % заявок — автоматическое решение за 2 минуты, NPL снизился на 0.3 п.п.
