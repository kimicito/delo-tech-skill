# Т-Банк

## Описание

Один из крупнейших российских банков. Лидер по внедрению генеративного AI в клиентскую поддержку.

## AI-кейс: Генеративный AI в поддержке

- **Задача:** снизить нагрузку на операторов первой линии
- **Решение:** RAG-система на базе внутренней базы знаний + LLM
- **Результат:** 60 % обращений закрываются без оператора, CSAT вырос на 12 %

## Технологии

- [[Generative AI]] — LLM
- RAG — Retrieval-Augmented Generation
