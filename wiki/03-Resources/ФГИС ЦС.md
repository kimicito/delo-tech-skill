# ФГИС ЦС

**Полное название:** Федеральная государственная информационная система ценообразования в строительстве

**Владелец:** Минстрой России

**URL:** https://fgiscs.minstroyrf.ru

**Статус:** Действующая система

## Что содержит

- [[Индексы]] — индексы изменения сметной стоимости по регионам и кварталам
- [[ФССЦ]] — федеральные сметные цены на материалы, изделия, конструкции
- [[ФЕР]] — федеральные единичные расценки
- [[ГЭСН]] — государственные элементные сметные нормы
- [[ФСНБ]] — федеральные сметные нормы и расценки
- Справочники базовых цен на проектные работы
- Справочники базовых цен на изыскания

## Индексы

Индексы публикуются ежеквартально по письмам Минстроя.

Пример (Иркутская обл., 1 зона, 2Q2026):
- [[INDEX_ZP]] = 66.60 (оплата труда)
- [[INDEX_MACH]] = 16.34 (эксплуатация машин)
- [[INDEX_MAT]] = 9.93 (материалы, кирпичные здания)
- [[INDEX_SMR]] = 8.64 (общий — только для ориентировки, не для расчёта!)

## Ограничения доступа

- Иногда geo-blocked из-за РФ
- Нет официального API
- Браузерная сессия может быть нестабильной
- Альтернатива: PDF писем Минстроя + ручной ввод

## Альтернативные источники

- **its.i-tat.ru/indexes/** — индексы по регионам
- **ergro.ru** — индексы с фильтром по регионам и кварталам
- **gge.ru** — письма Минстроя в PDF
- **Письма Минстроя** — официальные документы с индексами
