## 📝 Пошаговая инструкция

### Шаг 1: Открыть Метрику
1. Перейди на [metrika.yandex.ru/list/](https://metrika.yandex.ru/list/)
2. Войди в аккаунт (если не авторизован)

### Шаг 2: Выбрать счётчик
1. Найди нужный счётчик по номеру (92824982, 30201489 или 45030274)
2. Кликни на него

### Шаг 3: Открыть раздел Цели
1. Нажми на шестерёнку (Настройки) вверху
2. Выбери **"Цели"** в меню слева
3. Нажми **"Добавить цель"**

### Шаг 4: Создать цель
1. **Тип цели:** выбери **"JavaScript-событие"**
2. **Название:** введи понятное название (из таблицы выше)
3. **Идентификатор:** введи точный идентификатор (из таблицы, важно!)
4. Нажми **"Добавить цель"**

### Шаг 5: Повторить
- Повтори шаг 4 для каждой цели из таблицы
- Это займёт ~5 минут на сайт

## ✅ Проверка после создания

Через 24 часа проверь в отчётах Метрики:
1. **Отчёты → Стандартные → Конверсии**
2. Должны появиться твои цели со статистикой
