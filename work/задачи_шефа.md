## Правила нумерации
- Нумерация **жёсткая** — раз и навсегда.
- При удалении задачи номер освобождается, **перенумерация запрещена**.
- Новая задача = `max(существующие номера) + 1`.
- Пробелы в нумерации — норма.

## Правила evidence
- Каждая задача P1+ должна иметь evidence-файл
- Evidence = факты, переписка, решения, статус
- Обновлять evidence после каждого действия

## Правила gates
- Gate = точка остановки для решения шефа
- Обозначать ⛔ Gate: [описание]
- Не двигать задачу дальше без аппрува
